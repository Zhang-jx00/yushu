# 御书

> **宗旨：从起源构建世界。**
> 每一部小说都不单单是一篇文字，而是要创作出另一个世界——文化完整，有历史，有生态，有人文，有地理的完整世界。

「御书」是一款 **开源、本地优先、全流派** 的小说创作操作系统：以"世界"为第一公民，故事只是这个世界的一个切面。

## 它解决什么问题

| 写作者的痛点 | 御书的答案 |
|---|---|
| 设定散落在无数文档里，写着写着就崩 | **起源工作台**：从创世起源→法则→地理→生态→历史→文明→社会现状，引导式分层建档 |
| 改了上游设定，下游全书穿帮 | **世界引擎**：设定变更影响传播 + 跨层一致性校验（战力/时间线/人物-历史冲突） |
| AI 写着写着忘了人设、战力崩塌 | **记忆系统**：设定卡→卷摘要→章摘要→RAG 分层记忆，AI 生成时强制注入世界约束 |
| 各流派写法天差地别，工具一套模板打天下 | **流派引擎**：四维派系模型（频道×世界×手法×基调）+ 可组合/可自定义的派系包 |
| AI 代笔的合规风险 | **人类创作证据链**：编辑轨迹留存、AI 使用记录、平台申报材料一键导出 |
| 云同步失效 = 稿件蒸发 | **数据主权**：Markdown 开放格式 + 本地优先 + git 友好 + 可选 WebDAV/S3 备份 |
