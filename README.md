# 御书

> **宗旨：从起源构建世界。**
> 每一部小说都不单单是一篇文字，而是要创作出另一个世界——文化完整，有历史，有生态，有人文，有地理的完整世界。

「御书」是一款 **开源、本地优先、全流派** 的小说创作操作系统：以"世界"为第一公民，故事只是这个世界的一个切面。

## 它解决什么问题

| 写作者的痛点 | 御书的答案 |
|---|---|
| 设定散落在无数文档里，写着写着就崩 | **起源工作台**：从创世起源→法则→地理→生态→历史→文明→社会现状，引导式分层建档 |
| 改了上游设定，下游全书穿帮 | **世界引擎**：设定变更影响传播 + 跨层一致性校验（战力/时间线/人物-历史冲突） |
| AI 写着写着忘了人设、战力崩塌 | **记忆系统**：设定卡→卷摘要→章摘要→RAG 分层记忆，AI 生成时强制注入世界约束 |
| 各流派写法天差地别，工具一套模板打天下 | **流派引擎**：四维派系模型（频道×世界×手法×基调）+ 可组合/可自定义的派系包 |
| AI 代笔的合规风险 | **人类创作证据链**：编辑轨迹留存、AI 使用记录、平台申报材料一键导出 |
| 云同步失效 = 稿件蒸发 | **数据主权**：Markdown 开放格式 + 本地优先 + git 友好 + 可选 WebDAV/S3 备份 |

## 怎么跑起来

```bash
pnpm install
pnpm --filter @yushu/desktop dev      # Electron + Vite 热更新
```

## 怎么验（四连门禁，缺一项不算完成）

```bash
pnpm test                # 单元/集成测试：1526 例 / 147 文件
pnpm typecheck           # 9 个包 + 2 个应用零错误（内含全量构建）
pnpm --filter @yushu/desktop e2e     # 离线 mock LLM 的端到端全链路，逐条具名断言
pnpm --filter @yushu/desktop exec electron . "--ui-walkthrough=<空目录>"   # 66 步 UI 预演 + 逐步截图取证
# 前端改动的判据：docs/10-前端设计契约.md（令牌 / 中文排版 / 动效 / 键盘可达），由 ui-contract.test.ts 钉住
```

另有 `kill-test`（强杀进程不丢稿实测）与 `perf-test`（百万字性能实测）两个专项探针。
`perf-test` 的**退出码就是性能门禁**（R83 起）：绝对预算未达标 ⇒ 1；相对基线的回退只在报告里点名、
不翻退出码——同一份构建连跑两遍的实测差可达一倍（`cold_to_editable` 3160ms vs 1434ms），
拿个位数毫秒的 ±20% 当结论只会造出一台假红机器。

> **关于 CI**：本仓库**目前没有 CI 流水线**。上述四项每轮在本地实跑，数字与结论写进 `docs/06`。
> M4 的退出条件里包含「规则回归集进 CI」，所以这条空缺是**已知未办**、不是被忽略——
> 我们不用徽章冒充验证。

## 技术基线

Electron 44 + React 19 + TypeScript（严格模式）+ TipTap / CodeMirror 6，pnpm workspace（9 包 + 2 应用，共 11 个 workspace）；
Markdown 正文 + YAML 设定卡为真源，SQLite（FTS5 中文检索 + 向量表）为可重建派生索引；
OpenAI 兼容多模型接入主干（DeepSeek / 智谱 / Kimi / 百炼 / Ollama 等），全程可离线、无遥测、无账号体系；
EPUB / DOCX 已能真出（T5-4 进行中：PDF 要本机装 LaTeX / typst / weasyprint 之一，EPUB 质检要备 EPUBCheck jar）；
平台规则包机制（T4-12）已就绪，五个平台的规则本体还在 M5 填。

## 五条不会妥协的红线

1. **Markdown/YAML 是唯一真源**；SQLite 与 `.yushu/` 都是派生物，删掉可重建。
2. **AI 输出一律候选化**——未经作者确认不写正文、不改设定；采纳必须显式。
3. **密钥永不以明文落盘**：真源只记 `api_key_env` / `key_ref`，密文进 `.yushu/secrets.json`，该目录不入 Git、不入索引、不进快照。
4. **派生层不能变成第二真源**：一致性结论、影响传播提案都落派生区，不写 `reports/`。
5. **确定性优先**：排序走码点序（不用 `localeCompare`），同输入必得同输出。
6. **交付物不带密钥**：项目迁移包里既没有密文库（`.yushu/`），也不允许留下任何疑似明文密钥——写出前剥离、落盘后再复扫一遍。
