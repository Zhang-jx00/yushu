# 真人试跑材料包（T1-24 / A0）

> 用途：为「M1 最小验收场景」招募并执行 3 名真实作者的可用性试跑（新人 / 连载中 / 换工具的老作者各 1）。
> 配套：判定标准与 A0–A6 状态见 `docs/06-M1验收与自查清单.md`（§二 为组织者执行脚本，§六 为汇总记录表）。
> 原则：**只准备环境，不提供操作教程**——A0 要验证的是"陌生用户能否凭产品自身在 30 分钟内完成"，给教程会让结论失真。

## 一、组织者须知（5 分钟读完）

| 事项 | 要求 |
|---|---|
| 参与人 | 试跑者 1 人 + 组织者 1 人（计时、记录、截图，**不提示、不代操作**） |
| 时长 | 30 分钟计时；超时即记录卡点（不必催促），>=35 分钟可温和收尾 |
| 记录方式 | 边做边想边说（出声思维）；组织者记录"停在哪一步 / 第一反应 / 原话" |
| 截图 | 每完成一步截 1 张（命名 `U{n}-step{m}.png`）；卡点处补截 1 张 |
| 干预边界 | 仅当"完全卡死 >5 分钟且无法自行推进"才给最小提示，并记录"何时、提示了什么" |
| 回收物 | 记录表（本文档 §三）、截图、可选的录屏/口述要点；试跑项目目录建议放临时目录、结束后删除 |

## 二、环境准备（组织者一次性完成，试跑当天 2 分钟）

```bash
# 0) 前置：Node ≥ 22（本机 24 实测；`node -v` 自查）；首次 pnpm install 需联网，之后可离线
# 1) 依赖与构建（首次需联网，之后可离线）
pnpm install
pnpm build

# 2) 启动应用（保持窗口运行）
pnpm --filter @yushu/desktop start
```

**LLM 三选一**（决定第 5–6 步"AI 生成"能否进行）：

| 方案 | 适用 | 操作 |
|---|---|---|
| A. 本地模拟（推荐） | 无需 Key/网络，**断网也能跑完全部 9 步** | 另开一个终端常驻：`node scripts/mock-llm.mjs`；在试跑项目里让 AI 面板指向 `http://127.0.0.1:11434/v1`、模型名 `mock-novelist`、API Key 环境变量名留空（或在项目 `config/llm.yaml` 写入 §附录示例） |
| B. 真实 OpenAI 兼容 | 想在真实模型上观察文风 | 设环境变量 `YUSHU_LLM_API_KEY`，AI 副驾面板保持默认主干配置 |
| C. 本地 Ollama | 已有本地模型 | `base_url: http://127.0.0.1:11434/v1`、`model: qwen3:14b`（注意与方案 A 端口冲突，二选一） |

断网复现建议：全程用方案 A → 直接满足"A0 除 AI 调用外离线"并可完整走完；若用方案 B/C，则在第 1–4、7–9 步断网执行，第 5–6 步恢复网络。

## 四、组织者常见问题

| 情况 | 处理 |
|---|---|
| 卡在「存放目录」对话框 | 属正常步骤：提醒用户"随便选一个空文件夹或新建一个"（此提示不计入卡点，但要记录用户是否理解该对话框） |
| AI 面板按钮是灰的 | 检查 mock-llm 是否在跑；AI 开关是否打开；provider 是否显示"可用" |
| AI 报连接错误 | mock 端口是否与配置一致（默认 11434，被占用时换端口并同步配置） |
| 想观察"AI 默认关闭"的行为 | 故意让第 5 步保持关闭，记录用户如何发现并打开——这是 M1 的验收点之一 |
| 导出文件找不到 | 在试跑项目目录 `exports/<书名>-<时间戳>.txt` |
| 用户超过 30 分钟 | 不必打断；记录到达的步骤与总耗时，本项目评判 A0 时以"是否 ≤30 分钟完成 8 步"为准 |

## 附录：本地模拟 LLM 的 config/llm.yaml 示例

```yaml
apiVersion: yushu.llm/v1
format_version: 1
providers:
  - id: local-mock
    kind: openai-compatible
    base_url: http://127.0.0.1:11434/v1
    model: mock-novelist
```

> 写入试跑项目的 `config/llm.yaml` 后，在「AI 副驾」点「刷新/重新载入」即可看到 provider 为「可用」。
> 该 mock 仅监听 `127.0.0.1`、返回固定示例正文、不联网、不写磁盘（实现见 `scripts/mock-llm.mjs`）。
