## 0. 怎么来的：学习清单与"不抄"的边界

调研对象与**取用的东西**（全部只取口径与结构，没有复制任何闭源产品的 CSS、图形、文案或组件代码）：

| 参照 | 学到并写进本契约的 | 明确不学的 |
| --- | --- | --- |
| Material Design 3（Google） | 动效时长要**随距离与变化量变**；退出比进入快；桌面动效比移动更快更简（约 150–200ms）；层级先用色彩与描边表达，阴影只在必要时强调 | 移动端 300ms 级时长（在桌面工作台里显拖沓）；Material You 的动态取色（我们只有一个纸墨色系） |
| Linear / 现代桌面 SaaS 的公开 token 形状 | 令牌**分层命名**（space / radius / elevation / focus / motion 各自一族）；焦点环 = 2px + offset；`--ease-standard` 一条曲线走天下 | 它的暗色底与冷灰蓝配色（御书是纸墨色，改底色等于换产品） |
| W3C clreq（中文排版需求） | 中西之间留约 **1/4 em**（最小挤到 1/8 em）；行首禁则与标点悬挂；句末标点可挤到 1/2 em | — |
| 中文界面排版的通行经验 | 屏幕正文 14–24px 区间、**行高 1.4–1.7**；中文正文**不加 letter-spacing**（会削弱"横排"的提示，被迫加大行高反而更难读）；窄栏两端对齐会把字距拉到 >1em | 段首缩进（Web 界面用段间距分段更整齐） |
| Lucide 图标设计指南（ISC 许可） | 24×24 画布、画布内留 ≥1px、**2px 描边**、round join / round cap / 居中描边 | — |
| Radix / shadcn 的可访问性约定 | **每个可交互元素都要有可见焦点**；`aria-expanded` 归展开器、`aria-pressed` 归切换钮；低对比的 muted 色不许承载关键信息 | Tailwind 的原子类体系（我们是单表 CSS + 令牌，引它等于重写全部样式） |

**图标合规**（先说清，免得被读成"抄"）：`apps/desktop/renderer/src/icons.tsx` 里 11 个标签页图标是
**Lucide v1.55.0 的原件 path 数据**，按 ISC 许可原样使用、文件头保留许可声明、`NOTICE` 登记来源。
这不是"我们设计的图标"，是"我们在用一份开源图标库"——所以规则是**不许改 path**：
要换观感就换选哪个图标，而不是偷偷改坐标（改了就不再是上游那份，署名也失去意义）。

**反参照（这些一律不做，写出来是为了下次有人手痒）**：全站滚动淡入、每个元素都入场动画、
无因果的 bounce/overshoot、视差、装饰性 emoji、超过 3 次/秒的闪烁、"看着高级"的多层阴影。
御书是作者每天坐八小时的工作台，动效的职责是**告诉他东西去哪了**，不是表演。

## 1. 三条不可谈判的原则

1. **一个事实只有一个来源**。颜色、时长、圆角、间距、焦点环宽度都只在 `:root` 定义一次；
   组件里出现 `8px` 这类字面量必须进棘轮计数（只降不升），出现魔法时长直接红。
2. **改画面要有判据，不许"顺手美化"**。每个视觉决定都要能被 DOM/`getComputedStyle` 观察到
   （现有例子：step47 量"展开动画存在中间态且终值等于内容高"；step48 读真实 computed style）。
   观察不到的改动＝没验证过的改动。
3. **键盘与鼠标走同一条路**。任何可点的东西必须可用键盘完成；`li/div onClick` 这类"只有鼠标能碰到"
   的写法在本项目是**债**，已登记数量并逐轮减少（见 §6）。

## 2. 间距令牌（2px 网格）

`:root` 提供 `--space-1 … --space-12`（索引 = 值 / 2：`--space-4 = 8px`）。

R96 普查 `styles.css` 得到 :root 外 **710 处长度字面量**，取值确实铺在 2px 步进上
（4/6/8/10/12/14/16/18/20 都高频）。所以本轮**只把现有取值收进令牌，不顺手把密度压成 4px 基准**——
那会同时挪动上百处间距、版心宽度与滚动区高度，是一次要带截图对照的独立改版，
塞进任何一轮里都会变成"没人能审的改动"。改版时的正确姿势：先量，再改，改完用预演比对。

## 3. 字体与中文排版

- 字体栈：`"Segoe UI", system-ui, "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", "Noto Sans CJK SC", sans-serif`
  ——先系统英文再各家中文无衬线；**不加载网络字体**（离线可用 + 冷启动不背字体下载的账）。
- 字号令牌：`--text-2xs 11 / xs 12 / sm 12.5 / base 13 / md 14 / lg 16 / xl 18`。
  `12.5` 与 `11.5` 是表格里已经在用的两档，**收进令牌但不合并**（合并会在几十张表里同时改变行数与截断）。
- 行高：正文 `--leading-body 1.65`，控件/标题 `--leading-tight 1.35`，大标题 `--leading-display 1.2`。
- 中文正文**禁止** `letter-spacing`；唯一的例外是品牌字样 `.brand`（两字标）。
- 中英混排留 1/4 em 间距：交给 `text-autospace` / `text-spacing-trim`（step48 现场读 computed style 验可用性，
  不支持的浏览器**如实报告**而不是假装生效）。
- 数字列一律 `font-variant-numeric: tabular-nums`（字数、成本、比率要能竖着比）。
- 窄栏不用 `text-align: justify`（会把汉字字距拉到 >1em）；段落靠 `margin` 分段，不做段首缩进。

## 4. 圆角与层级

- 圆角令牌 `--radius-1 … --radius-6` + `--radius-pill(999px)` + `--radius-full(50%)`。
  R96 实测：58 处 `border-radius` 声明**全部走令牌（此前 0 处）**；
  判据是"任何 `border-radius` 声明里不许出现 px 字面量"（`ui-contract.test.ts`）。
- 层级：默认 `1px` 描边 + 极浅阴影。阴影令牌 `--elev-ring / --elev-raised / --elev-overlay`，
  **只有浮层（菜单、对话框、悬浮卡片）允许用 overlay 级**；面板与表格不许叠阴影。

## 5. 动效

| 令牌 | 值 | 用在 |
| --- | --- | --- |
| `--motion-quick` | 140ms | 微反馈：hover 抬起 1px、按下收到 0.98、颜色/描边变化 |
| `--motion-base` | 240ms | 状态切换、小位移 |
| `--motion-slow` | 380ms | 面板揭示（`grid-template-rows: 0fr→1fr` 的真实高度过渡） |

曲线：`--ease-premium cubic-bezier(0.4,0,0.2,1)`（同族通用）、`--ease-enter cubic-bezier(0.05,0.7,0.1,1)`（进场减速）。
四条口径：

1. **退场比进场快**，短距离比长距离快（M3 的桌面口径）；不做"进出对称"的懒设计。
2. 时长**只在 `:root` 出现**。组件里写 `0.2s` 直接红——唯一的三条例外已逐条登记
   （两条进度条 `0.15s/0.2s` 是刻意不同档、`prefers-reduced-motion` 里的 `0.01ms` 是惯用清零值）。
3. **`prefers-reduced-motion: reduce` 必须同时关 `transition` 与 `animation`**——只关前者等于没关（R63 实测踩过）。
4. 展开/折叠只许"从当前真实高度连续过渡到目标真实高度"，箭头旋转 180°，
   **不许文字跳位、不许布局突跳**（这是用户定的硬要求，step47 中途 60ms 采样取证）。

## 6. 焦点与键盘（当前债与判据）

- 焦点：`outline: var(--focus-width) solid var(--accent); outline-offset: var(--focus-offset)`，
  只在 `:focus-visible` 出现（鼠标点击不闪框）。选 `outline` 而不是 `box-shadow` 环，
  因为 Windows 高对比 / `forced-colors` 下 outline 跟系统色走，阴影不会。
- 展开器带 `aria-expanded`、切换钮带 `aria-pressed`、图标按钮带 `aria-label`、纯装饰 `aria-hidden`。
- `--muted` 是低对比色，**不许承载只有它可读的关键信息**（错误、结论、金额必须另有非 muted 的表达）。
- **R96 清点的键盘债**：渲染层里 `onClick` 挂在非原生可交互元素上的位置共 **12 处**
  （11 个 `<li>` + 1 个 SVG `<g>`）。本轮修掉记忆页 2 处，其余 10 处逐轮减少，
  `ui-contract.test.ts` 用**同一套扫描器**钉住"只降不升"，并带绝对下限防"扫描器坏了 ⇒ 零命中冒充全绿"。

## 7. 迁移策略（怎么做才不砸掉现有验收）

1. 令牌先行：先加 `:root` 令牌，**取值照现有分布**，一个像素都不改画面。
2. 逐个族收口：本轮收 `border-radius`（58/58）与壳层控件（topbar / tabs / panel / button / input / chip / badge）。
3. 判据同步：棘轮上限按迁移后的**实测**数字写死，例外按 `选择器=值` 登记（不登记行号——行号每插一段 CSS 就全体漂移）。
4. 每轮都跑预演取证：版心宽度、展开中间态、computed style 这类断言会立刻指出"画面被动过而没人同意"。
