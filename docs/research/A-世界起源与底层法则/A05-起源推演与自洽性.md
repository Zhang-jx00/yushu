# A05-起源推演与自洽性

> 类别：[A-世界起源与底层法则] ｜ 世界构建金字塔层级：[L0 起源层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

起源推演研究"如何从极少数起源事实出发，按依赖关系逐步推导出世界的其余部分，并保证链条自洽"：推演方向（自上而下 top-down / 自下而上 bottom-up / 混合式）、依赖链的显性化（哪条设定以哪条为前提）、自洽性检查（局部设定之间、局部与起源之间是否矛盾）以及"由果溯因"（snowflake 式从核心逐层放大）。它不研究具体某类设定内容（那是 A01-A04 的事），而研究设定之间的**逻辑组织方式**——这正是"从起源构建世界"这一项目宗旨的核心方法论层。与 A06 的区分：A06 关注设定与叙事之间的一致性管理（含文本层），本领域专注设定层内部的推导与校验。

## 2. 核心知识框架

1. **双向光谱与混合式**：r/worldbuilding 与 Scriv the Bard 的梳理——top-down 从大图景（大陆/神系/种族）向下推演，世界观宏大但易空泛；bottom-up 从一个具体地点（角色所在的小镇）向外扩张，其余世界处于"战争迷雾"中，细节扎实但易碎片化。Roleplaying Tips 提出的 Top-Bottom-Up 混合法主张：先定少量顶层"硬约束"，再局部自下而上填充，扩张时回补顶层。GRRM 的"inside out / outside in"自述（托尔金从内部出发，我从外部进入）说明两种路径都是大师路径。
2. **依赖管线**（Azgaar 范本）：地形→气候→河流/生物群系→文化→聚落→国家→宗教→外交→贸易，每层以若干上游层为输入、可独立重生成。把世界观当作"有向无环的生成管线"而非"并列的文件夹"，是本领域最重要的工程化思想。
3. **种子推演**（Serina 范本）：给定一个"种子世界"（初始物种与生态）后按时间推演出纪元化历史，每个纪元的物种都是前纪元的后裔——即设定节点之间存在"祖先→后代"的推导边，而非孤立条目。
4. **单核放大**（雪花法）：Ingermanson 的雪花法用一句话→一段→一页→多页的逐层放大流程，证明"从最小起源推导全局"在故事层同样成立；它与世界层的差别只在推演单元（情节 vs 设定）。
5. **自洽性优先**：Quirkworthy "Be Consistent" 主张无论科幻奇幻，内部一致性是可信度的底线；Fantasy-Hive 的"四 C"（Concept/Constructs/Consistency/Change，概述层面）进一步把"顶层概念与底层细节的调和"列为核心难题——即 top-down 结论与 bottom-up 细节相遇时必须有仲裁机制。
6. **可信度抓手**：Tolkien Society 对"What was Aragorn's tax policy?"的讨论说明：政治经济细节是否经得起追问，取决于上游是否真的推演过——自洽性不是抽象美德，而是"每个下游事实都能回答'这从哪来'"。

## 3. 可转化为产品规则的关键实践

1. 设定即节点+推导边 → 所有设定实体支持 `derived_from[]` 外键，形成全局 DAG（有向无环图）。
2. 分层依赖模板 → 预置 Azgaar 式依赖链模板（常数→自然→社会→文化），新建世界可一键套用。
3. 上游变更级联 → 修改某设定时，沿 DAG 下游遍历并提示所有受影响节点（Azgaar 级联重生成的产品化）。
4. 推演方向标记 → 每个实体标注 `origin_mode`（top-down/bottom-up），统计比例提示"当前世界偏空泛/偏碎片"。
5. 孤儿节点报告 → 无任何 `derived_from` 且非起源层的实体列为"悬空设定"，建议回溯上游。
6. 冲突仲裁记录 → top-down 结论与 bottom-up 细节冲突时强制生成 `ConflictResolution` 记录（改哪边、理由），防止静默修改。
7. 换代谱系 → 纪元/物种/王朝实体支持 `ancestor` 边，渲染演化谱系图（Serina 式）。

## 5. 对御书设计的启示

**数据结构建议**
- 全库实体继承 `derived_from[]` + `origin_mode` + `confidence`（作者定稿/推演草案）；后台维护设定 DAG 表（`edge: {from, to, relation: derives|depends|ancestor}`）。
- `ConflictResolution` 实体：`node_a`/`node_b`/`resolution`/`rationale`/`date`。
- 世界级元数据 `WorldMeta.derivation_depth`：当前 DAG 最长链深度，作为"推演充分度"指标。

**功能建议**
- "推演视图"：以图形展示全库 DAG，点击节点高亮其上游依据与下游派生物；起源层节点金色标识。
- 级联影响面板：编辑设定前预览"改这里会波及哪些节点"，确认后才写入。
- 世界体检报告：输出 孤儿节点数/最长推演链/冲突未决数 三项指标。

**校验规则建议**
- DAG 成环检测（A 派生 B、B 又派生 A）→ 阻断。
- 下游实体引用了已删除上游 → 阻断并建议替代。
- 起源层（A01 常数/创世）变更强制走级联确认流程，禁止静默修改。

**AI 提示词建议**
- 生成新设定时注入其上游链："以下是你必须遵守的上游设定：{chain}；新生成内容需说明派生自其中哪一条。"
- 仲裁冲突时注入双方原文并要求输出结构化 ConflictResolution（含 rationale），由作者确认后写库。

## 6. 领域内子主题备忘（可选）

- "推演预算"概念：为不同粒度设定分配不同的推演深度（与冰山原则衔接）。
- 多人协作下的 DAG 合并冲突（git 式 diff 仲裁）。
- AI 辅助反向解释：为已有细节自动生成合理的上游依据（自下而上回溯）。
- 设定的"置信度生命周期"：草案→已推演→已定稿→已被正文印证。
