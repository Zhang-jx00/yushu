# A07-多世界与位面体系

> 类别：[A-世界起源与底层法则] ｜ 世界构建金字塔层级：[L0 起源层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

多世界与位面体系研究"一个宇宙包含多个世界/位面时的整体架构设计"：位面的类型学（物质位面、元素位面、外位面、过渡位面、半位面、异界）、位面间的组织图式（轮式/轴式/环轨式/树状/网状）、跨位面通行规则（谁可以通行、代价、稳定通道）、以及多世界（多元宇宙）的分支逻辑（平行演化 vs 分叉时间线 vs 独立创世）。它与 A01 的区分：A01 是单个世界的宇宙观，本领域是"宇宙的宇宙"——当创世不止发生一次、或世界之外还有世界时的上层架构；与 A04 的区分：A04 管单条时间/空间制度的参数，本领域管多个时空之间的拓扑与连通。边界内还包括：位面与超凡法则的耦合（不同位面不同规则）、多世界的叙事管理（防设定爆炸）。

## 2. 核心知识框架

1. **轮式图式（Great Wheel）**：D&D 的经典方案——物质位面居中，环绕过渡位面（星界/以太）、内层位面（元素与能量）、外位面（按阵营排列的神祇居所），外围加异域（Far Realm）。Roll20 的 5e SRD 参考将其标准化为五类：Material/Transitive/Inner/Outer/Demiplanes，并提供两种通行方式（plane shift 类法术与传送门）。它的价值在于"每个位面都有存在理由"的结构化思维。
2. **对轮式的批判与替代图式**：Fistful of Wits 批评外位面沦为"阵营的宿舍"；The Dice Society 的 Unaria 方案改为"凡人被永远铭记即成为 Patron、其位面由生前成就对应"——把位面存在性与角色事迹绑定；Flutes Loot 提出"位面如卫星绕物质位面运行、经过时施加影响"的动态模型。教训：图式应服务于本世界的形而上学（呼应 A01），而非照抄。
3. **版本化宇宙观**：Reactor "If I Ruled the Multiverse" 展示了 D&D 各版本宇宙观（Great Wheel/World Axis/Spelljammer/Planescape）的融合思路——宇宙观本身可以像软件一样有版本与迁移方案，这对长线作品的正典管理（A06）是重要参考。
4. **多元宇宙的类型学**：TV Tropes The Multiverse 条目归纳了平行世界的叙事形态（分支时间线/镜面世界/口袋宇宙/穿越规则等）；DC 多宇宙的演化史（Sean P. Carlin 的分析）展示了"岛屿式独立世界被强行缝合为 mega-continuity"的风险——先有分散世界、后补总体架构是行业常态，也提示工具必须支持"后置整合"。
5. **通行规则优先**：Worldbuilding Stack Exchange 与 GiantITP 社区的共同结论：设计多世界先回答通行问题——谁能过、怎么过、代价是什么、单向还是双向；通行规则是位面经济的地基（跨位面贸易/流亡/殖民）。
6. **位面间规则差**：不同位面可有不同的物理常数与超凡法则强度（Feywild 的时间差即典型，衔接 A04 的 TimeFlowRule）；这要求位面实体能"覆写"全局常数。

## 3. 可转化为产品规则的关键实践

1. 位面五类枚举 → `Plane.plane_type`（material/transitive/inner/outer/demiplane/other），强制归类或说明。
2. 位面拓扑图 → 位面之间用有向边连接（`adjacent_to`/`connected_via`），渲染成可拖拽的宇宙图（轮/轴/树自定）。
3. 通行规则必填 → `Portal`/`TravelRule` 实体：`who_can_pass`/`cost`/`direction`（单向/双向）/`stability`（恒定/波动/单次）。
4. 常数覆写机制 → 每个位面可声明对全局 `WorldConstant` 的 override（如时间流速比、重力、魔法浓度），未声明则继承全局。
5. 位面存在性理由字段 → `justification`（此位面为何存在、对应何种形而上学），空白即警告"宿舍位面"。
6. 分支逻辑登记 → `Multiverse.divergence_model`（固定平行/事件分叉/混合），时间线分叉必须引用分叉事件（衔接 A04 纪元）。
7. 正典版本化 → 宇宙观图式支持版本切换（如从轮式迁移到轴式），保留旧版为历史正典。

## 5. 对御书设计的启示

**数据结构建议**
- `Plane`：`plane_type`、`parent_cosmos`、`justification`、`constant_overrides{}`（键值对覆写 A03 的 WorldConstant）、`time_flow_ref`（指向 A04 TimeFlowRule）、`magic_intensity`。
- `Cosmos`（多元宇宙容器）：`divergence_model`、`planes[]`、`topology`（轮/轴/树/网 + 自定义坐标）；`Portal`：`from_plane`/`to_plane`/`who_can_pass`/`cost`/`direction`/`stability`/`known_by`（哪些势力知晓——衔接叙事层）。
- 位面图式版本：`CosmologyVersion`（`schematic`、`status`：现行/历史正典）。

**功能建议**
- 宇宙图画布：位面为节点、Portal 为边，支持轮式/树状/自由布局切换；节点悬浮卡显示覆写常数摘要。
- "位面档案"页：进入某位面写作时，编辑器自动叠加该位面的常数覆写与时间流速（提示条形式）。
- 后置整合工作流：把既有独立世界批量收纳进一个 Cosmos 时，自动检查世界间常数冲突清单。

**校验规则建议**
- Portal 两端位面必须已存在；`direction=单向` 时校验叙事中无反向通过事件。
- 时间流速覆写与全局值相同 → 提示冗余；跨位面场景未找到适用 TimeFlowRule → 引用 A04 校验。
- 位面 `justification` 为空且无关联故事线 → "宿舍位面"警告。

**AI 提示词建议**
- 生成跨位面剧情时注入："两端位面常数：{overrides}；通行规则：{portal rules}；输出中的物理/魔法/时间描写必须符合目标位面覆写值。"
- 生成新位面时要求先答三问：存在理由/与物质位面的关系/通行代价，再生成环境描述。
