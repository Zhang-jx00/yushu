# A03-物理与自然法则

> 类别：[A-世界起源与底层法则] ｜ 世界构建金字塔层级：[L0 起源层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

物理与自然法则指一个虚构世界中"不依赖剧情而恒定成立"的自然常数与规律：地理结构（山系/河流/气候带）、天体与历法的基础参数（本领域的空间侧；时间流速归 A04）、生态与演化规则（食物网/生物群系/物种适应）、以及作者显式修改的现实常数（低重力/双月/逆流河）。本领域回答"世界的地基有多厚"：它决定地图、物产、贸易路线、族群分布等一切下游设定的可信度。与 A02 的区分：A02 研究超自然力量，本领域研究（含被修改的）自然规律；与 A07 的区分：本领域聚焦单一世界内部的自然系统。边界内还包括：地理可信度方法论、生态推演、伪科学参数的声明方式、以及"自然法则→社会后果"的传导链。

## 2. 核心知识框架

1. **分层生成管线**（Azgaar 模式）：Fantasy Map Generator 的生产流程是 heightmap（地形）→ 气候 → 河流/生物群系 → 文化 → 城镇 → 国家 → 宗教 → 外交 → 贸易路线，各层严格依赖上游、且每层可独立重生成。这是"自然法则作为上游参数、社会作为下游派生物"的工程化范本。
2. **地理可信度三原则**（Mythcreants "Crafting Plausible Maps"）：山脉的形成要有板块逻辑（山系走向决定雨影效应与河流走向）；河流从高处流向低处并汇合而不是散开；气候带按纬度与洋流分布——违反这些直觉会被读者"感觉到不对"。
3. **自上而下的生物群系顺序**：r/worldbuilding 社区与 r/mapmaking Wiki 的共识流程是先画山系 → 推导气候梯度（迎风坡/雨影/洋流）→ 再铺生物群系 → 最后放族群与城镇；Quill & Steel 的作者向流程进一步要求"每个地名都要有地理理由"。
4. **生态推演与纪元化**（Serina 范本）：Serina 是一个"种子世界"推演项目——给定初始生态位后按地质纪元推演数千万年演化，形成纪元化编年史；Speculative Evolution Wiki 提供物种设计、食物网、生态位占用的方法论。这把"自然法则"从静态地图升级为动态系统。
5. **显式修改常数**：Wrede 问卷"物理与历史"板块引导作者逐项决定：几个太阳/月亮、重力是否正常、昼夜长度、大陆形状——每项修改都必须登记为"世界常数"，因为它是下游矛盾的最大来源。
6. **自然→社会传导**：贸易路线依赖湖海/山系/首都权重（Azgaar 社区的新贸易路线功能即是证明）；"先自然后社会"是社区一致认可的防矛盾顺序。

## 3. 可转化为产品规则的关键实践

1. 世界常数登记表 → 实体 `WorldConstant`：重力/昼夜/卫星数/大陆数/ magic 密度等逐项登记，新增时提示下游影响。
2. 山系先于气候先于生物群系 → 生成向导强制顺序：地图层未完成前锁定生物群系与族群层。
3. 河流方向校验 → 地图层校验规则：河流必须从高海拔流向低海拔并汇合，逆流即报警。
4. 雨影效应提示 → 在山脉背风侧放置湿润生物群系时警告"疑似雨影错误"。
5. 物产-地理绑定 → 每个地区实体的 `products` 字段校验其与气候带/生物群系的一致性（雪原不产香料）。
6. 纪元时间轴 → 自然事件（造山/大洪水/物种迁移）必须挂到地质纪元轴上，不允许"无时间戳的自然变迁"。
7. 常数变更级联 → 修改世界常数（如双月改三月）时列出所有引用该常数的下游实体（历法/潮汐/宗教节日）要求确认。

## 5. 对御书设计的启示

**数据结构建议**
- 实体 `WorldConstant`：`key`（gravity/day_length/moon_count/...）、`value`、`unit`、`deviation_from_earth`（枚举：相同/修改+说明）、`downstream_refs[]`。
- 地图层实体族 `GeoLayer`：`layer_type`（heightmap/climate/river/biome）、`depends_on[]`、`regen_policy`（上游变更后是否允许独立重生成）、`seed`（随机种子，保证可复现）。
- `Region` 实体：`climate_zone`、`biome`、`elevation`、`products[]`（与 biome 绑定校验）。

**功能建议**
- "地基向导"：按 常数→地形→气候→水文→生物群系 五步引导，每步完成后解锁下一层编辑。
- 图层画布：地图各层可叠加显示、按层隐藏，模拟 Azgaar 的分层体验。
- 生态纪元轴：自然事件沿地质纪元排列，可与人类历史轴并排对比。

**校验规则建议**
- 河流方向校验（如上）。
- 产品-气候一致性校验：`Region.products` 超出该 `biome` 合理物产集合时警告。
- 常数未登记检查：任何实体引用了"双月""低重力"等描述但 `WorldConstant` 表中无对应项 → 提示补录。

**AI 提示词建议**
- 生成地区描述时注入："当前区域 climate_zone={x}, biome={y}, 海拔={z}；物产、植被、动物描述不得超出该生物群系合理范围。"
- 生成历史事件时注入世界常数快照："本世界 moon_count={n}, gravity={g}，涉及天象/物理的描写必须与之相符。"
