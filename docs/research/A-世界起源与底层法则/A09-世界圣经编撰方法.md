# A09-世界圣经编撰方法

> 类别：[A-世界起源与底层法则] ｜ 世界构建金字塔层级：[L0 起源层 + 叙事层交叉]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

世界圣经（world/story bible）编撰方法研究"如何把散落的设定组织成一份可长期维护、可检索、可服务写作的权威文档"：圣经的章节结构（从 Wrede 问卷到 Reedsy 31 页模板的目录学）、强类型模板 vs 弱类型页面的组织范式（World Anvil 与 LegendKeeper 之争）、实体间链接与视图（地图/时间线/关系图）、圣经的演进步骤（随写作增量生长而非一次性编完）、以及中文网文场景的本土化变体（工作流、人物声线圣经）。它是 A 类所有知识领域的"载体层"——前八份文档研究的对象都要装进圣经这个容器。与 A06 的区分：A06 管圣经里的治理规则（一致性），本领域管圣经本体的编撰学与工具形态。

## 2. 核心知识框架

1. **三种工具范式**（工具评测共识）：World Anvil=强类型模板派（25+ worldbuilding 模板、交互地图、时间线，能力强但表单重）；LegendKeeper=弱类型页面派（无限嵌套 wiki 页为核心，地图 pin 与 Chronicle/Calendar 视图作增值，创作流更顺）；Campfire=模块拼装派（Species/Religions/Magic/Languages 等 18 个独立模块按需购买）。三派之争的核心是"结构先行的收益 vs 表单负担的成本"。
2. **引导式建档**（Wrede 问卷传统）：SFWA 的 Fantasy Worldbuilding Questions 用"世界/物理与历史/魔法/民族/社会组织/商业贸易/日常生活"七大板块数百问引导建档——圣经不是空白文档而是问答向导；Reedsy 的 31 页免费模板延续了同一思路并给出现代章节划分。
3. **开源与文件优先形态**：Fantasia Archive 代表免费离线开源的桌面圣经工具；Obsidian 生态（TTRPG 插件群 + vault 结构模板 + 社区教程）证明"markdown 文件 + 双链 + 插件视图（日历/地图/数值块）"是可自持的圣经形态——对御书的文件制最直接相关。
4. **增量生长原则**：Writing Excuses 5.34 与 Scrivener 论坛的警示一致——圣经应随写作生长、服务于正在写的故事；先造巨厦再填内容的"兔子洞"是失败主因。BlurbBio 的"每章回填"与 PlotForge 的系列四习惯给出了增量维护的节律。
5. **职能分层**：Scryla 区分 story bible（叙事事实台账）与 worldbuilding bible（世界运作规则）；一份完整作品圣经通常两层都要，且需显式分隔（对应御书中"设定库"与"事实台账"两个库）。
6. **中文网文变体**：webnovel-handbook（面向 AI agent 的中文网文知识库）提出工作流圣经、人物声线风格圣经等本土形态，并强调"每章承诺-进度-回报-钩子"——中文场景的圣经需额外容纳：境界体系表、势力关系表、更新计划与伏笔台账。

## 3. 可转化为产品规则的关键实践

1. 模板分层供给 → 提供强类型模板（实体+字段）与自由页面两种条目形态，同一库混用（三派折中）。
2. Wrede 板块作目录 → 圣经目录树预置七大板块，每板块挂对应引导问题（问卷即向导）。
3. 渐进披露 → 条目字段分"必填 3 项 + 可扩展"，禁止一上来要求 30 字段全填（防表单劝退）。
4. 实体互链优先 → 一切条目可双链；创建时自动推荐相关条目（同地区/同纪元/同体系）。
5. 增量节律内置 → 章节完成 → 触发回填流（A06）；圣经体检报告每周/每卷输出一次。
6. 视图层附挂 → 地图 pin、时间线、关系图、数值块（statblock）作为条目的可选视图而非独立数据。
7. 中文网文模板 → 预置"境界表/势力表/伏笔台账/更新排期"模板包，与西方模板并列。

## 5. 对御书设计的启示

**数据结构建议**
- 圣经=结构化库+文档层：`Entity`（强类型，schema 注册表驱动）与 `FreePage`（markdown，可挂实体引用）两种条目共存在同一 namespace；`Entity.template_id` 指向可演进的模板注册表（字段增补向后兼容）。
- 模板注册表：`Template {id, entity_type, fields[{name,type,required,group}]}`——`required` 只允许 ≤3 个，其余渐进披露。
- 卷级导出物 `BibleExport`：按板块（Wrede 七板块映射）一键导出为可打印圣经。

**功能建议**
- 双形态编辑器：同库内"实体卡"与"自由页"可互相转换、互相同步引用。
- 建档向导：按七大板块提问式建档，答案直接落到对应实体字段（问卷→数据）。
- 圣经体检：孤儿条目/空必填/未链接/长期未更新四项指标 + 每卷例行报告。
- 中文模板包：境界表（对接 A02 RealmLadder）、势力关系表、伏笔台账（对接 A08）、更新排期。

**校验规则建议**
- 模板演进约束：已实例化的字段不可删除只可弃用（deprecated 标记），防止圣经静默失真。
- 导出完整性：BibleExport 前检查必填缺失与断链引用。
- 双库一致性：事实台账（A06 ContinuityFact）与设定库条目的双向链接缺失时提示。

**AI 提示词建议**
- 条目生成提示词注入模板："请按字段 {required_fields} 输出 JSON，其余字段留空待补；不得虚构必填字段值。"
- 圣经摘要提示词："将以下实体压缩为 200 字速查卡，保留：身份/所属体系/当前状态/与其他实体的关系。"——供写作时上下文注入。
