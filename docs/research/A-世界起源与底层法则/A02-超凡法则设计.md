# A02-超凡法则设计

> 类别：[A-世界起源与底层法则] ｜ 世界构建金字塔层级：[L0 起源层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

超凡法则指世界中一切超越现实物理的力量体系：魔法、灵气、真元、异能、神术、修炼境界等的来源、运行规则、限制与代价。本领域回答四个问题：力量从哪里来（来源）、如何被获取与引导（机制）、边界在哪里（限制与代价）、力量如何反过来重塑社会（后果）。与 A01 的区分：A01 决定超凡力量的"本体论出处"（神赐/天地自然），本领域负责把出处落实为可运行、可自洽、可支撑情节冲突的规则系统；与 A08 的区分：本领域定义规则本身，A08 决定这些规则以何种节奏透露给读者。边界内还包括：硬/软魔法光谱、理性/非理性魔法之分、力量等级（境界）体系、施法组织与社会普及度。

## 2. 核心知识框架

1. **桑德森三定律**（Sanderson's Laws）：第一定律——作者用魔法解决冲突的能力与读者对该魔法的理解程度成正比；第二定律——"限制大于能力"（Limitations > Powers），给角色能做什么不如给角色不能做什么与代价；第三定律——在新增设定前先深挖既有设定（expand, don't add）。三定律共同构成超凡体系最常被引用的设计准则。
2. **硬/软光谱与理性/非理性之分**：Mythcreants 指出硬魔法≠理性魔法——理性指所有咒语遵循同一套形而上学法则（可外推），硬指规则向读者显式公开；一个系统可以理性而保持神秘（如《冰与火之歌》只展示效果不解释原因）。构造理性系统的三问：来源（能量/更高存在/物质/改变现实四类）、获取与引导方式（意志/沟通/配方仪式）、约束条件（理论上限+每个施法环节的失败点）。
3. **折衷式（eclectic）系统的逆向设计**：Mythcreants 另一方法面向民俗式杂烩魔法——先列需求，再选法术功能（塑形/影响目标/供能），做功能-组件匹配，最后整合，使"精灵法杖五芒星"式的传说元素获得内在逻辑而非随机感。
4. **六要素清单**（Fantasy-Faction "Creating a Magic System"）：力量来源、限制与规则（含代价）、施法方式、组织结构、使用者类型、普及程度。"魔法不能是万能解"是总纲。
5. **从现实科学借形而上**：The Dice Society 实操案例用热力学第二定律解释"为何魔法会被繁衍稀释"（人类繁殖最快故完全失去魔法），并把"分支事件"（世界分裂为三个位面）作为魔法总量下降的原因——展示"科学类比+历史事件"双支柱推导超凡法则的做法。
6. **体系化模板**：Campfire 等工具把 Magic 作为独立模块，字段通常含来源/代价/限制/使用者/组织；Wrede 问卷的"魔法与法师"板块则用约 30 个问题覆盖魔法与自然法则的关系、代价、社会态度等，是引导式建档的经典蓝本。

## 3. 可转化为产品规则的关键实践

1. 三定律 lint → 校验规则：检测"用未向读者披露的魔法能力解决关键冲突"的章节标记并警告（第一定律）。
2. 能力必配代价 → 实体校验：每个超凡能力字段 `cost`/`limitation` 至少填一项，缺失则标记"危险：可能沦为万能解"。
3. 来源单选枚举 → 能量/更高存在/物质/改变现实 四类来源必选其一，防止来源互相矛盾。
4. 施法失败点表 → 每个体系维护"环节-失败方式"列表（获取失败/引导失败/释放失败），供情节冲突生成。
5. 硬度滑杆 → 每个体系设 `hardness`（0 软-100 硬）与 `rationality`（0 非理性-100 理性）两个独立滑杆字段。
6. 普及度联动 → `prevalence` 字段（无人会/少数/普遍）触发对社会实体的提示："普遍飞行魔法是否消解了你的城防设定？"
7. 深挖优先提醒 → 新建能力时自动检索同体系既有能力，提示"可否由既有规则外推？"（第三定律）。

## 5. 对御书设计的启示

**数据结构建议**
- 实体类型 `PowerSystem`（超凡体系）：`source`（四类枚举）、`channeling`（意志/沟通/仪式配方）、`hardness`、`rationality`、`prevalence`、`cost_model`（结构化：体力/资源/记忆/寿命/社会代价）。
- 实体类型 `PowerAbility`（能力条目）：外键指向 PowerSystem；字段 `rule_text`、`limitation`、`cost`、`failure_points[]`、`derived_from`（可指向既有能力，表达"规则外推"谱系）。
- 网文向扩展：`RealmLadder`（境界梯）实体——每级含 `name`/`capability_delta`/`bottleneck`/`failure_risk`，支持境界之间的包含关系。

**功能建议**
- "体系画布"：一屏展示 来源→引导→约束 主链与全部能力节点，能力节点可折叠为谱系树（第三定律可视化）。
- 冲突生成器：按 `failure_points` 随机/定向生成"施法失败"情节种子，确保代价真正进入剧情。

**校验规则建议**
- 能力无代价/无限制 → 阻断级警告。
- 同一体系内两个能力违反各自 `rule_text`（如能力 A 声明"魔法不作用于生命"，能力 B 却直接治愈）→ 提示补充"例外规则"字段并要求说明理由。
- `prevalence=普遍` 时检查 C 类社会实体是否声明了相应适应（否则提示"社会未响应力量设定"）。

**AI 提示词建议**
- 生成新能力时注入："体系来源={source}，既有规则={rules}；请优先从既有规则外推；输出必须含 limitation 与 cost 各至少一条，并给出一个失败点。"
- 检查场景草稿时注入第一定律："列出本场景中被魔法解决的冲突，并标注该能力的读者可见度（已解释/未解释）。"
