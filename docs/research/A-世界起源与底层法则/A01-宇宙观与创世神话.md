# A01-宇宙观与创世神话

> 类别：[A-世界起源与底层法则] ｜ 世界构建金字塔层级：[L0 起源层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

宇宙观回答"世界是什么结构、从哪里来"：世界的本体构成（物质/精神/超凡的分层）、宇宙的空间图景（天与地、生者与亡者的疆界）、创世的叙事（谁以何种方式创造了世界、代价与遗留物是什么）。创世神话则是宇宙观的叙事化表达——它既是 L0 层最顶端的设定事实，又是可以"降维"为宗教、历法、禁忌、政治合法性等下游设定的生成源。本领域与 A02（超凡法则）的区分在于：A02 研究力量如何运行，本领域研究力量与结构"从何而来"；与 A07（多世界与位面）的区分在于：本领域聚焦单一世界的宇宙图景与创世叙事，跨世界的整体架构归 A07。边界内还包括：神话母题的分类、神祇与神系结构、创世叙事与信仰体系的派生关系、东方原生资源（以《山海经》为代表）的宇宙图式。

## 2. 核心知识框架

1. **从创世点派生信仰体系**：Fantasy-Faction 的方法主张"从创世故事出发向下设计信仰体系"——创世事件决定神祇谱系，神祇谱系决定教义、仪式与节日，节日又锚定历法与社会节奏。创世神话不是孤立文本，而是整棵设定树的根节点。
2. **神系结构类型学**：Red Ragged Fiend 将神祇分为自然神、概念神、飞升神、外来神等类型，神系结构可分为单一主神、夫妇对偶、多神执政内阁（pantheon）、泛灵万物有灵、无神/不可知等；Inkwell Ideas 强调先设计神与神的关系（敌对/亲缘/职权重叠），再落地为宗教组织，"关系图先于名册"。
3. **形而上学先行**：GiantITP 社区的共识是造神前先回答形而上学问题——神是飞升的凡人、创世的元存在、自然概念的化身，还是被信仰喂养的产物？这个答案直接决定 A02 超凡力量的来源与上限。
4. **避免直接搬运**：The Dice Society 的实践是用既有神话（如道家）作参照系，但改写创世事件的因果链，使宇宙观"原创而非借用"；r/worldbuilding 社区也指出全球创世神话存在共同母题（混沌生序、屠龙/弑原兽、尸体化生万物、大洪水），可重组但需显式标注参照源。
5. **东方原生图式——《山海经》**：刘宗迪的研究指出《山海经》以"山—海—荒"三圈构成空间秩序，把地理、物产、异兽、神祇、方国组织为一个"地理-神话知识体系"；知乎与维基条目则展示了主神/帝系/生态的拆解方式。它是中国网文神话宇宙观（如洪荒流）的源头 schema，为"以方位与圈层组织宇宙"提供东方范式，区别于西方"垂直天界-人间-冥界"图式。
6. **宇宙观与叙事层的接口**：创世神话在故事内通常以"残缺版本"存在——不同宗教各持一套互相矛盾的创世叙述，而真相只有作者知道。这一"作者真相 vs 角色版本"的双层结构是宇宙观类设定的标准形态。

## 3. 可转化为产品规则的关键实践

1. 创世事件作为根实体 → 新建世界时强制/引导创建一条"创世记录"，其余实体可声明"派生自创世记录"。
2. 神祇关系图先于神祇名册 → 神祇实体创建时先画关系边（敌对/亲缘/职权），再填字段。
3. 形而上学问卷前置 → 提供"神的本体类型"单选（飞升者/元存在/概念化身/信仰产物），作为神祇实体的必填枚举字段。
4. 神话母题标注 → 创世记录可挂"母题标签"（混沌生序/尸体化生/洪水），提示 AI 生成时避免与已有母题重复。
5. 宗教派生自创世 → 宗教实体必填"创世叙述版本"引用字段，允许多宗教引用同一创世事件的不同变体。
6. 作者真相与角色版本分离 → 创世记录设 `canon_level`（作者定稿/教会版本/民间讹传）字段。
7. 东方圈层图式模板 → 内置"山海经式"宇宙模板（内圈山/中圈海/外圈荒），与西方垂直三界模板并列。

## 5. 对御书设计的启示

**数据结构建议**
- 新增实体类型 `CosmologyRecord`（宇宙观记录）：字段含 `origin_event`（创世事件链，可多段）、`structure_schema`（垂直三界/水平圈层/其他）、`metaphysics_answer`（神的本体类型）、`canon_level`、`motif_tags[]`。
- `Deity` 实体必含 `ontology`（枚举）、`domain[]`、`relations[]`（边类型：亲缘/敌对/职权重叠/从属）；`Religion` 实体必含 `cosmology_ref`（指向 CosmologyRecord）+ `narrative_variant`（该教派对创世的转述文本）。

**功能建议**
- "创世向导"：按 原初状态→第一因→代价→遗留物 四步引导生成创世事件链，每步产出结构化字段而非纯文本。
- 神祇关系画布：节点为神祇、边为关系类型，创建宗教时自动检查其引用的神祇是否已存在于图中。
- "宇宙观速查卡"：把创世链压缩成一屏卡片，供写作时悬浮查看。

**校验规则建议**
- 无主宇宙观警告：存在 `Deity`/`Religion` 但全库无 `CosmologyRecord` 时提示"建议先建立创世记录"。
- 转述一致性检查：宗教 `narrative_variant` 与作者定稿创世链冲突（如叙述中出现定稿里不存在的神）时给出 diff 提示（允许保留，标记为"有意讹传/待决"）。
- 母题重复提示：新建创世事件母题与已有世界重复率 >80% 时建议差异化。

**AI 提示词建议**
- 生成创世神话时强制注入："基于以下形而上学设定（神的本体={ontology}，空间图式={structure_schema}）生成创世事件链，必须包含代价与遗留物，不得引入设定外的神祇。"
- 生成宗教教义时注入对应 `narrative_variant` 而非作者真相，保证角色视角正确。
