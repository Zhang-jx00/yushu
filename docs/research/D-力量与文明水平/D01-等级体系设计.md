# D01-等级体系设计

> 类别：D-力量与文明水平 ｜ 世界构建金字塔层级：L4 文明层 + 叙事层交叉
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

等级体系设计研究"超凡力量的阶梯结构"：境界如何划分（大境界/小境界/层级命名）、每级的能力范围与代价、升级曲线（升多快、卡多久、瓶颈在哪）、以及体系与世界其他部分（寿元、社会地位、资源）的挂钩方式。边界：只管"梯子长什么样"，不管具体招式功法（D04）、不管梯子之间的战力对比如何防穿帮（D02/D03）、不管升级在剧情里的呈现节奏（D07）。它是修仙/玄幻/西幻升级流的骨架文件——读者对网文最核心的预期"变强"就挂在它上面。

## 2. 核心知识框架

1. **东西方两大范式**。东方修仙谱系有事实标准阶梯：炼气/练气 → 筑基 → 金丹（结丹）→ 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫，每大境常分初期/中期/后期/圆满或一至九层；西幻/ progression fantasy 则更多用职业+等级、魔法环阶（1-9 环）、或自定义称号阶梯。网文语境下"升级流"已是独立流派标签（萌娘百科 Oo 流），系统流则把等级数值化、面板化。
2. **Sanderson 三定律作为体系设计准则**：第一定律——读者对体系理解越深，用它解决冲突越可信，所以境界能力必须"可学习"；第二定律——限制大于能力，每一境的"不能做什么"比"能做什么"更重要；第三定律——先深挖已有境界再新增，警惕境界通胀。
3. **境界属性五元组**：成熟体系的每个境界都应回答——能力范围（能做/不能做）、代价与限制（消耗、副作用、依赖资源）、寿元/生命层次跃迁、突破条件（资源、悟性、机缘、天劫）、社会对应物（此境界在世界里算什么人物）。凡人流代表作《凡人修仙传》的耐读正来自"突破条件+资源稀缺"的持续张力。
4. **升级曲线类型**：匀速型（每章小进步，爽感密但易通胀）、阶梯型（大瓶颈+小台阶，张力足）、天花板递进型（先声明当前界天花板，破界开后有更高层界）。小境界快、大境界慢是通用共识——大境界必须"难"才值钱。
5. **多路线并行**：体修/气修/剑修/法修等平行阶梯可以不同名、不同速，但要预先定义跨路线换算规则（D02 的职责），否则战力对比必崩。

## 3. 可转化为产品规则的关键实践

1. 每个境界建立结构化档案而非一段散文 → 生成"境界体系卡"（见第 5 节 schema）。
2. 大境界突破必须填"突破条件"字段，禁止留空 → 校验规则：突破条件为空的境界标记为"未设计完成"。
3. 寿元字段强制填写 → 支撑"生命层次跃迁"叙事，并与时间线系统（C02）联动校验"角色年龄 vs 境界寿元上限"。
4. 每境界写明"本境界做不了的事"至少 2 条 → 落实 Sanderson 第二定律，供剧情漏洞检查时反查。
5. 境界总数超过 12 个时提示"天花板声明"必填 → 防境界通胀（D03）。
6. 平行路线（体修/法修）各自建阶梯并填写跨路线对照表 → 缺对照表则禁止跨体系战斗情节（联动 D03）。
7. 命名走"每文化一套构词规则" → 境界名生成器按 C09 命名体系出题，避免"练气筑基金丹"全网撞名。

## 5. 对御书设计的启示

### 数据结构建议：境界体系卡 schema
```
RealmCard {
  realm_id, realm_name,            // 境界名（挂命名规则文化包）
  tier_index, sub_stage,           // 大境界序号 + 小境界划分（初期/中期/后期/圆满 或 1-9 层）
  ability_scope: { can: [], cannot: [] },   // 能力范围：至少 2 条 cannot（第二定律）
  cost_and_limits,                 // 代价：消耗资源、副作用、依赖条件
  lifespan,                        // 寿元（数值或区间），联动时间线校验
  breakthrough: { condition, resource, risk, ritual },  // 突破条件/所需资源/失败风险/仪式描写要素
  social_meaning,                  // 此境界在社会中的对应身份（联动 D06）
  cross_track_refs                 // 跨修炼路线对照（体修X层≈气修Y层）
}
```
### 功能建议
- "境界阶梯画布"：拖拽排列大境界/小境界，自动生成等级-寿元-社会地位三轴对照图。
- 命名生成器按文化包批量出境界名候选，一键替换整套阶梯（防全网撞名"练气筑基"）。
- 提供"阶梯模板库"：标准修仙九境、魔法环阶、职业等级、自定义称号流，各带预填字段。

### 校验规则建议
- 境界卡 `cannot` 列表为空 → warning："该境界未定义能力边界（Sanderson 第二定律）"。
- 后一境界 lifespan ≤ 前一境界 → error："寿元未随境界跃迁"。
- `cross_track_refs` 缺失且存在多路线 → error："多修炼路线未建立换算表"。

### AI 提示词建议
- 生成境界体系时强制注入模板："为每个境界输出：能做什么/不能做什么/代价/寿元/突破条件/社会对应物，禁止只写能力清单。"
