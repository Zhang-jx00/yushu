# D05-科技水平与科技树

> 类别：D-力量与文明水平 ｜ 世界构建金字塔层级：L4 文明层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

科技水平与科技树研究"文明层面的技术能力坐标"：当前技术纪元的判定（石器/青铜/中世纪/文艺复兴/工业…）、关键技术的依赖关系与解锁顺序（科技树）、技术对交通/通信/战争/日常生活的约束，以及魔法/超凡力量与技术发展的相互作用（替代、抑制或加速）。边界：纯个人战力归 D01-D04，技术引发的社会制度变化归 D06，本领域管"这个世界的文明整体能用什么工具、还不能用什么工具"。它是防"时代穿帮"（中世纪背景出现印刷厂与火枪混搭无解释）的依据文件。

## 2. 核心知识框架

1. **技术纪元标尺**。GURPS 的 Tech Level（TL0-TL12+）与 Cultural Level 年代表是最成熟的自由标尺：TL0 石器 / TL1 青铜 / TL2 铁 / TL3 中世纪 / TL4 文艺复兴（火药）/ TL5 工业 / TL6 电气 / TL7 信息 / TL8 现代 / TL9+ 近未来；Alternity RPG 的 Progress Levels 是同构体系。标尺的价值不在精确断代，而在"一句话锁定全世界的工具边界"。
2. **技术纪元决定冲突类型**：World Anvil Academy 明确指出技术等级决定了角色如何旅行、通信以及"什么样的冲突可能发生"——没有远程通信就没有跨大陆阴谋的实时协同，没有火药就没有骑士阶层的瓦解。选纪元=选故事。
3. **依赖关系与解锁顺序**：科技树的本质是有向无环图——冶铁依赖采矿与鼓风，火器依赖冶铁与化学，印刷依赖造纸与油墨。创作工具应支持"前置技术未解锁则后置技术不存在"的校验。
4. **魔法与技术的相互作用**：Michael Tedin 指出多数幻想默认"半中世纪+魔法"，作者应有意识地选择而非默认；社区讨论常见两条路线——魔法替代技术（魔法普及导致某技术树停滞）或魔法加速技术（附魔冶金）。关键是为"为什么这里没有/有某技术"写出体系内原因。
5. **防"中世纪停滞"**：历史真实的文明在缓慢进步，编年史（联动 C02/C05）应有纪元间的技术差异；Wrede 问卷的"物理与历史"板块用交通/通信/武器/医疗等问题逐项逼问技术水平。

## 3. 可转化为产品规则的关键实践

1. 每个文明/区域建"技术坐标卡"：TL 等级 + 纪元别名 + 明确可用/禁用技术清单 → 单字段锁定工具边界。
2. 科技树用有向无环图建模：节点=技术，边=前置依赖 → 前置未解锁的后置技术自动标灰并拦截引用。
3. 魔法-技术替代表：列出"魔法承担了哪些现实技术职能"（传讯阵替代电报） → 防止该现实技术被无解释引入。
4. 交通/通信/武器/医疗四维清单入卡 → 对应 Wrede 问卷，作为情节生成时的硬约束注入。
5. 编年史纪元切换时强制填"技术变迁事件" → 防"千年不变的中世纪"。
6. 跨区域技术差（联动 B03 地缘）：贸易路线带来的技术传播事件建模 → 解释边境与中心的工具差异。

## 5. 对御书设计的启示

### 数据结构建议
```
TechLevelCard {
  scope_ref,                  // 挂文明/区域/纪元
  tl_level, era_alias,        // TL 数值 + 本世界纪元别名
  allowed: [], forbidden: [], // 可用/禁用技术清单（工具边界硬约束）
  four_axes: { transport, communication, weaponry, medicine },  // Wrede 四轴
  magic_substitution: []      // 魔法替代的现实技术职能表
}
TechNode {                   // 科技树节点
  tech_id, name, tl_req, prereqs: [],   // 前置依赖（DAG）
  unlocked_by, unlock_year,   // 解锁事件（挂 C02 编年史）
  social_impact               // 引发的制度/阶层变化指针（挂 D06）
}
```
### 功能建议
- "技术标尺"滑杆：拖动 TL 值，四轴清单与允许/禁用技术自动填充为可编辑草案。
- 科技树画布：节点依赖图可视化，拖线建边，环自动检出。
- 与编年史联动：纪元切换时弹出"技术变迁事件"模板（火药传入/印刷术普及…）。

### 校验规则建议
- 正文引用的技术不在 `allowed` 且在 `forbidden` → error："时代穿帮：该技术未解锁（前置缺失：X）"。
- `magic_substitution` 声明的职能被现实技术覆盖且无解释 → warning："魔法替代职能冲突"。
- 编年史跨纪元无 `TechNode.unlock` 事件 → warning："千年技术停滞风险"。
- DAG 检出循环依赖 → error。

### AI 提示词建议
- 场景/情节生成前注入："当前区域 TL=X，可用技术：[清单]，禁止技术：[清单]；魔法替代职能：[清单]。禁止描写清单外技术。"

## 6. 领域内子主题备忘（可选）

- 卡达肖夫标尺（Kardashev Scale）用于高等文明/星际尺度的能量等级声明。
- 蒸汽朋克/柴油朋克等"错位技术树"流派的技术-美学自洽规则。
- 技术扩散速度建模：一项技术从中心到边境的传播年限。
- 军事技术史与战术形态联动（C05 战争史的交叉面）。
