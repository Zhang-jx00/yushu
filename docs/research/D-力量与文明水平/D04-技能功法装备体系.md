# D04-技能功法装备体系

> 类别：D-力量与文明水平 ｜ 世界构建金字塔层级：L4 文明层 + 叙事层交叉
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

技能功法装备体系研究"力量在个体身上的具体载体"：技能/法术/招式的获取与成长规则，功法/心法/职业的品阶与传承结构，装备/法宝/丹药的品级、稀有度与产出逻辑，以及三者如何叠加到境界之上参与战力计算。边界：D01 管"人的阶梯"，本领域管"人身上的东西"；比较与防崩规则归 D02/D03。在系统流语境下，这一层就是"面板"——技能栏、背包、装备栏的三件套。

## 2. 核心知识框架

1. **稀有度分层是成熟工业标准**。D&D 体系将魔法物品分六档：普通/非普通/稀有/极稀有/传说/神器（Artifact），每档有明确的产出节奏与战力预期；SRD 还规定物品创造与基础价格挂钩的硬规则（造价决定耗时与成本）。这套"品级×获取门槛"结构可直接迁移为法宝/丹药/功法品阶。
2. **LitRPG 的多层系统设计**：优秀的升级系统不是单一等级数字，而是多层并行——等级/职业/技能/天赋/装备各自有成长曲线与交互关系（Abnormal v Average 的系统构建综述）。技能应有熟练度成长，装备应与技能产生协同或冲突。
3. **限制与代价是品阶的真正含义**：Sanderson 第二定律在此层的体现是——高品阶不是"数值更大"，而是"限制更少但代价更重"。Jed Herne 的限制清单（消耗/需求/副作用/获取门槛）同样适用于技能与功法设计。
4. **物品的品牌化与故事性**：Roleplaying Tips 提出"给魔法物品做品牌"——命名、来历、传承谱系让物品成为叙事资产而非数值道具；命名神器（如轩辕剑、诛仙四剑）自带故事钩子。
5. **功法=技能的"元层"**：东方体系的功法/心法本质是技能树的根——决定能学什么技能、学多快、有无副作用；品阶应同时约束"技能上限"与"突破资格"（联动 D01 的突破条件）。

## 3. 可转化为产品规则的关键实践

1. 技能/功法/装备三类实体统一建模为"力量载体卡"，共用品阶字段 → 单一品阶枚举（凡品→天品 或 稀有度六档），跨类可比。
2. 每件装备登记 稀有度 + 获取来源 + 持有者变更史 → 防止"传说级法宝"批量出现、防止物品凭空转移（联动 D03 事件日志）。
3. 每个技能登记 学习条件/熟练度成长/冷却或消耗 → 支撑"成长感"与战斗表现一致性。
4. 功法卡登记 品阶/技能上限/突破资格/副作用 → 与 D01 境界卡双向引用。
5. 品阶分布统计：全书已出场物品按稀有度画直方图 → 传说级占比超阈值报警（防通胀）。
6. 装备与技能的"协同声明"：套装/共鸣/反噬关系显式建档 → 战斗生成时自动检查组合合法性。
7. 物品命名走命名规则文化包 + 来历模板（制作者/年代/流传） → 一键生成有故事的物品档案。

## 5. 对御书设计的启示

### 数据结构建议：力量载体卡（技能/功法/装备统一 schema）
```
PowerCarrierCard {
  carrier_id, kind: "skill|method|equipment|elixir",
  name, tier,                       // 品阶：统一枚举，跨类可比
  learn_or_wield_condition,         // 习得/驾驭条件（境界门槛、体质、代价）
  effect: { can: [], cannot: [] },  // 效果与限制（第二定律：cannot 至少 1 条）
  cost_or_side_effect,              // 消耗/冷却/反噬
  growth: "熟练度|进化路线|无",      // 成长曲线
  provenance: { creator, era, lineage },  // 来历：品牌化三件套
  holders_history: [],              // 持有者变更史（挂事件日志）
  synergy: { combos: [], conflicts: [] }  // 协同/冲突声明
}
```
### 功能建议
- "品阶直方图"面板：全书力量载体按品阶/类别分布统计，通胀预警。
- 装备-技能组合器：拖拽角色身上的载体卡，实时提示协同加成与反噬风险，输出到战斗生成上下文。
- 物品来历生成器：命名 + 制作者 + 流传史一键成稿，直接可进正文。

### 校验规则建议
- 效果限制 `cannot` 为空 → warning："该力量载体未定义边界（第二定律）"。
- 传说级及以上物品无 `provenance.lineage` → warning："神级物品缺少来历（叙事资产流失）"。
- 装备驾驭条件与持有者当前境界不匹配且无越级杠杆声明 → error（联动 D02）。

### AI 提示词建议
- 生成宝物/功法桥段时注入模板："输出品阶、习得条件、效果与至少一条限制、代价、来历三件套；禁止无限制的强力新物品。"
