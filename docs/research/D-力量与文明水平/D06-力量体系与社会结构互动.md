# D06-力量体系与社会结构互动

> 类别：D-力量与文明水平 ｜ 世界构建金字塔层级：L4 文明层 + L5 社会现状层交叉
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

力量体系与社会结构互动研究"力量如何沉淀为阶层、阶层如何固化为制度"：超凡力量（境界/魔法/科技）与社会阶层的映射关系、力量机构的组织形态（宗门/法师塔/骑士团/超管局）、力量资格的法律与伦理管制（谁能修炼、禁忌力量如何处置）、以及力量流动性对社会稳定的影响。边界：D01-D05 管"力量本身"，本领域管"力量长成社会后的样子"——它同时触及文明层（制度设计）与社会现状层（当下实然状态），是"为什么这个世界这样运转"的核心解释层。

## 2. 核心知识框架

1. **力量即阶层的放大器**。Michael Schultheiss 的分析指出：魔法精英会加固既有等级制，魔法还会复利式放大阶级与财富壁垒（资源、教育、师承都被力量垄断）。推而广之：任何超凡力量的获取门槛（天赋/资源/机缘）直接决定它是"流动通道"还是"种姓墙"。
2. **力量定义身份：魔法贵族制（magocracy）**。Giant in the Playground 社区的经典设计：以"能施放几环法术"定义社会头衔——能施三环即为贵族阶层。这正是东方体系"金丹真君/元婴老祖"称谓制度的西方镜像：境界头衔=爵位。
3. **力量机构的类型学**。Tropedia 的 Magical Society 条目与 Mythic Scribes 的组织讨论归纳了法师组织的常见形态：法师行会（管制+认证）、学院（再生产）、隐秘结社（非法力量）、教会法团（神授力量）。宗门=行会+学院+武装三位一体的东方变体。
4. **底层如何用力量**：r/worldbuilding 的讨论显示，平民阶层往往只能接触"物质性/元素性"的粗浅力量——力量分层会在日常生活（打铁、耕作、医疗）留下痕迹，而不只在战斗里。这是"力量渗透社会"最容易被忽略的写作面。
5. **GRRM 的政治经济学视角**：托尔金学会记录的"Aragorn's tax policy"之问提醒——力量结构必须落到税赋、土地、兵源等具体制度上才可信；Art of Worldbuilding 则给出阶层设计的操作面：每个阶层要有独特的思维方式、衣着、行为与需求。

## 3. 可转化为产品规则的关键实践

1. 建立"力量-阶层映射表"：每个力量档位对应一组社会身份/权利/义务 → 结构化映射规则（见第 5 节）。
2. 每条映射规则登记"流动性"字段：通道开放/半开/封闭 → 决定主角"逆天改命"是否有体系依据。
3. 力量机构建档：组织类型+管制权限+入会门槛+惩戒手段 → 与 C11 社会结构、C08 宗教组织联动查重。
4. 底层渗透清单：每个力量体系列出"凡人/底层如何使用它"≥3 项 → 防力量只在战斗场出现的悬浮感。
5. 禁忌力量管制规则：哪类力量违法、执法机构、刑罚 → 支撑反派动机与法律冲突情节的合法性。
6. 制度后果推演：新增力量档位时自动提示"将产生哪些制度需求"（考核、登记、婚姻、继承） → 检查表式提示词。

## 5. 对御书设计的启示

### 数据结构建议：力量-阶层映射规则
```
PowerClassMapping {
  power_ref,                    // 挂 D01 境界 / D05 TL / D04 品阶
  class_tier,                   // 对应社会阶层（贱籍/平民/士绅/贵族/超凡阶层）
  titles: [],                   // 头衔称谓（境界=爵位）
  rights: [], duties: [],       // 权利与义务（佩剑权/免税/兵役/贡赋）
  mobility: "open|semi|closed", // 流动性：升级通道开放度
  institutions: [],             // 管制机构引用（挂组织实体）
  taboo_rules                   // 禁忌力量与刑罚声明
}
```
### 功能建议
- "力量金字塔"视图：左轴境界阶梯、右轴社会阶层，映射线可视化，未映射档位高亮。
- 机构档案模板：预置宗门/法师塔/骑士团/超管局四类骨架字段（权限/门槛/惩戒/与皇权关系）。
- 与 C11/C12 联动检查：映射表中的权利（免税、土地）必须在经济与政体档案中有承接实体。

### 校验规则建议
- 某力量档位无对应 `class_tier` → warning："该境界未沉淀社会身份（悬浮力量）"。
- `mobility=closed` 却出现底层快速跃升情节 → warning："跃升需机缘/杠杆声明（联动 D02）"。
- `taboo_rules` 为空且存在"魔功/禁术"元素 → warning："禁忌力量无管制制度"。
- 底层渗透清单 <3 项 → warning："力量未渗透日常生活"。

### AI 提示词建议
- 生成宗门/朝堂场景时注入映射表："当前角色境界 X 对应身份 Y、权利 Z、受限 W；写其对下位者的言行须体现阶层差异。"
