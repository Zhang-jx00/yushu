# I04-节奏与注水控制

> 类别：I-网文连载工程 ｜ 世界构建金字塔层级：工程层 · 连载工程
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究连载正文的"节奏质量"与"注水（内容稀释）"的可检测化：什么是注水、为什么产生、如何在文本层与工程层被量化识别、诊断与干预。边界划分：F02 管四级骨架（卷-章），F03 管场景与节拍（目标-冲突-结果），G05 管爽点与情绪供给，F06 管冲突升级——本领域不重复设计结构，只做"节奏体检"：把"这段是否推进""信息是否新增""是否重复""读者是否会跳读"变成可计算的指标与 lint。与 I01 的分工：I01 管章节实体与更新节奏（字数/断章/存稿），本领域消费其字数分布与章纲数据，产出"注水报告"；与 I08 的分工：I08 出码字统计与体检报告框架（对应 docs/01 §4.6 作者刚需套件），本领域提供节奏相关检查项与阈值。

## 2. 核心知识框架

1. **注水的三种成因**。①日更字数义务：为凑 4000~6000 字/日与全勤档位，用重复描写、无意义对话、拖沓支线填量（蓝媒热评指出作者"为追求日更字数、维持账号热度，被迫压缩内容打磨与细节查证的时间"）。②AI 批量生成：番茄 2026-07 治理公告显示，拒签 AI 生成/空洞水文类 16 万本、处置水文违规近 5.4 万本，问题特征为"行文机械生硬、语言模板化、排版错乱"，平台侧把"通顺但空洞"的内容称为数字泔水。③能力性注水：知识储备与生活阅历不足，只能以套话与同质套路填充。
2. **注水的五种表现**。①为凑字数：空洞描写与心理活动来回刷；②支线拖延：与主线无关的人物/事件硬插入；③重复解释设定：同一世界观信息反复复述；④空转对话：只调侃不推进信息；⑤无推进的日常：天气/吃饭/闲聊等无目标场景。中国作家网以"内容相互模仿'灌水'严重"概括同类问题。
3. **可量化的节奏指标**。场景推进率（每场景是否推进主线/支线）、信息密度（新增有效信息/千字：新实体、新事实、状态变化、承诺与兑现）、重复度（段落级近似重复、句模板重复、高频套话占比）、动作频率（描写/动作比）、张力递进（每场景是否抬升赌注或重复同一情绪拍）。
4. **检测原理（工程范式）**。生产级节奏分析器（AI Pacing Analyzer）的做法可借鉴：先做场景切分（scene segmentation），再对每场景抽特征——句长变化、对话/叙述比、动作频率、场景长度、张力递进——据此标注"平淡中段/信息倾倒/重复场景/超长描写"；其中"读者会跳过三段而不错过任何内容"即为注水的操作性定义。
5. **两类节奏失衡**。反向两个极端：连续多章无爆点（压抑洼地/期待断层，直接导致弃书）与连续爆点疲劳（"连续 10 章纯战斗""连续 5 章同一 Strand"致审美疲劳）。社群检查表把阈值写死为可执行项：连续 500 字纯描写→删除或压缩；铺垫超 2000 字未进入冲突→立即加速；纯过渡章→至少插入一个小爽点。
6. **两类人工测试**。"删掉不影响理解"测试：逐段删除后若理解与情绪强度不变，则该段为可删注水；"跳读测试"：读者（或作者自评）自然跳过却不错过情节的部分即为掺水（阅文作家专区观点："如果看文的时候有自动跳过或者觉得没意思不想看的部分，那部分可能就是掺水了"）。两者是量化指标的人工校准基线。
7. **节奏基准参考值**。日更单章宜含一个完整的"压抑—释放"情绪单元；每 10 万字左右设小高潮、每 20~30 万字设大高潮（施俊杰）；单章约 3000 字、情节相对完整、语言浅白平实、可短时间"扫"完（光明网）。这些构成默认阈值基线，可按题材与基调覆写。

## 3. 可转化为产品规则的关键实践

1. 场景推进标注 → 每场景 frontmatter 增 `advances: [main|sub-<id>|none]`，`none` 场景进入"空转场景"清单（联动 F03 场景卡）。
2. 场景推进率统计 → 卷/篇章级"推进场景占比 = 有 advances 的场景数 ÷ 总场景数"，低于阈值提示。
3. 信息密度计算 → 用实体抽取（人物/地名/物品/新概念）+ 状态变化 + 承诺事件计"新增有效信息数 ÷ 千字"，输出逐章信息密度曲线（联动 I08）。
4. 重复检测 → 段落级 MinHash/SimHash 近似去重 + 句模板聚类 + 高频套话词表，命中即列入"重复段落"清单。
5. 删段测试辅助 → AI 逐段生成"删除后可读性"判断，给出"可删段"建议清单（人工确认，不自动删）。
6. 跳读测试 → 以"段落信息增益"近似：删段后剧情摘要不变则该段可跳，输出"跳读热区"叠加条。
7. 节奏失衡诊断 → 复用 G05 情绪事件台账，检测"连续 N 章无 release"（压抑洼地）与"连续 M 章高强度"（疲劳区），两侧都出报告。
8. 章节字数分布联动 I01 → 字数骤高章节自动触发注水体检（超均字 30% 且信息密度低于均值）。
9. 体检报告落点 → 检测项统一进入编辑器 lint（单章/选中范围）与项目体检报告（全书），与 I08 共用报告框架。
10. 阈值外置 → 推进率下限、字数上限、重复相似度等阈值进派系包/项目配置，可按基调覆写（与 G06 派系包同构）。

## 5. 对御书设计的启示

**数据结构建议：场景推进标注（frontmatter 草案）**

```yaml
# chapters/vol1/ch-012.md
id: ch-012
scene_units:
  - id: sc-012-1
    advances: [main]          # main | sub-<线id> | none（空转）
    goal: 潜入藏经阁取回残页   # 场景目标（F03）
    conflict: 巡夜弟子盘查
    outcome: partial          # yes | no | partial（价值翻转）
    tension_delta: +2
  - id: sc-012-2
    advances: [none]
    outcome: no
pacing:
  info_density: 3.1            # 新增有效信息/千字（引擎计算）
  repeat_hits: 2               # 命中重复段落数
  can_delete_ratio: 0.18       # 建议可删段占比
```

**数据结构建议：节奏诊断报告（并入项目体检报告的 pacing_report）**

```yaml
pacing_report:
  scope: {type: volume, ref: vol1}     # project | volume | chapter
  metrics:
    advance_rate: 0.62                 # 推进场景占比
    info_density_avg: 4.0
    info_density_min_ch: ch-047
    repeat_paragraph_count: 12
    high_freq_terms: [{term: 冷笑一声, count: 41}]
    max_pure_desc_run: 780             # 最长连续纯描写字数
    no_release_streak_max: 4           # 最长无释放连章数
    high_tension_streak_max: 8         # 最长连续高强度章数
  findings:
    - {rule: pacing-no-advance, level: warn, at: [ch-045, ch-046]}
    - {rule: water-repeat-paragraph, level: info, at: ch-047}
    - {rule: pacing-fatigue-burst, level: info, at: [ch-060, ch-067]}
```

**功能建议**

- 节奏体检器（编辑器 lint）：写作时实时显示选中范围的推进率/可删段占比/重复命中，gutter 标"空转场景""可跳段"。
- 节奏仪表盘：逐章信息密度曲线 + 推进率柱状 + 重复热区叠加，异常章一键跳转；与 I08 码字统计共用报表页。
- "删段/跳读"双测试工具：对选中范围生成"可删段清单"与"跳读热区"，支持逐条采纳（AI 建议 + 人工确认，不自动改写）。
- 注水预警：字数骤高章自动进入注水体检，体检报告按卷汇总"注水指数"（联动 I01 字数分布）。
- 阈值配置面板：项目级与派系包级两处阈值，允许按基调覆写（甜宠放宽、黑深残收紧）。

**校验规则建议**

- `pacing-no-advance`：连续 ≥3 个场景 `advances` 仅含 `none`，或单章推进场景数为 0 → warn。
- `pacing-no-release`：连续 >N 章未登记 release 事件（男频默认 N=3，可覆写） → warn（复用 G05 台账）。
- `pacing-fatigue-burst`：连续 >M 章 intensity 均 >+4 → info"爆点疲劳，建议穿插缓冲"。
- `water-repeat-paragraph`：段落近似相似度 >0.8 → info，列出对照段落。
- `water-high-freq-term`：套话词频超阈（如"冷笑/冷哼一声"每千字 >3 次） → info。
- `water-pure-description`：连续纯描写 >600 字 → info；>1000 字 → warn。
- `water-info-density-low`：单章信息密度 < 全书均值 ×0.6 → info。
- `water-word-count-spike`：单章字数 > 全书均值 ×1.3 且信息密度低于均值 → info（联动 I01）。
- `pacing-deletable-scene`：场景 `outcome: no` 且 `advances: [none]` → info"可考虑整场删除/压缩"。

**AI 提示词建议**

- 「注水体检」：输入章节正文 + 世界实体表，输出场景切分表（目标/冲突/结果/推进线）、信息密度估算、重复段落清单与可删建议，仅给证据不改写。
- 「压缩改写」：对指定可删段给出 2~3 个压缩版本，标注删减字数与保留的关键信息，供整段或局部采纳。
- 「节奏诊断」：输入连续 10 章摘要 + 情绪事件台账，判断处于"压抑洼地/爆点疲劳/节奏正常"，给出下一章推进与释放建议（注入 G05 相位）。
