# J11-长文本连贯生成

> 类别：J-AI与LLM工程 ｜ 世界构建金字塔层级：工程层 · AI 工程
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"用 LLM 生成远长于单次上下文窗口的连贯正文"的工程方法：单次生成长度上限与分段策略、按节生成 + 递归重注入、计划—生成—修订（plan-draft-revise）循环、百万字项目的一致性策略（分层摘要 + 关键设定常驻）、上下文滑窗与"前情回顾"生成、长程连贯的量化评估，以及与 I02 三级大纲的分层对接（细纲→节→段）。边界划分：J03 管记忆系统与上下文组装（分层摘要 / RAG / 注入预算），本领域管"长文生成如何分段与编排循环"；J04 管 prompt 工程与结构化输出，J10 管评测方法；I02 管大纲数据结构，本节只对齐其层级。核心问题：如何把"百万字一致性"这个宏大目标，分解为可执行、可审计、可人工介入的分段生成与重注入流程。

## 2. 核心知识框架

1. **单次生成长度上限与分段**。LongWriter 指出当前 LLM 单次输出约 2000 词即到顶，更长文本必须"分段规划 + 逐段写作"（AgentWrite 的 plan→write 管线），并对每段做字数控制。这条学术结论被 docs/01 §4.5 直接采纳为"按节生成、字数分档"。
2. **分层计划与递归重注入**。Plan-and-Write 奠定了"先规划故事线、再逐段写作"的范式；Re3 用"计划 + 递归重注入 + 重排序 + 修订"把长篇连贯性提升 14~20%；DOC 用分层细纲约束"何时发生什么"；DOME 用动态分层大纲 + 记忆增强，允许"边写边改大纲"。四者共同指向：**计划层要显式、可维护，并在每次生成时重新注入**。
3. **记忆与计划状态**。RecurrentGPT 用自然语言短期/长期记忆 + 每步更新计划，实现人机协同的超长生成；Anthropic 上下文工程提出 context rot（上下文变长后召回劣化）、及时检索、压缩、笔记式记忆等策略。
4. **一致性失败模式**。长文生成易出现"自我矛盾的设定 / 人物 / 世界规则"（Consistency Bugs 研究），说明连贯性不能只靠生成长度，必须有独立的生成后一致性审查层。
5. **上下文分层与滑窗**。稳定前缀常驻（世界总纲 + 风格卡）+ 分层摘要（卷摘要 / 章摘要 / 事实级带出处）+ 最近原文滑窗 + 按别名/提及触发的设定注入；稳定前缀同时服务于 Prompt Caching 的 KV 复用（J01/J03）。
6. **长程连贯的评估**。LongBench 提供 8k–2M 的长上下文基准；工程侧可计算跨章实体一致率、时间线冲突率、设定违背率等可量化指标。
7. **与大纲的分层对接**。总纲→卷纲→章纲→节→段的多级扩写，每层人工确认后再进下一层（I02 分层控制），生成粒度与大纲节点一一对应。

## 3. 可转化为产品规则的关键实践

1. 单次输出上限检测 → 目标字数超过阈值（约 2000 词）时强制切分，提示"已按节拆分"（引 docs/01 §4.5）。
2. 按节生成 + 递归重注入 → 每节生成后先更新该节摘要与计划状态，再作为下一节注入上下文，而非一次性拼接。
3. 计划—生成—修订循环 → 每节走"计划候选→正文草稿→一致性修订"三步，修订只改问题句不重写全节。
4. 分层摘要常驻策略 → 世界总纲 + 风格卡置于稳定前缀；卷/章摘要滚动更新；最近原文保留固定窗口（J03）。
5. 前情回顾生成 → 长间隔续写前自动生成"前情回顾"短段，并允许作者修正后回库。
6. 一致性审计 → 生成后跑实体/时间线/设定三类校验，产出审查报告，问题定位到节与句。
7. 大纲分层对接 → 扩写入口固定在"细纲→节→段"，每级可单独生成/修改（I02）。
8. 上下文预算护栏 → 组装前按预算裁剪（保留常驻层、压缩摘要、缩减窗口），超预算时提示并给出裁剪建议。
9. 长文评测埋点 → 记录跨章实体一致率、时间线冲突率，形成项目级"连贯性仪表"。
10. 成本优化 → 摘要/审计等辅助任务用小模型，正文用旗舰；稳定前缀对齐缓存（J01/J02）。

## 5. 对御书设计的启示

**数据结构建议：分节生成计划 schema（对接 I02 细纲）**

```yaml
# outline/generation-plan.yaml —— 一章的分节生成计划
plan:
  chapter_ref: ch-012
  strategy: plan_draft_revise      # 计划→草稿→修订
  budget: {context_tokens: 6000, reserve_out: 1200}
  sections:
    - id: sec-01
      goal: 主角夜探藏经阁               # 取自 I02 章纲五要素
      word_target: 800
      outline_ref: co-012#part1
      status: drafted          # pending | generating | drafted | revised
    - id: sec-02
      goal: 遭遇守卫、初次交手
      word_target: 900
      status: pending
context_assembly:                  # 每次生成前的重注入顺序（稳定前缀在前）
  - {layer: world_core, mode: always, tokens: 900}      # 世界总纲常驻（J03）
  - {layer: style_card, mode: always, tokens: 300}      # 风格卡常驻（J12）
  - {layer: volume_summary, mode: rolling}
  - {layer: chapter_summary, mode: rolling}
  - {layer: plan_state, mode: always}                   # DOME 式"当前计划/待完成节"
  - {layer: entities, mode: mention}                    # 按别名/提及触发（J03）
  - {layer: recent_text, mode: window, tokens: 2000}    # 最近原文滑窗
recap:
  enabled: true
  text: "前情回顾：……"          # 长间隔续写前生成，可被作者修正回库
audit:
  entity_consistency: 0.98       # 跨章实体一致率
  timeline_conflicts: 0          # 时间线冲突数
  setting_violations: []         # 设定违背清单（定位到 section_id）
```

**上下文组装顺序（稳定前缀 → 动态层 → 最近窗口）**

```text
[世界总纲][风格卡]  ← 稳定前缀，命中缓存
[卷摘要][章摘要][计划状态]  ← 滚动更新
[按提及触发的实体卡]  ← 动态插入
[最近原文滑窗 2000 tok]  ← 紧贴生成点
```

**功能建议**

- 分节生成面板：按节列表显示 goal/字数/状态，可单节重生成或手工改写后再继续。
- 上下文预览器：可视化本次实际注入的各层与预算占用，标出被裁剪项（沿用 docs/01 §4.3 调试要求）。
- 前情回顾卡片：长间隔续写前弹出可编辑的回顾段，确认后写入章摘要。
- 连贯性仪表：项目级展示实体一致率、时间线冲突率趋势（联 I02 偏差面板）。
- 一键一致性审查：生成后产出报告，问题跳转到对应节与句。

**校验规则建议**

- `longgen-single-shot-overlimit`：单次目标字数 > 阈值（约 2000 词）却未切分 → error。
- `longgen-plan-ungated`：分节计划未经人工确认即批量生成全部节 → warn。
- `longgen-context-overbudget`：组装后 context_tokens 超预算且未裁剪 → error。
- `longgen-summary-missing`：已写完章节无章摘要 → warn（阻断后续重注入质量）。
- `longgen-entity-conflict`：新节与既有实体卡冲突（战力/身份/关系）→ error（联 D03/E03）。
- `longgen-timeline-conflict`：节内事件与编年史时间线矛盾 → error（联 C02/F05）。
- `longgen-setting-violation`：正文违背世界总纲/超凡法则 → error（联 A06）。
- `longgen-recall-stale`：引用的摘要版本早于正文最新版 → info，提示刷新。
- `longgen-prefix-unstable`：稳定前缀层被频繁改写导致缓存失效 → info（成本提示，联 J02）。

**AI 提示词建议**

- 「分层扩写」：细纲（I02）→ 节计划（本 schema）→ 单节正文，每层确认后再进下一层。
- 「递归重注入续写」：注入"世界总纲 + 当前计划状态 + 章摘要 + 最近原文窗口"，要求"只写下一节、遵守待完成目标、不提前兑现后续节"。
- 「前情回顾」：输入最近 N 章摘要与在册伏笔（F08），生成 ≤200 字回顾，供上下文置尾。
- 「一致性修订」：输入草稿 + 审查报告，输出最小改动补丁（只改问题句），并标注改动理由。
- 「连贯性体检」：跨章比对实体属性与时间线，输出冲突清单与置信度。
