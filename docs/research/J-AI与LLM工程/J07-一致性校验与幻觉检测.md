# J07-一致性校验与幻觉检测

> 类别：J-AI与LLM工程 ｜ 世界构建金字塔层级：工程层 · AI 工程
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究对 AI 生成文本的"产出后校验"：把生成内容与结构化设定库、出处记忆比对，检测事实、人物、时间线、战力、称呼、地理/设定等维度的矛盾，并对"无出处的断言"（幻觉）打标；最终产出机器可读的审查报告（规则 id + 文本区间 + 证据 + 修复建议）与人可读的高亮界面。边界划分：规则本体来自各领域（D03 战力防崩塌、F04 视角与人称、E07 声线一致性、F08 伏笔生命周期），本领域只管"校验引擎怎么跑、报告长什么样、误报怎么压"；生成时的约束注入归 J03/J05，抽取产出入库归 J06，本领域是**生成后的独立校验层**（S4 关键发现：一致性需要独立校验层）。与 J15 联动：校验发现的问题直接进入"局部采纳"修复流。

## 2. 核心知识框架

1. **校验维度分类**。事实（与设定库比对）、人物（性格/能力/称谓，E07）、时间线（内部数字刻度与多历法，F05）、战力（D03）、称呼漂移（E07 称呼表）、地理与设定冲突（B/A 类）、视角纪律（F04 一场一人称）、伏笔（F08 无 plant 的 payoff）。
2. **幻觉检测的本质是"出处比对"**。把生成文本拆成**原子事实**（FActScore 范式），逐条判断是否有可靠知识源支撑；知识源在御书里 = 结构化设定库 + 带出处的事实级记忆（J03）。无支撑的断言即"无出处断言"。
3. **零资源采样一致性检测**。SelfCheckGPT：黑盒模型多次采样，模型"知道"的内容样本间一致，幻觉事实则发散/自相矛盾——不需要外部库即可给事实性打分，适合评估"设定库里没有"的新造设定。
4. **事实级（知识图谱）检测**。FactSelfCheck 把长文转成 `(head, relation, tail)` 三元组，算事实级幻觉分，比句级更可解释、更易定位修正；Agent-as-Judge 用角色知识图谱（CKG）给出"缺失/错误事实"的可操作修正建议。
5. **错误分类学与证据链**。ConStory-Bench 定义五类一致性错误 + 19 个细分子类，并给出"类别引导抽取→矛盾配对→证据链→JSON 报告"的四阶段检测管线，每条判定必须挂显式文本证据。
6. **规则分级与作用域**。沿用 G06 规则 DSL：`severity` 取 error/warn/info，`scope` 取 scene/chapter/cross_chapter/project；规则由派系包注入（流派差异）。
7. **误报控制**。白名单/排除词表、大小写敏感匹配（Novelcrafter）、用户显式豁免（须记理由）、按项目校准阈值、按卷重新校准——误报率是校验功能能否被作者长期使用的生死线。
8. **校验时机三态**。生成后即时轻校验（快规则、可提示）、保存后异步全量校验、手动"全书体检"（重规则 + AI 采样）。

## 3. 可转化为产品规则的关键实践

1. 校验 = 规则 DSL + 比对源 → 规则由派系包提供（G06），比对源 = 设定库 + 事实级记忆（J03），引擎本身与流派解耦。
2. 统一报告结构 → 每条发现含 `rule_id/severity/span/evidence/message/fix`（见 §5 schema），前端据此统一渲染。
3. 无出处断言打标 → 断言若既不在设定库又无 `source_ref` → 标记 `hallucination-no-source`，进"待确认"清单。
4. 高风险段采样一致性 → 仅对新设定、战力描写等高风险段落做 2~3 次采样比对，样本发散度高 → warn（成本可控）。
5. 白名单/豁免 → 项目级与词条级 exclusion，避免"Will/Red"式误报；用户豁免必须记录理由（可审计）。
6. 分级呈现 → error 阻断提交、warn 高亮提示、info 汇总；作者可"接受风险"并留痕。
7. 校验时机三态 → 即时/保存时/批量体检分档，重规则不阻塞写作流。
8. 报告可执行 → 每条附"修复建议"与"跳转原文"，一键进入 J15 局部采纳或 J06 候选确认。
9. 校验结果回流 → 误报标记与豁免理由沉淀为规则调参数据，供派系包维护者改进规则。

2. [学术论文] FActScore: Fine-grained Atomic Evaluation of Factual Precision（EMNLP 2023） — https://aclanthology.org/2023.emnlp-main.741/ — 原子事实分解 + 可靠知识源支持率，长文事实精确度的细粒度度量。
3. [学术论文] SelfCheckGPT: Zero-Resource Black-Box Hallucination Detection — https://arxiv.org/abs/2303.08896 — 多次采样，幻觉事实在样本间发散/矛盾，样本一致性即事实性信号，无需外部库。
4. [学术论文] TruthfulQA: Measuring How Models Mimic Human Falsehoods — https://arxiv.org/abs/2109.07958v2 — "模仿性谬误"：模型越大不一定越真，说明幻觉须独立检测而非靠模型规模自愈。

6. [学术论文] FactSelfCheck: Fact-Level Black-Box Hallucination Detection for LLMs — https://arxiv.org/pdf/2503.17229v3 — 把长文转成 (head, relation, tail) 三元组做事实级幻觉检测，比句级更可解释、更利修正。

9. [开源项目] Long-Novel-GPT — https://github.com/MaoXiaoYuZ/Long-Novel-GPT — 层次化大纲/章节/正文与反思循环，中文长文一致性维护的工程参照。

## 5. 对御书设计的启示

**数据结构建议：一致性审查报告 schema（机器可读 + 可高亮渲染）**

```yaml
# reports/consistency-ch-012.yaml
report_id: consist-ch-012
scope: chapter                       # scene|chapter|cross_chapter|project
engine: {rules_pack: xuanhuan-xitong, checks: [fast, sampled]}
findings:
  - rule_id: consist-power-regress    # 复用 D03 规则 id
    severity: error                   # error|warn|info（G06 DSL）
    span: {chapter: ch-012, start: 120, end: 168, quote: "他实力大跌却仍一掌拍碎城门"}
    evidence:                         # 必须挂证据，避免空口误报
      setting_refs: [char-linyuan#combat_power]
      source_refs: [ch-003, ch-009]
    message: "战力表现高于档案且无事件日志（D03 R2/R6）"
    fix: {type: rewrite, suggestion: "补一条突破/受伤事件日志，或下调战斗表现"}
  - rule_id: hallucination-no-source
    severity: warn
    span: {chapter: ch-012, start: 402, end: 438}
    evidence: {setting_refs: [], source_refs: []}
    message: "断言『玉佩出自皇室』在设定库与出处记忆中均无支撑"
    fix: {type: confirm-or-drop}
summary: {error: 1, warn: 1, info: 0}
whitelist_applied: [word-exclusion:will]
```

**校验规则建议（规则 id 与分级）**

- `consist-fact-contradiction`：正文断言与设定卡字段直接矛盾 → error。
- `consist-name-drift`：A 对 B 的称呼不在称呼表（E07）且无过渡事件 → warn。
- `consist-power-regress`：战力表现超档案且无事件日志（D03） → error。
- `consist-timeline-conflict`：事件时序与编年史冲突（F05） → error。
- `consist-voice-out-of-knowledge`：对白触及该角色"知识边界"之外的事（F04/E07） → warn。
- `hallucination-no-source`：断言无设定库与出处支撑 → warn（可豁免）。
- `report-highlight-on-unsourced`：报告须为每条发现生成可点击的原文区间 → info（渲染约束）。

**功能建议**

- 审查面板：左侧违规列表（按 severity 分组）、右侧正文高亮；点击条目滚动到原文并显示证据出处（跳设定卡/跳来源章节）。
- 全书体检：手动触发，重规则 + AI 采样，产出按卷汇总的体检报告与"风险章节清单"。
- 误报反馈：每条发现可标"误报/豁免"，记录理由并回写规则级白名单，供派系包维护者迭代。
- 生成后即时提示：写作视图内联显示轻校验结果（红色波浪线 + 悬浮修复建议），不打断流式输出。

**AI 提示词建议**

- 断言抽取：「把本章拆成原子事实（主-谓-宾）列表，每条附原文片段与位置」——产出可比对的结构。
- 矛盾判定：输入 `[设定卡 X]` 与 `[正文断言 Y]`，输出 `{contradict: bool, kind, evidence}`，要求给出两侧证据。
- 修复建议：给违规 span + 触发规则，输出 1~2 条**最小改动**方案（不重写整段）。
