# K11-导出与发布

> 类别：K-软件工程与产品 ｜ 世界构建金字塔层级：工程层 · 软件工程
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究把 Markdown 真源转成面向上架/阅读/投稿的成品文件的工程链路：Pandoc 转换管线与参数陷阱、EPUB 3.3 的质量门禁（EPUBCheck）、平台章节格式适配、世界圣经（设定集）汇编导出、模板与元数据、长文档性能，以及导出物与数据主权的边界。边界划分：I07 管平台规则包与合规自查，本领域只做"格式适配与产出"；K03 管存储格式，本领域管序列化与打包；J13 管 AI 版权，本领域管导出物携带 AI 声明。核心诉求来自 docs/01 §4.8：TXT / EPUB 3.3（EPUBCheck 质检）/ DOCX / PDF / 平台章节格式，以及"世界圣经自动汇编：设定集一键导出"。

## 2. 核心知识框架

1. **Pandoc 管线与模型**。Pandoc 是"Haskell 库 + 命令行工具"，采用 reader→AST→writer 的模块化设计；多输入文件默认先拼接后再解析（`--file-scope` 可逐文件解析）。官方明确：多数格式转换"结构可保、格式细节不保"，源格式比 Pandoc Markdown 更具表达力时转换会有损。EPUB 为原生 writer。
2. **Pandoc 关键参数与陷阱**。① 元数据：可用 `--epub-metadata`（Dublin Core XML）或 Markdown/YAML 元数据块（`title/creator/identifier/rights/lang/cover-image/css/page-progression-direction/accessibility*` 等）。② 封面：`--epub-cover-image=FILE`，官方建议图片宽高 <1000px。③ 分章：`--split-level`（旧名 `--epub-chapter-level`）按标题级别切分；`--top-level-division` 决定顶层标题映射为 part/chapter/section。④ 目录与 PDF：`--toc/--toc-depth`；PDF 需外部引擎 `--pdf-engine=xelatex`（中文须配 CJK 字体，联动 clreq 排版）。⑤ 陷阱：多文件默认拼接、样式细节丢失、复杂表格可能无法完整表达。
3. **EPUB 质量门禁 EPUBCheck**。W3C/DAISY 官方一致性校验器，最新 5.3.0（2025-09-01）用于校验 EPUB 3.3；CLI 支持 `--mode`（exp/opf/nav…）、`-j/--json` 报告、`--failonwarnings` 控制返回码。W3C EPUB 3.4 草案明确建议使用一致性校验器，EPUBCheck 为业界事实标准。常见错误来自绝对定位 CSS、绝对内部链接、超大图片、manifest 缺项等。
4. **平台章节格式适配**。各平台对投稿/上传的字数口径、章节名格式、简纲/人设材料要求不同（详见 I07 规则包），导出模块须按目标平台参数化产出（如平台章节格式的 TXT：卷章分隔符、章节标题行、编码；投稿 docx 模板），不得硬编码阈值。
5. **世界圣经汇编导出（docs/01 §4.8）**。把设定卡（人物/地点/势力/物品/事件/关系/时间线/地图）汇编为"设定集"：按世界构建金字塔层级编排目录、实体卡转章节、关系图/时间线/地图作插图、按叙事可见性脱敏。
6. **模板与元数据**。导出模板 = 目标格式的静态骨架（EPUB CSS、DOCX reference.docx、LaTeX 头、TXT 章节模板）；元数据 = 书名/作者/简介/封面/语言/标识符/版权。元数据应作为项目级单一配置，多种导出复用，避免各格式各写一份。
7. **长文档性能**。百万字项目需分卷/分章导出：并行化转换、进度与可中断/断点续跑、流式打包、内存预算（联动 K13）；避免一次性把所有正文读入内存。
8. **数据主权边界**。导出物必须"可脱离御书阅读"：TXT/EPUB/DOCX/PDF 均为通用格式、不依赖专有壳；导出物是数据的"出口"而非镜像，正源始终是项目内的 Markdown/YAML（对齐 docs/01 §6 数据主权承诺）。

## 3. 可转化为产品规则的关键实践

1. 导出 = 管线化任务 → 用"导出任务"配置（schema 见 §5）描述目标格式、范围、模板、元数据、后处理，可复跑可保存。
2. Markdown 真源 → Pandoc 直接读项目内的 Markdown/YAML，不引入中间私有格式（对齐 K03、docs/01 §6）。
3. EPUB 走质量门禁 → 生成后自动跑 EPUBCheck（本地打包 JRE 或调用可执行文件），未通过则阻断"完成"状态并列出错误码与文件定位。
4. 元数据单点配置 → 项目级 `metadata.yaml` 供各格式复用；EPUB 按 Pandoc 字段映射（title/creator/identifier/lang/rights/cover-image）。
5. 平台格式参数化 → 目标平台格式从 I07 规则包读取（字数口径、章节命名、投稿材料），导出时按其参数产出。
6. 世界圣经汇编 → 独立"设定集"导出预设：按金字塔层级生成目录、每张设定卡成节、关系图/时间线/地图作插图，支持可见性脱敏。
7. 中文排版前置 → 导出前按 clreq/GB/T 15834 做标点与版式规范化，PDF 指定 CJK 字体（联动 J14 中文校对）。
8. 分卷与增量 → 百万字按卷/章切片，支持"仅导出某卷/某范围"，进度可中断续跑（K13）。
9. 导出物可独立阅读 → 产物不含专有依赖；同时导出一份导出清单（元数据 + 来源摘要，便于回溯）。
10. AI 声明随产物 → 按平台与法规（国信办 2025-09-01 标识办法）在导出物中携带 AI 使用标识/申报材料（联动 J13、I07）。

## 5. 对御书设计的启示

**数据结构建议：导出任务配置 + 元数据 + 平台参数**

```yaml
# 项目级导出配置：exports/<name>.yaml
export_task:
  id: export-epub-main
  format: epub            # txt | epub | docx | pdf | platform
  scope: { volumes: [vol1, vol2], chapters: "*" }   # 支持分卷/范围
  source: manuscript/**/*.md                         # Markdown 真源
  metadata_ref: metadata.yaml                        # 单点元数据
  template:
    epub_css: templates/epub.css
    cover: assets/cover.jpg
  pandoc:
    split_level: 1                 # 一级标题分章
    top_level_division: chapter
    toc: true
    toc_depth: 2
    pdf_engine: xelatex            # pdf 用；需 CJK 字体
  postprocess:
    - epubcheck                    # epub 必过质量门禁
    - clreq-normalize              # 中文标点/版式规范化
  output: dist/《书名》.epub
```

```yaml
# metadata.yaml（各格式复用）
title: 书名
creator: { text: 作者, role: author }
identifier: { scheme: ISBN-13, text: "urn:isbn:9787000000000" }
lang: zh-Hans
description: 一句话简介
rights: "© 2026 作者，保留所有权利"
cover_image: assets/cover.jpg
ai_disclosure: { used: true, level: assist_only, declared_channel: [] }  # 联动 J13/I07
```

```yaml
# 平台章节格式参数（从 I07 规则包读取，不硬编码）
platform_export:
  platform: fanqie
  chapter_title_format: "第{index}章 {title}"
  encoding: utf-8
  volume_separator: "\n\n"
  valid_word_rule: "后台打卡口径"
  submission_materials: [简纲, 人设, 创新点, 看点]
```

**校验规则建议**

- `export-metadata-missing`：缺 `title/creator/lang` → error（EPUB 必填，导出前阻断）。
- `export-epubcheck-fail`：EPUBCheck 返回非零 → error，列出错误码与文件定位，导出不得置为"通过"。
- `export-cover-too-large`：封面宽或高 >1000px → warn（Pandoc 官方建议）。
- `export-link-absolute`：产物内出现绝对路径的内部链接 → error（EPUB 常见错误）。
- `export-platform-format-mismatch`：目标平台章节标题/字数口径与规则包不符 → warn（联动 I07）。
- `export-bible-visibility-leak`：设定集导出含"叙事可见性=未揭示"条目且未勾选脱敏 → warn。
- `export-cjk-font-missing`：PDF 导出未指定 CJK 字体 → warn（中文乱码/缺字）。

**功能建议**

- 导出向导：选格式 → 选范围 → 选模板/元数据 → 预览 → 执行 → 后处理（EPUBCheck/规范化）→ 产物清单。
- 质量门禁：EPUB 导出内嵌 EPUBCheck，失败给可点击的错误列表。
- 世界圣经汇编：一键生成设定集预设（层级目录 + 设定卡成节 + 图谱/时间线/地图插图 + 脱敏开关）。
- 平台适配：按 I07 规则包产出平台章节格式与投稿材料。
- 大文档分卷导出：进度条、可中断续跑、导出日志（联动 K13）。

**AI 提示词建议**

- 「简介/文案」：由大纲与设定生成书名候选、一句话简介、平台分类标签（人工确认）。
- 「设定集导读」：为世界圣经汇编生成各章导读与术语索引。
