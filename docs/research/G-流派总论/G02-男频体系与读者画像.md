# G02-男频体系与读者画像

> 类别：G-流派总论 ｜ 世界构建金字塔层级：叙事层 · 流派维度
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究男频作为"频道维"取值的内容体系与读者规律：主流赛道与题材份额、读者画像（人口结构、付费习惯、平台分化）、男频写法的频道特异性（主角视角强度、爽点类型偏好、感情线态度）。边界：只管"频道层"共性规律，具体流派写法归 H 类；通用爽点算法归 G05，本领域只记男频特化参数；纯爱/无CP 归 G04。产出直接服务派系包的频道维默认值、开篇模板权重与雷点清单，并与 G03 女频画像卡成对镜像。

## 2. 核心知识框架

1. **赛道结构与份额**：番茄男频都市/同人/玄幻合计约 85%（生态分析文）；起点男频 14 分类以玄幻/都市/仙侠为主力；出海市场欧美偏好修仙/玄幻/都市/奇幻冒险、推理悬疑（国际传播报告）。
2. **读者画像**：以男性为主，免费平台（番茄/七猫）下沉市场占比高；高额付费男频读者在意作品质量与写作态度（作家访谈视角）；爽文消费对应青年心理的即时反馈与掌控补偿（中国青年研究）。
3. **写法特征**：主角视角强代入（第三人称限制视角为主）、金手指文化（"金手指"即男频核心卖点装置）、升级/打脸/事业三大爽点家族、感情线可弱化——"无女主"是被平台与读者接受的常见选项而非缺陷。
4. **开篇与节奏**：黄金三章在男频更严苛——快节奏短段落、第一章内金手指生效或预告、第一冲突前置；官方写作指导同时强调主角辨识度与反派塑造（"反派如 NPC 会导致全书僵化"）。
5. **雷点谱系**：战力崩塌、圣母/无原则原谅、绿帽/送女情节、憋屈过久不反弹、反派降智——社区高频吐槽词，可整理为检测词表。
6. **双频道互读**：男频女读者/女频男读者现象真实存在（知乎科普），频道维决定的是"默认写法参数"而非"读者资格"——工具应按"默认值+可覆盖"建模。

## 3. 可转化为产品规则的关键实践

1. 男频画像卡 → 频道维档案数据文件，供项目向导与 AI 提示词注入引用。
2. 金手指亮相规则 → 开篇校验：第一章内生效或预告、第二章内首次生效（男频权重，联动 F11）。
3. 打脸节拍 → 男频默认爽点循环参数（兑现型爽点间隔上限 5 章，联动 G05）。
4. 感情线默认值 → 男频默认"无女主/单CP 可选"，感情线弱化不警告、强感情线才提示。
5. 男频雷点词表 → 内置检测词库（圣母、绿帽、送女、憋屈 3 章无反击）。
6. 平台分化参数 → 映射番茄/七猫时加载免费版激进节奏参数（段落更短、断章更密）。

## 5. 对御书设计的启示

**数据结构建议：频道维画像卡（与 G03 对称）**

```yaml
channel_profile:
  id: male_channel
  name: 男频
  audience:
    gender_skew: 男性为主
    platforms: {qidian: 付费主力, fanqie: 免费下沉, qimao: 免费下沉}
    overseas_preference: [修仙, 玄幻, 都市, 奇幻冒险, 推理悬疑]
  craft_defaults:
    pov: 第三人称限制视角（强主角代入）
    golden_finger: {reveal_by_ch: 1, active_by_ch: 2}   # 预告/生效章节上限
    payoff_interval_max: 5          # 兑现型爽点间隔上限（章）
    emotion_wave_per_chapter: 1
  romance_default: none             # 无女主/单CP 均常见；弱化不警告
  taboo_list: [战力崩塌, 圣母无原则原谅, 绿帽送女情节, 憋屈3章无反击, 反派降智]
```

**开篇/爽点差异规则（与 G03 对照）**
- 开篇：男频"金手指 ≤2 章"优先于一切氛围铺垫；第一冲突前置到第一章。
- 爽点家族：升级/打脸/事业为主动线，感情线不作为默认期待来源。
- 憋屈管理：压抑事件登记后 >3 章无反击 → "情绪欠账"黄牌（参数可被派系包覆写）。

**校验规则建议**
- 男频项目金手指未在第 2 章生效 → 黄牌"卖点迟到"（慢热文风可豁免并填理由）。
- taboo 词表命中 → 红牌定位段落并给改写建议。

**功能建议**
- 频道参数切换器：同一世界观以女频参数预览的差异 diff（教育新人理解两频写法分工）。
- 免费平台模式：映射番茄/七猫时收紧 golden_finger 至第一章、提高断章密度建议值。

**AI 提示词建议**
- 续写注入："主角视角强代入；本章含 1 个情绪波动点；处于压抑段则章末给期待钩。"
