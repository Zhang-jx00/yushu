# G05-爽点方法论与情绪曲线

> 类别：G-流派总论 ｜ 世界构建金字塔层级：叙事层 · 流派维度
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"爽"的底层机制与工程化表达：爽感的心理构成（代入感/成就/期待）、通用爽点循环算法（压抑→期待→释放→新循环）、爽点分类与密度参数、断章与期待感管理、情绪曲线的数据建模。边界：只管"情绪供给的通用方法论"；各流派的特化爽点参数由派系包（G06）注入，男频/女频的爽点家族差异见 G02/G03。本领域是派系包"爽点模式库"（docs/01 §3.2 第 5 件）与"节拍表"的方法论上游，并与 F07（悬念信息差）、F08（伏笔）共享"已许诺未兑现"的期待模型。

## 2. 核心知识框架

1. **爽感三要素**：代入感（主角可代入）、畅快成就（目标达成）、爽点（具体兑现事件）；情绪价值是网文的产品本质（"网络小说是一种情绪小说"）。
2. **通用循环算法**：压抑蓄力→暗示期待→集中释放→新循环。多来源交叉印证：技术流模板"压抑→拉升→释放→留钩子"；作者社群"爽点原理"体系化讲解；知乎实证"删 1/3 爽点并延后，追读率 35%→67%"——期待感 > 爽点密度。
3. **爽点分类与密度**：爽点三分类（升级型/打脸型/收获型等）+ 每章至少一个情绪波动点 + "叠加爽点"操作法（多线爽点同章兑现）；压抑段过长是头号杀手。
4. **断章钩**：断章=在情绪高点切断（CSDN 悬念钩子/断章/伏笔分层体系）；期待感由"已许诺未兑现"事件驱动，与伏笔台账同构。
5. **心理机制**：即时反馈式满足；阶段性成绩比终点更重要（阶段爽点设计依据）；青年心理的掌控补偿（中国青年研究）；微短剧"冲突反转密集+节奏紧凑"是同一算法的视觉化印证。
6. **节奏参数**：释放间隔上限、压抑连续章数上限、波动点/章下限、断章率下限——可量化参数集构成情绪曲线校验的指标基线。

## 3. 可转化为产品规则的关键实践

1. 爽点循环模板 → 内置"压抑→期待→释放→新循环"四段节拍模板，参数可被派系包覆写。
2. 情绪事件台账 → 每章登记压抑/期待/释放事件（类型/强度/对象），自动生成曲线。
3. 压抑超时预警 → 连续压抑 >N 章无反击 → 黄牌"憋屈欠账"（男频 N=3，可覆写）。
4. 期待感账本 → "已许诺未兑现"清单（与 F08 伏笔台账同构），兑现超期提醒。
5. 断章顾问 → 章末评分：是否停在情绪高点；全书断章率低于阈值提示。
6. 叠加爽点规划 → 多条期待线在同一释放章收束的规划视图。

## 5. 对御书设计的启示

**数据结构建议：爽点循环算法（可配置节拍模板）**

```yaml
satisfaction_cycle:
  id: face_slap_basic              # 派系包可覆写参数（如玄幻包 payoff=5 章）
  phases:
    - {id: suppress, beat: 压抑,   devices: [被打压, 退婚, 被轻视], max_chapters: 3}
    - {id: expect,   beat: 期待,   devices: [金手指预兆, 对手嚣张, 支线铺垫]}
    - {id: release,  beat: 释放,   devices: [打脸, 反转, 兑现承诺]}
    - {id: new_cycle, beat: 新循环, devices: [更大危机, 断章悬念]}
  rules:
    - 单循环 3~8 章；suppress 连续 >3 章 → "憋屈欠账"黄牌
    - release 前必须有 expect 事件，否则"无铺垫爽点"降级警告
    - 每章 ≥1 情绪波动点（微爽/微压均可计数）
    - new_cycle 事件须在章末且指向下一条期待线
```

**数据结构建议：情绪曲线（章节级台账）**

```yaml
emotion_curve:
  events:
    - {chapter: 12, type: suppress, who: 主角, what: 当众被退婚, intensity: -3}
    - {chapter: 13, type: expect,   what: 神秘老者示好, intensity: +1}
    - {chapter: 15, type: release,  what: 退婚者上门被打脸, intensity: +5}
  metrics:
    wave_per_chapter_min: 1
    release_interval_max: 5
    suppress_streak_max: 3
    cliffhanger_ratio_min: 0.6
  promises:                        # 期待感账本（许诺→兑现）
    - {promise: 打脸退婚者, made_ch: 12, due_ch: 15, status: paid}
```

**校验规则建议**
- 指标集按基调覆写：甜宠的 wave 以糖点计数；黑深残可放宽 release_interval。
- 曲线可视化：intensity 沿章节连线，连续负值区间自动高亮"压抑洼地"。

**功能建议**
- 爽点仪表盘：期待线看板（已许诺/已兑现/超期）+ 曲线图 + 违规清单三栏联动。
- 断章评分器：比较章末段情绪强度与全章均值，给出"建议断点"位置。

**AI 提示词建议**
- 续写注入当前相位："当前处于 expect 段第 2 章：只蓄力不兑现，章末强化期待钩。"
