# G01-网文流派分类学

> 类别：G-流派总论 ｜ 世界构建金字塔层级：叙事层 · 流派维度
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

本领域研究"流派"是如何被平台与社区分类、命名和传播的：起点/番茄/晋江/飞卢/七猫等平台的分类树（频道×题材两层）、标签层（角色/情绪/关键词标签）、社区流派词（"X流/X文"）三者之间的关系与差异。边界：只研究分类学本身——体系结构、正交性、命名法、收录流程；各流派的具体写法归 H 类，四维模型与派系包的工程化归 G06。分类学是派系包"平台分类映射表"（docs/01 §3.2 第 11 件）与"流派收录规范"（docs/05 §6）的直接上游：御书要能回答"你写的流派在目标平台挂在哪个分类、贴什么标签"。

## 2. 核心知识框架

1. **官方分类与社区流派词的双层结构**：官方分类是"频道×题材"两层树（起点男频 14 个一级分类、番茄男频 19 个分类、晋江五层正交、飞卢男生/女生频道、七猫细分标签），而流派词（系统流/赘婿流/规则怪谈）不在官方树内，分布在标签层与社区百科层——萌娘百科"Oo流"汇总了种田流/升级流/凡人流/玛丽苏流等十余个"X流"词条及"起点流/晋江流/龙空流"平台风格词。
2. **平台体系对比**：起点（付费，男频 14 分类+女生网，角色/情绪标签）；番茄（免费，需求导向：战神赘婿/都市种田/"脑洞"类直接成为分类，女频以关键词页组织）；晋江（五层正交：原创/衍生×言情/纯爱/百合×时代背景×题材×风格，是御书四维模型最接近的官方先例）；飞卢（同人独立子站，"鲜花/收藏"互动体系，穿越+系统+同人快餐流）；七猫（免费，古代情缘/宫闱宅斗/种田经商细分标签，现实题材征文为题材风向标）；豆瓣阅读（中文情感标签体系：破镜重圆/先婚后爱/社会派）。
3. **付费按题材世界切分、免费按爽点需求切分**：起点/晋江分类是"题材世界"本位；番茄/七猫分类暴露"需求"本位（战神、赘婿、甜宠即分类名）。同一流派在两类平台落点完全不同，映射表必须按平台分别建模。
4. **流派构词法**：社区以"X流/X文"为标准构词；命名规范性=可检索性，同义词并存会分裂讨论（如"种田文/种田流"）。
5. **流派生命周期**：开山作出现→社区讨论发酵（知乎/龙空/贴吧/NGA）→平台设分类或标签→进百科词条；流派有仿作与反套路演化，需携带首次流行年代字段。
6. **流派=可叠加标签包**：快穿+团宠+马甲可同书叠加；《诡秘之主》=克苏鲁+蒸汽朋克+SCP+西幻——分类学必须支持多维组合而非单选树。

## 3. 可转化为产品规则的关键实践

1. 平台分类快照库 → 内置"平台分类树"数据文件（平台×频道×分类×标签），随版本与社区维护更新。
2. 派系包映射表 → 派系包必填字段 platform_mapping，逐平台给出频道/分类/标签落点。
3. 免费平台风格预设 → 映射到番茄/七猫时自动加载"快节奏/金手指前置"参数包。
4. 流派词条 schema → 流派库记录统一携带 定义/开山作/演化链/首次流行年代 四要素。
5. 构词法 lint → 用户自建流派命名校验：推荐"X流/X文"格式，自动聚合别名防同义分裂。
6. 新流派收录三步校验 → 社区提交新流派须附开山作与社区讨论证据，防注水。
7. 标签正交校验 → 阻止把基调词（爽文/甜宠）填进世界维字段，维度值互换即报错。

## 5. 对御书设计的启示

**数据结构建议：平台分类快照 + 派系包映射表（本领域核心产出）**

```yaml
# data/platforms/qidian.yaml —— 平台分类快照（社区可维护，版本化更新）
platform:
  id: qidian
  name: 起点中文网
  model: paid                 # paid | free | mixed
  taxonomy:
    - channel: 男频
      categories: [玄幻, 奇幻, 武侠, 仙侠, 都市, 现实, 军事, 历史, 游戏, 体育, 科幻, 悬疑, 轻小说, 短篇]
      tags: [系统, 穿越, 重生, 赘婿, 打脸, 无女主, 扮猪吃虎]
    - channel: 女生网
      categories: [古代言情, 现代言情, 浪漫青春, 仙侠奇缘, 玄幻言情, 悬疑推理]

# 派系包内 mappings.yaml —— 逐平台落点（G06 派系包引用本结构）
platform_mapping:
  - platform: qidian
    channel: 男频
    category: 玄幻/东方玄幻
    tags: [系统]
  - platform: fanqie
    channel: 男频
    category: 玄幻脑洞
    tags: [系统, 升级]
  - platform: jjwxc
    channel: null              # 晋江无男频玄幻主分类 → 显式空映射
    note: 建议提示改投起点/番茄，或走晋江衍生频道
```

**校验规则建议**
- 映射完整性：所选发布平台无映射条目 → 投稿向导提示"该平台无对应分类"。
- 正交性：维度字段值互换（基调=玄幻）→ 红牌；流派词条缺 origin_work/era → 降级为草稿流派，不进向导。
- 平台 model 分流：目标为 free 平台时自动附"快节奏参数包"建议。

**功能建议**
- 流派选择向导：四维多选 → 联合查询派系包库；无现成包的组合给"就近包+需魔改"提示。
- 扫榜研究入口：关联平台榜单页与流派统计，辅助新人做市场调研。

**AI 提示词建议**
- 生成简介时注入映射标签："按起点男频玄幻+系统标签口吻撰写简介，含升级/打脸钩子。"
