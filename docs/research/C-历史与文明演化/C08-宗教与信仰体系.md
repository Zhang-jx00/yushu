# C08-宗教与信仰体系

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L4 文明层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

宗教与信仰体系研究"世界里的超验解释系统及其社会组织"：神祇（是否存在、神系结构、神域划分）、教义与经典、仪式与实践、教团组织、信仰与政治及日常生活的互相塑造、宗教的传播与分裂。与 A01 的区分：A01 管创世神话的"真相"，本领域管真相落地为"人们如何信、如何拜、如何因此结盟或开战"；与 C10 的区分：宗教衍生的节日与禁忌在本领域定义，在 C10 展开为日常实践。宗教是 C 类中与 A 类（超凡法则）耦合最深的领域，必须双向校验。

## 2. 核心知识框架

1. **神祇实在性光谱**：奇幻默认"神存在且回应祈祷"，但这会杀死信仰本身的张力。社区讨论（r/worldbuilding "Systems of Belief"）建议把"神是否真实"设为世界级开关：真实显灵 / 真实但沉默 / 不可证伪 / 纯粹人创——四档决定无神论者、怀疑派、伪神教派是否可能存在。
2. **神系结构**：Inkwell Ideas 提出核心结构问题（单一神系还是多神系并存、信徒如何对待不崇拜的神）；Red Ragged Fiend 给出神祇类型（主神/职能神/英雄神/魔神）与神际关系网；Art of Worldbuilding 建议直接类比现实神系再改造。神域重叠产生教义冲突，是剧情富矿。
3. **宗教四要素**：教义（世界观+伦理）、仪式、组织（教职等级、修道与布道体系）、经典与圣物。缺任何一件，宗教就会沦为"背景板神像"。
4. **仪式最小集**：LoreTeller 的实用规则——每个宗教至少三种仪式：日常仪轨（晨祷/饭前礼）、人生过渡礼（诞生/成年/婚丧）、集体节庆（圣日）。
5. **组织化光谱与分裂**：民间信仰（无教职）→ 祭司集团 → 国教 → 教权与王权对抗；教派（sect）、异端（heresy）、改革与合流（syncretism，多神教吸纳地方神）是宗教的时间维度。World Anvil 指南主张从"核心信念+议程"出发设计，而非从神像外观出发。
6. **信仰地理与传播**：Azgaar 生成管线中 religions 层依赖 cultures 层——宗教分布由文化扩散与圣地权重决定；朝圣流动天然接入贸易网络（联动 C12）。
7. **东方范式**：《山海经》"帝"系与方国祭祀、社稷/宗法/封禅/天命观，是东方世界"宗教-政治"的接口：祖先崇拜承担宗教职能，天命承担合法性职能；洪荒神话纪元可为教义提供时间纵深。

## 3. 可转化为产品规则的关键实践

1. 宗教实体模板 → 必填"一句话教义+神祇引用+仪式清单+组织形态"，扩展项为经典/圣物/建筑。
2. 四态度字段 → 每宗教声明对死亡、婚姻、商业、暴力四类行为的态度，直接供剧情与对话生成引用。
3. 三仪式底线 → 每宗教至少 1 日常仪式+1 过渡礼+1 节庆，否则 lint"悬浮的宗教"。
4. 神实在性开关 → 世界级设置四档，校验无神论角色、伪神教派、怀疑派台词是否在该档位下合法。
5. 教派分化树 → 宗教可派生子宗教，自动继承神祇与部分教义，必填"分歧点"事件与年代。
6. 圣地-朝圣-贸易联动 → 圣地自动生成朝圣人流建议，可一键加入 C12 贸易网络。
7. 禁忌广播机制 → 禁食/禁色/禁日字段广播到 C10 饮食节日与 C12 违禁品清单。
8. 民间实践层 → 每个官方宗教下可挂"民间变体"条目，允许与正统教义矛盾并注明祭司态度。

## 5. 对御书设计的启示

**数据结构建议**
- `Religion {一句话教义, 神实在性立场, 神祇引用[], 组织形态 enum[民间信仰|祭司集团|国教|修道型|无组织], 四态度{死亡,婚姻,商业,暴力}, 禁忌[], 母宗教引用, 圣地[]}`。
- `Deity {神域[], 神系引用, 显灵记录[], 信徒规模, 圣物}`；`Ritual {类型: 日常|过渡|节庆, 频率, 场所, 参与者}`；`Schism {分歧点, 年代, 结果教派[]}`。

**功能建议**
- 神系关系图：以 Inkwell 式网络图展示神域重叠与神际恩怨，重叠区高亮"潜在教义冲突"。
- 宗教分布图层：依赖文化分布（C07）自动生成并允许手改。
- 宗教冲突生成器：组合"神域重叠+圣地争夺+教义对立"三个槽位，输出冲突理由卡。
- 教派树视图：母教-子教派的时间线，分歧点事件可跳转 C02 编年史。

**校验规则建议**
- 悬浮宗教 lint：无仪式、无组织、无信徒民族的宗教 → 警告。
- 显灵档位矛盾：神实在性为"纯粹人创"却存在显灵记录 → 报错；"真实但沉默"档下出现近期显灵 → 报错。
- 节日来源检查：C10 节日声明宗教来源但引用的宗教不存在 → 报错。
- 国教缺失：C11 政体声明国教但无对应 Religion 条目 → 报错。

**AI 提示词建议**
- "为该宗教设计一个与正统教义表面矛盾的民间变体，解释祭司为何默许它存在。"
- "从两个神域重叠出发，推演一次教派分裂：导火索、分歧点、各自的神学辩护。"
- "在'神真实但沉默'档位下，写一位大祭司的信仰危机独白。"

- 邪教、末日派与秘教：小型高张力信仰组织模板。
- 宗教艺术与建筑风格（联动 C10 艺术面）。

- 宗教历法：圣日体系与世界历法（A04）的对齐。
