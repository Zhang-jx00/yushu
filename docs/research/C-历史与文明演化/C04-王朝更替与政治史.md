# C04-王朝更替与政治史

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L3 历史层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

王朝更替与政治史研究"政权作为历史主体的兴衰过程"：王朝的生命周期（创业-守成-衰亡）、合法性来源及其转移（天命/血统/武功/选举/法理）、宫廷与派系斗争、政体类型在时间中的演化与突变，以及政权之间的政治关系史（并立、朝贡、征服、联姻）。它是 L3 历史层中"政权尺度"的主干：C03 研究文明如何诞生，本领域研究政权如何上台、维持与下台，并为 C06 提供"政权遗产"（制度、边界、仇恨、姻亲）的源头。边界：不研究战争本身的军事细节（C05），不研究历史对当下社会的沉积机制（C06）；焦点是"政权兴衰的戏剧"——谁上台、凭什么、怎么垮。

## 2. 核心知识框架

1. **朝代循环（dynastic cycle）**：经典叙事结构为天命授予→开国武功→黄金时代→人口增长与土地兼并→腐化、灾荒、税负加重→民变/外患→失去天命→新朝重建。本土对应"治乱循环"与"历史周期律"（黄炎培窑洞对）。现代史学批评（如 Miller 对"朝代循环旧知识"的清算、气候冲击与王朝兴衰的定量研究）指出：该叙事掩盖了使每个朝代各不相同的结构性趋势——周期背后是人口、财政、气候等变量，而非单纯的君主道德剧本。
2. **世俗周期机制（Turchin & Nefedov《Secular Cycles》）**：把朝代循环改写为可检验的反馈回路——人口压力、精英过剩、国家财政周期、社会凝聚力起伏。对虚构世界的含义：王朝的每个阶段必须有对应的人口/财政/精英状态支撑，不能只靠"出了昏君"驱动。
3. **合法性谱系**：天命/神授、血统、功绩武功、选举共治、契约法理、财富。合法性来源决定继承危机的形态——血统制出继承战争，选举制出贿选与派系操纵，天命制出谶纬造假与"祥瑞竞赛"。
4. **政体类型学与"默认值批判"**：36 类政体目录提供枚举参照；现实政治写作指南批判"奇幻默认绝对君主制"，主张同时设计合法性来源、法律体系（刑/民/习惯/宗教四类）与官僚人事，并让政体随时间自适应演化而非静止。
5. **派系驱动叙事**：政治世界build教程（Worldbuilding 102）主张用 2-4 个利益相异的派系（宫廷、军方、教会、商人、地方贵族）制造政治深度——派系结构是王朝史的"齿轮"，政治事件应由派系互动产生。
6. **政权间关系形态**：并立（南北朝式）、朝贡宗藩、征服王朝、共主邦联、霸权体系；World Anvil 的 diplomacy webs（外交关系网）是该关系的工具化形态。
7. **东方资源**：正统论与"大一统"叙事、庙号/谥号/年号体系、"新朝为前朝修史"的叙事收编传统；玄幻网文的"皇朝-帝朝-天庭"王朝分级可作为高魔世界王朝等级的参考。

## 3. 可转化为产品规则的关键实践

1. 王朝生命周期模板 → 实体 `Dynasty` 内置阶段枚举（创业/鼎盛/僵化/衰亡），每阶段必填 1 个支撑事件 + 人口压力/财政/精英三状态值。
2. 合法性字段 → `legitimacy: 天命|血统|武功|选举|法理|财富`，驱动继承危机生成器按类型产出对应危机剧本。
3. 派系表 → 存续超 50 年的政权至少 2 个派系实体（诉求、领袖、与王室关系），政治事件必须挂派系归属。
4. 继承检查器 → 统治者更替必须有继承事件（册立/政变/内战/选举），血统制政权自动校验血缘链完整性。
5. 政体演化时间线 → 政体字段为带时间戳的序列而非单值，每次变更须挂"改革/革命"类事件。
6. 王朝关系网 → 婚姻、称臣、敌对、和约边可视化（对标 diplomacy web），可从关系网半自动生成外交事件。
7. 修史仪式字段 → 王朝实体可挂"为前朝修史"记录，自动生成官方史观条目（联动 C02 的 Account 层）。
8. 王朝命名器 → 华夏式庙号/谥号/年号生成器 + 玄幻式"皇朝/帝朝/圣朝"分级模板。

## 5. 对御书设计的启示

**数据结构建议**
- `Dynasty {名称, 起讫, legitimacy, 当前阶段, 状态向量{人口压力, 财政, 精英过剩, 凝聚力}, 前朝, 继承法}`——状态向量沿用 Turchin 变量，作为衰亡推演与"改朝换代"生成的输入。
- `Faction {所属政权, 诉求, 势力值, 关系边[]}`；`Ruler {在位区间, 上台事件, 下台事件, 庙号/谥号/年号}`。

**功能建议**
- 王朝体检报告：状态向量随时间的折线图 + 阶段标注，直观暴露"没有衰亡机制的千年王朝"。
- 继承危机模拟器：给定合法性类型与继承人状况，生成 2-3 种危机剧本并标注各派系站位。

**校验规则建议**
- 阶段-事件一致性：每个王朝阶段必须由至少一个事件支撑；"鼎盛 800 年且人口压力恒定"触发合理性警告。
- 无派系政权警告；政体单值化警告（政体未随任何事件变更为静态设定）。

**AI 提示词建议**
- "用人口/精英/财政/凝聚力四个变量为王朝 X 写四段阶段性诊断，每段配一个标志性事件"。
- "为政权 Y（合法性=天命）生成三种继承危机剧本，各带派系冲突与后续涟漪一句话"。
