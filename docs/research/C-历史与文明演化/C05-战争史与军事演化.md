# C05-战争史与军事演化

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L3 历史层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

战争史与军事演化研究"武装冲突作为历史事件的书写"与"军事体系作为历史变量的演化"：战争的层级（战役-会战-战争的因果链）、后勤与动员的物质约束、军事技术-组织-战术的代际演进（军事革命论）、军队与社会的互动（兵役制度、军事贵族化），以及战争在编年史上的记录形态（战报、伤亡、条约）。它是 L3 历史层中的"冲突"专题：战争是年表上密度最高、后果最重的事件类型，也是王朝更替（C04）最常见的中介机制。边界：不研究兵器武备的静态设定与个体武力的力量体系（D 类），不研究超凡法则本身（A02）；本领域管"仗怎么打、为什么打、打完留下什么"——最后一环与 C06 衔接。

## 2. 核心知识框架

1. **战争的写作四原则**（Fluff about Fantasy《Writing A War》）：战争必须有内嵌于世界观的明确目的与原因（"你世界里的任何事都不该凭空发生"）；战争影响所有人（从官员到农夫，没有旁观者）；掌握战争结构——会战短促、决定性、代价高昂，围城漫长、消耗、张力递增，大型战争应两者交替；会战之间要写结盟、筹粮、士气建设等"幕间"，且敌方也在做同样的事。
2. **军事世界build知识清单**（Worldbuilding SE 军事知识库帖）：先定义军队的使命（维和/国土防御/非对称作战/远征），再考虑地区的哲学与组织文化；兵源、后勤、指挥、技术四要素共同决定军事合理性——军事设定是"社会设定的延长线"。
3. **后勤第一性**：军事后勤研究的基本结论——"外行谈战略，内行谈后勤"；补给半径决定战役半径，骡马化军队的草料与粮秣上限决定前现代战争的规模上限（远征万人已是中古极限量级）。任何奇幻远征都绕不开这个约束，除非明确给出魔法解决方案及其代价。
4. **军事革命（Military Revolution）**：Roberts-Parker 论题——16-17 世纪火炮、棱堡（trace italienne）、线式战术、常备军与税收国家之间的连锁反应；军事技术跃迁不是"换装备"，而是同时改写城防形态、财政制度与国家结构。对虚构世界的推论：引入一种新武器必须推演其制度后果，否则技术史与社会史脱节。
5. **战术形态过渡谱系**：方阵→骑兵优势→长枪与火枪混编（pike and shot）→线列步兵；每种形态对应特定社会结构——骑士对应封建制、长矛方阵对应市民军团、火枪常备军对应中央集权税收国家。军事史即社会史的镜像。
6. **东方资源**：《孙子兵法》的"庙算/五事七计/因粮于敌"提供前现代战略语言与东方军事话语；玄幻网文的"宗门战争/圣战"必须回答"个体超凡力量压倒性存在时，军队为何还存在"——这是 D 类力量设定向战争史提出的第一问。
7. **伪战史书写**：GRRM《血与火》示范同一战役的敌我两版伤亡数字与叙事偏差——战争是 C02 多视角记载机制的最佳应用场景。

## 3. 可转化为产品规则的关键实践

1. 战争事件模板 → `War {原因链, 参战方[], 战役列表[], 条约, 伤亡区间, 财政负担, 领土变更[]}`，战役作为其子事件落在编年层。
2. 战役形态字段 → 会战/围城/海战/游击枚举 + 时长模板；围城与远征必须填写后勤来源字段。
3. 后勤 lint → 军队规模 × 行军天数与 B03 地理资源数据联动校验，超限警告"不可持续的远征"，附"魔法补给需声明"提示。
4. 军事技术代差表 → 各势力武装代际标签（青铜/铁器/火药/超凡），代差超过一级的开战应自动给出悬殊推演或"劣势方生存理由"提示。
5. 军事-社会联动字段 → 兵役制度（征兵/募兵/封建/部落/超凡抽调）联动 E 类社会结构；兵役制变更作为历史事件记录并注入 C06 涟漪。
6. 战争原因核查 → 开战必须挂"原因链"（至少一条导火索 + 一条结构性原因），否则警告"为打而打"。
7. 条约生成器 → 战后自动生成条约实体（割地/赔款/联姻/驻军/通商），其后果指针直接作为 C06 涟漪的源头边。
8. 战报伪史料 → 为每场大战生成两版战报（我方/敌方）+ 一首战后民谣，自动挂为多视角 Account。

## 5. 对御书设计的启示

**数据结构建议**
- 在 C02 的 `Event` 之上扩展 `War` 与 `Battle` 两级事件类型，`Treaty` 作为独立实体并携带后果边；`War.battle_ids[]` 保持编年可展开的"本末"结构。
- `Army {规模(宣称值/估计值双值), 补给方式, 兵役制, 技术代际, 归属派系}`——规模双值呼应伪史多视角，供 AI 检索时按可信度取用。

**功能建议**
- 远征可行性计算器：输入路线、兵力与季节，输出沿途补给推演与建议规模上限，附"超限理由"填写框。
- 战争编年泳道：多战线（西线/东线/海线）并排甘特视图，战役与幕间事件同层显示。

**校验规则建议**
- 伤亡守恒：单场战役伤亡超过参战方可动员人口的合理比例 → 警告。
- 技术时序：某方在 T 年使用某武器，则该武器传入/发明事件必须早于 T（联动 C03 传播校验）。
- 无条约战争警告：改变了领土或政权的战争必须有对应条约/和议事件。

**AI 提示词建议**
- "按'原因链→幕间→会战→条约→涟漪'五段为战争 W 生成编年条目，每场会战配两版战报"。
- "解释新武器 X 在该世界的制度后果：城防/财政/兵役/贵族地位各写一段，并给出一个反抗该后果的社会群体"。
