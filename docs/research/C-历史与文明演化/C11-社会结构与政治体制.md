# C11-社会结构与政治体制

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L4 文明层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

社会结构与政治体制研究权力如何组织：社会分层（阶级/种姓/流动通道）与政治体制（政体类型、权力来源、继承与更替），以及体制的展演单位——派系。与 C04 的区分：C04 管政权兴衰的历史过程（时间轴上的动态），本领域管政权的静态结构与运转规则（机器的构造图）；与 C06 的区分：C06 管故事开始时的势力格局，本领域提供格局的内部构造件。政体与派系是权谋类、历史类网文的核心设定消费点，字段化程度直接决定 AI 能否生成可信的政治剧情。

## 2. 核心知识框架

1. **政体目录**：Chaotican Writer 枚举 36 种政体（从部落会议到僭主制、神权帝国）；Summon Worlds 归纳奇幻五大常用（封建君主、法师议会、商人共和国、神权政体、帝国）；现实光谱（部落制→城邦→封建→官僚帝制→共和）可作枚举底表。目录的意义是防"全世界只有王国一种"。
2. **权力三问**：Darling Axe 问卷的框架——谁掌权、权力如何合法化（神授/血统/选举/超凡实力）、如何更替。继承规则是政变的计时器：嫡长制的模糊处（庶子、幼帝、摄政）就是剧情的裂缝。
3. **社会分层与流动**：阶级（经济定义）、种姓（出身固化并神圣化）、流动通道（科举/教会/军队/行会/婚姻）。流动通道决定底层主角的上升剧情是否可信；零通道社会是"高压锅"，需要爆炸点剧情。
4. **派系即引擎**：Tedin 主张用派系制造政治深度；Shedd 强调派系必须随事件演化而非静态贴图；Loreteller 给派系加内部张力与个人利害。Anima 的底线规则最可操作："三个目标互不兼容的派系"自动产出冲突。
5. **统治细节=可信度**：Tolkien Society 记录的 GRRM 之问"亚梭伦的税收政策是什么"——税收、兵役、司法等"无聊细节"是政权可信度的抓手，也是冰山原则下"水面下十分之九"的典型内容。
6. **超凡与权力的耦合**：魔法/修为如何改写权力结构——法师寡头、武力即真理的江湖、宗门与皇朝双轨制（东方网文特有：仙凡两套权力系统并存、互相借力又互相提防）。政体必须声明超凡者的政治地位。
7. **帝国治理梯度**：中心-行省-边疆的控制力递减，总督/藩王/羁縻/土司等代理统治方式；多民族帝国的认同政治联动 C07，边疆失控联动 C04 王朝周期。

## 3. 政体字段枚举与派系卡 schema

**Government（挂接在 C03/C04 的 State 之下）**

```yaml
Government:
  类型: enum[部落会议, 城邦公民会, 封建君主制, 中央集权帝制, 选举君主制,
        神权政体, 贵族共和, 商人寡头, 僭主制, 游牧汗国, 长老制,
        行会联盟, 法师议会, 军事执政官, 殖民地总督制, 双头共治, 自定义]
  权力来源: enum[血统, 神授, 军功, 财富, 选举, 超凡实力, 民心, 宪章祖制]
  继承规则: enum[嫡长子, 诸子/兄终弟及, 选举, 禅让, 遗命指定, 武力夺位, 轮替, 无]
  中央集权度: 0-10        # 10=郡县直管，0=纯羁縻
  官僚化程度: 0-10
  合法性叙事: []          # 必填，引用创世/宗教/历史事件
  现任元首: 引用           # 角色
  首都: 引用
  超凡参政: bool + 说明   # 与 A02 力量体系一致性校验
```

**Faction（派系卡，可挂政权也可独立存在）**

```yaml
Faction:
  名称: str
  类型: enum[朝廷党争, 宗室外戚, 宦官, 地方豪强, 宗教教派, 江湖宗门,
        商业行会, 秘密结社, 军事集团, 起义军, 外族势力, 学者门派]
  核心目标: str           # 必填
  意识形态: str
  领导结构: enum[个人独裁, 元老会, 集体领导, 神秘化领袖]
  实力六维: { 人数, 财力, 武力, 超凡战力, 情报, 人脉 }   # 各 0-10
  关系矩阵: [{ 对象派系, 态度: 敌对|竞争|中立|同盟|附庸, 原因 }]
  内部张力: str           # 潜在分裂线
  底牌: str
  弱点: str
  当前行动: str
  叙事可见性: enum[明面, 半公开, 暗线]   # 冰山元数据
```

## 4. 可转化为产品规则的关键实践

1. 政体模板 → State 自动携带 Government 子结构，类型枚举 16 项+自定义，字段渐进披露（类型+权力来源必填）。
2. 合法性叙事必填 → 政体必须引用至少一条创世/宗教/历史事件作为合法性来源，否则 lint"悬浮政权"。
3. 继承规则字段 → 继承法的模糊度自动加权"继承危机"事件生成器的触发概率。
4. 派系底线 → 每个政权至少 3 个派系且核心目标两两冲突，用 lint 检查"全体一条心"政权。
5. 流动通道登记 → 每个社会列上升通道清单；零通道社会标记"高压锅"并提示需冲突剧情。
6. 超凡权力耦合 → 政体声明超凡者是否参政，与 A02 力量体系做一致性校验（有魔法无魔法政治→报错）。
7. 治理梯度 → 帝国型政体须声明边疆控制方式（总督/藩镇/羁縻），联动 C03 路径与 C04 衰亡方式。
8. 叙事可见性标注 → 派系的"暗线/明面"元数据控制其在正文提示中的出现时机。

## 6. 对御书设计的启示

**数据结构建议**
- Government 与 Faction schema 见第 3 节；建议 `SocialStratum {名称, 定义方式: 阶级|种姓|修为, 占比, 特权, 上升通道引用[]}` 作为政体的分层子结构，与 C12 财政、C10 阶层饮食共用。

**功能建议**
- 派系关系图：World Anvil diplomacy web 式力导向图，态度用颜色编码，点击边展开原因与历史事件。
- 权力结构树：元首→中央官制→地方代理三层树，集权度滑杆联动树的深度。
- 派系压力模拟：输入事件（灾荒/战败/新君继位）推演各派系立场移动，输出"谁受益谁受损"卡。
- 继承危机雷达：扫描所有政体的继承规则模糊点，列出可写的夺位窗口清单。

**校验规则建议**
- 悬浮政权 lint：无合法性叙事引用的政体 → 警告。
- 无派系政权 lint：仅 1 个派系或派系目标全兼容 → 提示"政治真空"。
- 力量-政治矛盾：A02 声明魔法普遍且强大，但政体无超凡参政说明 → 警告。
- 历史矛盾：帝制国家的建国史无建国者条目 → 报错（联动 C04）。

**AI 提示词建议**
- "列出该政权三个目标互不兼容的派系，各给受益者与失败者，并指定一条暗线派系。"
- "用'谁交税、交多少、交给谁、交不起怎么办'四问写出该国的财政与统治日常。"
- "推演幼帝继位后的三次派系洗牌，每次引用派系卡中的实力六维与内部张力。"
