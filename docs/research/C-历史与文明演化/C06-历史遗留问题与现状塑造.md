# C06-历史遗留问题与现状塑造

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L3 历史层 + L5 社会现状层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

历史遗留问题与现状塑造研究"历史如何沉积为现状"：哪些事件会留下可感知的遗产（制度、边界、仇恨、创伤、废墟、节日、姓氏），遗产以什么机制跨代传导（直接后果/一代涟漪/多代涟漪），以及"从现状倒推历史"的 outside-in 工作流。它是 L3 历史层与 L5 社会现状层之间的映射器：C01-C05 从前往后写历史，本领域从后往前验历史——每一个现状（世仇邻国、被禁宗教、废弃古道）都应在历史层找到成因，每一条重大历史都应在现状层留下可见痕迹。边界：不研究历史事件本身的写法（C02/C04/C05），只研究"事件→现状"的传导、显影与双向校验。

## 2. 核心知识框架

1. **Wrede 问卷的"历史→现在"提问法**：经典世界build问卷在"物理与历史"板块反复追问"这件事如何影响现在"——历史事件清单必须逐条回答"它现在留下了什么"，否则只是背景板；这是把历史层与现状层强制缝合的最简方法论。
2. **Outside-in 与冰山原则**：GRRM 自述从现状出发倒推历史、"冰山九分之十在水下"——作者需要掌握全部历史，但只显影能被现状感知的部分。因此历史条目需要"叙事可见性"元数据（与 A 类的 reveal state 同构），避免把背景史整块倾倒给读者。
3. **遗产的物质性**："Aragorn 的税政"之问指出：现状的政治经济细节（税制、道路、饷银、方言）是历史可信度的抓手；真实世界的"一战后果"条目完整示范遗产形态——新边界、赔款、帝国解体、复仇叙事、战争债与恶性通胀，以及由此生长出的下一场战争。
4. **战争的传导链**："战争影响所有人"原则把传导落到角色尺度——阵亡名单、寡妇村、孤儿、老兵、物资管制、占领区合作者与抵抗者；C05 的条约后果是本领域最主要的涟漪源，战争的遗产比战争本身更适合进入正文。
5. **社区方法论**：r/worldbuilding 两条高讨论度的实践——"哪些事件造就了你的世界现状"（以现状为锚反向征集成因事件）与"如何展示世界随时间变化"（反对静态世界，要求历史差异显影于当下的日常生活）。
6. **涟漪层级模型**：直接后果（条约、废墟、人口损失）→ 一代涟漪（制度重建、移民潮、经济重心转移）→ 二代及以后涟漪（身份认同、节日、口传仇恨、废墟浪漫化）。遗产随代际衰减但可能被仪式化固定，"百年仇恨"可降格为礼仪性敌意或节庆。
7. **东方资源**：网文"量劫""因果"话语是涟漪传导的原生隐喻（洪荒流的量劫遗留、修仙界的上古遗迹与功法断代）；族谱、祖训、宗祠、碑刻是农耕社会的历史记忆载体，可直接用作现状层实体。

## 3. 可转化为产品规则的关键实践

1. 遗产类型表 → 历史事件的后果指针必须带遗产类型枚举：制度/边界/人口/经济/文化记忆/物质遗迹/仇恨关系/正面遗产。
2. 涟漪三级标注 → 后果边带 `ripple_level`（0 直接/1 代/2 代+）与到达时间区间，引擎可把远期遗产自动写成现状条目草稿。
3. 现状溯源字段 → L5 现状实体（禁忌、世仇、节日、贫富分区、遗迹）必须填 `origin_event` 引用，否则警告"无因现状"。
4. 显影度字段 → 历史事件挂 `visibility`（无人知晓/学界考据/民间传说/妇孺皆知），控制其进入正文的披露层级。
5. 历史审计报告 → 正向从重大事件生成"应留痕清单"逐项核查；反向从现状实体生成"待解释清单"，两份合并为连通性评分。
6. 遗迹生成器 → 大事件自动建议生成遗迹条目（废都、界墙、万人坑、纪念碑、沉船），标注当前位置与现用途（与 B04 地点库衔接）。
7. 世代记忆衰减器 → 按事件距今年代自动建议现状的态度温度（复仇→礼仪性敌意→节庆化→仅存地名），作者可覆盖。
8. 量劫模板包 → 东方世界可选启用：断代功法、上古遗种、封印物、劫后幸存家族四类"量劫遗留"现状实体。

## 5. 对御书设计的启示

**映射规则（历史遗留问题→现状格局）**
- R1 领土类：割地/合并/解体 → 现状的边界线、飞地、争议区、边境驻军与双文化边境带（L5 政治格局）。
- R2 人口类：屠杀/瘟疫/移民潮 → 人口分布、民族拼图、方言岛、姓氏密度、"失落的一代"。
- R3 制度类：革命/改革/占领 → 政体残留（前朝法典、旧官僚、复辟派）、度量衡与历法混用。
- R4 经济类：贸易路线转移/赔款/赖债 → 兴衰城市带、世袭财阀、报复性产业与经济怨恨。
- R5 记忆类：暴行/英雄/耻辱 → 节日、禁忌词、纪念碑、教科书叙事、世仇家族与复仇组织。
- R6 物质类：决堤/焚烧/封印 → 废墟、界墙、禁地、超凡封锁区（联动 A02 与 B04）。
- 每条规则实现为 `LegacyRule {触发事件类型, 遗产类型, 作用目标(L5 实体类型), 衰减函数, 显影方式}`，引擎按规则自动生成候补现状条目供作者确认或否决。

**数据结构建议**
- `Consequence {源事件, 目标实体, 遗产类型, ripple_level, 时间区间, 强度, canon_level}`——目标实体可位于 L3（后续历史）或 L5（社会现状），形成跨层有向图。
- L5 现状实体统一挂 `origin_event[]` 与 `visibility`，与 C02 的 Event/Account 体系共用 canon 字段。

**功能建议**
- 双向走查工作台：正向"事件→应留痕清单"、反向"现状→成因溯源"，合并输出"历史-现状连通性"评分与缺口列表。
- 世代温度滑杆：拖动年代轴实时预览某仇恨/荣耀在当下的应有温度与表现形式。

**校验规则建议**
- 无因现状 lint：L5 实体缺 `origin_event` → 警告；作者可声明"天生如此"并注记豁免理由。
- 无痕大事 lint：强度超阈值的历史事件若涟漪数为 0 → 警告"史诗级事件没有留下任何东西"。
- 衰减一致性：距今年代超过 N 代的仇恨类遗产若仍为最高烈度 → 提示补充"持续再生产的机制"（世代宣传、宗教教义、制度性歧视）。

**AI 提示词建议**
- "对事件 E 依次套用 R1-R6 映射规则，列出它在直接/一代/二代涟漪分别应产生的现状条目"。
- "为现状 S 写三层成因倒推：可观察症状→导火索事件→结构原因，各层两句话"。
