# C12-经济与商业体系

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L4 文明层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

经济与商业体系研究世界里的物质流转：资源与产出、货币与价格、贸易路线与商路节点、商人组织、税收与财政。与 B03 的区分：B03 管资源的地理分布（矿在哪、粮产在哪），本领域管资源如何变成财富与权力；与 C11 的区分：C11 管权力结构，本领域回答"政权靠什么养活自己"——即 GRRM 之问"亚梭伦的税收政策是什么"的正面回答。经济是 Azgaar 生成管线的最下游（资源→聚落→路线），也是货币、物价、俸禄等高频数字一致性的唯一权威来源。

## 2. 核心知识框架

1. **Wrede 商业问卷**：经典七板块中的"商业贸易"——货币形态、物物交换区域、商队与商路、行会与垄断、技术对生产的影响、人们如何计算财富。可直接转成实体 checklist，是本领域的骨架来源。
2. **资源-聚落-路线生成链**：Azgaar 的实现——聚落选址即经济选址（河流/海岸/资源点），贸易路线按城市权重与地形成本自动生成（r/FMG 新版贸易路线依赖湖海山系与首都权重）。经济是地理层的下游，路线生成应"可解释、可重生成"。
3. **货币设计**：面额体系与兑换比、本位制（金/银/粮本位/灵石本位）、铸币权（谁有权铸币即主权的物质表现）、货币信任（劣币、私铸、剪边、通货信用崩溃）；边疆与非货币经济（以物易物、劳役、贡赋）长期并存。
4. **贸易品与比较优势**：地区特产（B03 资源图）→ 贸易品清单 → 路线 → 关税与走私；奢侈品（香料/丝绸/灵材）驱动长距离贸易，必需品决定区域自给线。Kara Copple 的做法可参考：锚定一个已被验证的历史贸易网（如罗马帝国）再改写。
5. **商业组织**：行会、商队（caravan）、钱庄/票号/银行、海上商团；商人财富转化为政治权力的通道（买爵、资助战争、垄断特许）是接入 C11 派系卡的接口。
6. **税收与财政**：税种（田赋/商税/盐铁专卖/人头税/关税）、税吏与包税制、战争财政；"财政危机→加税→民变"是王朝周期律的经济版本（联动 C04），Darling Axe 经济问卷把"社会在故事时间线内押上什么"作为核心问题。
7. **超凡经济**：灵石/丹药/法器作为货币与商品——修真世界的"灵石本位制"、宗门经济（灵田/坊市/炼丹产业）、超凡劳动的定价；力量体系（A02）必须映射为经济稀缺性，否则"一颗丹药值多少"全书漂移。

## 3. 货币与贸易数据结构

```yaml
Currency:
  名称: str
  面额: [{ 单位, 兑换比(相对基准单位) }]      # 例: 1金=10银=1000铜
  本位: enum[金银, 粮食, 灵石, 信用票据, 其他]
  发行方: 引用(政权|宗门|钱庄)                 # 无发行方 → lint
  铸币材质: str
  信任度: 0-10                                 # 低信任区自动建议以物易物
  流通区域: []                                 # 引用政权/地区

TradeGood:
  名称: str
  类别: enum[粮食, 原料, 手工品, 奢侈品, 超凡品, 违禁品]
  产地: []                                     # 引用 B03 资源点/地区
  基准价格: { 数值, 计价货币引用 }
  价格波动事件: []                             # 引用 C02 事件
  叙事可见性: enum[明面, 暗线]                 # 冰山元数据

TradeRoute:
  起点: 引用 / 终点: 引用
  中继节点: []                                 # 城市/关隘/渡口
  运输方式: enum[商队, 船运, 飞舟, 传送阵]
  主要货品: []                                 # 引用 TradeGood
  关税与过所: str
  风险: { 匪患, 气候, 兽潮 }                   # 供剧情与保险/镖局生成
  依赖声明: []                                 # 河流/山口/资源引用(可解释性)

MarketHub:
  城市/坊市引用: ref
  集市周期: 历法引用(A04)                      # 例: 每旬逢五开市
  经营主体: enum[官营, 行会, 宗门, 自由集市]

FiscalRecord:
  政权引用: ref
  税种: enum[田赋, 商税, 专卖, 人头税, 关税, 灵田租]
  收入估算 / 主要支出: { 军费, 宫廷, 河工, 宗门供养 }
  盈缺: 数值                                   # 缺口自动挂剧情建议
```

## 4. 可转化为产品规则的关键实践

1. 特产-城市自动连线 → 依据 B03 资源与 B05 城市自动建议贸易路线候选（Azgaar 式），作者确认后入库。
2. 货币兑换器 → 多货币世界的价格换算与跨币种交易场景生成；铸币权冲突事件模板（中央铸币 vs 地方私铸）。
3. 财政三问卡 → 每个政权必答"税收/支出/缺口"，缺口自动建议剧情（卖官/加税/借债）并联动 C11 派系反应。
4. 违禁品与走私 → 组合 C08 禁忌与关税政策自动生成走私路线与黑市条目。
5. 价格事件时间轴 → 灾荒/战争/新路开通自动生成"物价变动"事件并广播到沿线城市。
6. 商人组织模板 → 行会/商队/钱庄卡含政治关联字段，可直接升级为 C11 派系卡。
7. 超凡物价表 → 灵石/丹药基准价与"凡人年收入"对照表，保证超凡物品定价全书一致。
8. 一条商路的传记 → 输入路线与 C02 事件，自动生成该商路的兴衰史文本（何时因战争改道、何时因新法器崛起）。

## 6. 对御书设计的启示

**数据结构建议**
- 五实体 schema 见第 3 节（Currency/TradeGood/TradeRoute/MarketHub/FiscalRecord）；TradeGood 挂叙事可见性元数据，与冰山原则对齐；所有价格引用唯一计价货币，换算由 Currency 面额表负责。

**功能建议**
- 贸易路线地图层：可开关显示货品流向与中继节点，路线着色按主要货品类别。
- 价格沙盘：输入灾荒/战乱事件，沿依赖链推演物价涟漪并生成事件条目。
- 财政仪表盘：按政权汇总 FiscalRecord，盈缺与军费占比超阈值时红显并弹出剧情建议。
- 商路的传记生成器：把路线依赖声明+C02 事件串成叙述文本，直接可用作正文背景交代。

**校验规则建议**
- 孤立节点 lint：有产地无路线、有路线无货品 → 警告。
- 产地越界：城市有特产但产地不在辐射圈且无输入路线 → 报错（可豁免：贸易输入）。
- 发行方缺失：Currency 无发行方 → 报错；政权灭亡后其铸币仍在流通 → 提示补"旧币流通期"设定。
- 时序检查：价格波动事件引用的事件早于该商品首次出现 → 报错（联动 C02）。

**AI 提示词建议**
- "用一句话回答'这个国家的钱从哪来、花到哪去'，再展开成完整财政卡。"
- "为灵石设计本位制：谁开采、谁定价、谁垄断、崩盘时谁先破产，并推演一次灵石挤兑。"
- "沿新开通的商路，列出三个因此繁荣与两个因此衰落的城镇，各附一句市井细节。"

## 7. 领域内子主题备忘（可选）

- 人口与劳动力制度：奴隶/佃农/佣兵/徭役的经济地位。
- 坊市制度与宵禁：市场空间与时间的管理（联动 B05 城市结构）。
- 海上贸易与季风航路（联动 B02 气候）。
- 经济危机类型学：饥荒/银荒/挤兑/泡沫的剧情模板。
- 超凡资源枯竭经济学：灵脉衰竭对整个文明的影响（联动 B09）。
- 镖局、保险与风险定价：超凡世界里的护卫产业。
