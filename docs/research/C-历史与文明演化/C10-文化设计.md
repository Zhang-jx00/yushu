# C10-文化设计（礼俗·节日·艺术·饮食）

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L4 文明层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

文化设计研究单个文化的"内容层"：礼俗（婚丧嫁娶、待客、称谓、禁忌）、节日（岁时与纪念）、艺术（音乐/纹样/表演/建筑风格）、饮食（物产→菜系→餐桌礼仪）。与 C07 的区分：C07 管族群分类与族间关系，本领域管某个文化内部的日常质感——角色走进一座城时"闻到什么、听到什么、被什么冒犯到"。Wrede 问卷的"民族与习俗""日常生活"两大板块是本领域的检查清单原型。文化内容是叙事质感的主要来源，也是 AI 生成场景描写时最需要的上下文。

## 2. 核心知识框架

1. **习俗的生成逻辑**：社区共识（fantasy-writers.org、Well-Storied）——习俗不是随机装饰，而是环境与历史的回应：海岸文化重航海礼、多战文化重成人礼、缺水文化发展出一整套待客饮水礼。正确顺序是先定地理与历史，再派生习俗，每条习俗可溯源。
2. **文化最小集**：Mythic Scribes 与 Well-Storied 的六面模型——价值观（何为荣/何为耻）、习俗与礼仪、语言与称谓、服饰、饮食、艺术。六面齐备，文化即可感；缺价值观与习俗两面则沦为"服装与食物展板"。
3. **节日四来源**：宗教（圣日/纪念日）、农时（节气/收获/开耕）、历史（建国/大捷/国耻）、人生礼俗（成年礼/命名日）。每个节日应有"若被中断会怎样"的叙事钩子（fabledplanet 的冬至讨论提出庆祝须与剧情利害挂钩）——节日是天然的剧情定时器。
4. **历法支撑**：节日必须落在具体历法日期上。LegendKeeper 的自定义历法视图示范了"历法-节日"绑定；东方节日的骨架是农历与二十四节气（岁时体系），节气天然连接农时与祭祀。
5. **饮食链**：物产（B03 资源）→ 烹饪方式（燃料、炊具、保存技术）→ 菜系与名菜 → 餐桌礼仪与禁忌（接收 C08 宗教禁忌）。社区讨论强调城市餐桌要分层：平民糊口、行会宴席、宫廷礼膳，阶层饮食差是最便宜的阶级叙事。
6. **艺术作为世界观表达**：纹样讲神话、史诗唱历史（联动 C01/C02 编年史）、建筑说财力与信仰；艺术风格的差异是辨识两个文化最低成本的手段，且可为"文物/古董"类剧情提供实体。
7. **礼俗的冲突价值**：待客法、婚俗、丧俗、称谓与避讳——违反礼俗即冲突。两个文化互相"最可能冒犯对方的三件事"，是跨文化角色互动的低成本戏剧来源。

## 3. 可转化为产品规则的关键实践

1. 文化内容六面模板 → 价值观/习俗/称谓/服饰/饮食/艺术六字段，渐进披露：先必填"3 条价值观+1 条核心习俗"，其余可后补。
2. 习俗溯源卡 → 每条习俗必填起源解释（引用地理/历史事件/宗教三者之一），无溯源则标记为"装饰性习俗"提示。
3. 节日日历绑定 → Festival 必须引用历法日期（A04）与来源类型，自动标注到时间轴与章节日历视图。
4. 节日剧情钩子 → 每个节日自动生成"若节庆被打断"的三个冲突方向（政变窗口/灾害降临/亵渎事件）。
5. 饮食-物产校验 → 名菜主食材必须在该文化产地范围内可得，违者警告（可用"贸易输入"豁免并联动 C12 路线）。
6. 禁忌广播接收 → 自动接收 C08 宗教禁忌字段，生成饮食限制与节日避讳清单。
7. 礼俗冲突生成器 → 输入两个文化，输出"互相最可能冒犯的三件事"并各附一句示例场景。
8. 称谓表生成 → 从 C09 命名语言与 C11 等级制度自动生成称谓/敬语/避讳表，供对话渲染。

## 5. 对御书设计的启示

**数据结构建议**
- `CultureContent {所属文化引用, 价值观[], 习俗[]{名称, 起源引用: 地理|历史|宗教, 违反后果}, 称谓表, 服饰, 艺术风格[], 饮食{主食, 烹饪方式[], 名菜[]{名称, 食材引用[]}, 禁忌}}`。
- `Festival {名称, 日期(历法引用A04), 来源: 宗教|农时|历史|礼俗, 来源事件引用, 仪式流程[], 叙事钩子[], 参与民族[]}`。

**功能建议**
- 节日年历视图：LegendKeeper 式自研历法网格，节日/禁忌日/集市场次叠加显示，章节可按"故事发生在某年某月"自动列出当月节俗。
- 文化对比面板：两文化六面并排差异表，差异项一键生成"文化冲突"剧情种子。
- 名菜卡与食材溯源链：点击名菜展示"物产→产地→运输→烹法"链路，断链处即 lint 提示。
- 装饰性习俗回收站：被标记"无溯源"的习俗集中存放，作者可为其补写起源或删除。

**校验规则建议**
- 无日期节日 lint：Festival 缺历法日期 → 警告"飘在时间之外的节日"。
- 来源悬空检查：节日来源为宗教但宗教条目不存在 → 报错（联动 C08）。
- 阶层饮食提示：政体为森严等级制（C11）但饮食无阶层区分 → 提示。
- 物产越界：名菜食材无本地来源且无输入贸易路线 → 警告。

**AI 提示词建议**
- "从该文化的地理、历史与宗教各推导一条习俗，每条给出起源解释与违反后果。"
- "为两国共有的同一节日写两个版本：纪念同一事件，但叙事与仪式完全相反。"
- "写出主角初入该文化城市时，因不知礼俗而差点冒犯对方的三连场景。"

## 6. 领域内子主题备忘（可选）

- 服饰细节体系：面料（联动物产）、等级色禁、场合着装。
- 建筑风格谱系与民居-神殿-宫殿三档。
- 体育、竞技与博弈（赛会是节日的常见附件）。
- 待客法（guest-right）与誓言礼：跨文化安全保障与背叛的重量。
- 性别角色与人生阶段划分（成年礼年龄的多样性）。
- 艺术品作为剧情道具：赝品、失传、赠礼外交。
