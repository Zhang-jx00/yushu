# C01-历史观设计

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L3 历史层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

历史观设计研究"这个世界的总历史如何被讲述"：作者采用哪种史观组织历史（线性进步、治乱循环、黄金时代退化、唯物阶段论、英雄史观等），历史被切成哪些"纪元/时代"、按什么标准切分（政权、技术、神话、宗教），以及世界内史官叙述与作者真相之间的双层关系。它是 L3 历史层的顶层设计：先定史观与分期骨架，C02 才能填编年条目，C03/C04/C05 才有展开的时空框架。边界在于：本领域不研究具体事件怎么写（C02）、文明兴衰规律本身（C03/C04）、也不研究历史对现状的沉积效应（C06）；本领域只回答"历史的形状"——是直线、螺旋还是钟摆。

## 2. 核心知识框架

1. **史观光谱**：真实史学的主要史观包括线性进步史观（启蒙/辉格叙事）、循环史观（伊本·赫勒敦的 asabiyyah 四代周期、斯宾格勒的文化生命周期、汤因比的挑战-应答）、退化史观（黄金时代→堕落，神话宇宙观常用）、唯物史观（按生产方式/技术划分阶段）、年鉴学派的长时段观（事件/局势/结构三层时间，见 longue durée）。循环观与动力学的区别：Turchin 强调"历史动力学不是循环史观"——周期来自可建模的反馈机制而非神秘宿命，这对虚构世界意味着每个"轮回"必须有机制。
2. **分期方法论**：按政权（朝代/王朝始末）、按技术与经济（石器-青铜-铁器-蒸汽，即"三代论"式技术分期）、按精神文化（古典-中世纪-近代；神话时代-英雄时代-历史时代，赫西俄德五纪是原型）。维基 Periodization 条目指出：分期本身就是一种论断——切在哪里、以什么为界，决定了历史叙事的重心。虚构世界同理：每条纪元边界都是一次作者声明。
3. **纪元状态差异原则**：奇幻世界最常被批评的毛病是"万年中世纪停滞"（《魔戒》《时光之轮》等时间跨度数千年而技术社会几乎不变）。对策是把"纪元"定义为状态的显著跃迁：相邻纪元在技术、政体、人口、贸易、宗教上至少应有可见差异。
4. **世界外真相层 vs 世界内叙述层**：GRRM 把《血与火》当"伪史书"写——世界内史官的记载有立场、有缺环、有互相矛盾；作者的真相层才是一致的。这与 A01 的"作者真相 vs 角色版本"双层结构同构，是历史类设定的标准形态。"outside in"方法（GRRM 自述）意味着历史层可以从现状倒推生成，但真相层必须自洽。
5. **架空历史的分歧点（POD）方法**：若世界以真实历史为底本，需声明 POD（point of divergence）——时间线在哪一刻分岔，以及蝴蝶效应的传播范围与收敛边界（alt-history 社区的核心方法论）。
6. **东方原生资源**：中国史学的朝代分期与"通史/断代史"二分、正统论叙事，以及洪荒流式的神话分期（创世→神战→人间王朝），是区别于西方"古典-中世纪"框架的另一套现成分期语言。

## 3. 可转化为产品规则的关键实践

1. 史观声明字段 → 世界实体必填"主导史观"枚举（线性/循环/退化/混合），驱动纪元模板与推演方向。
2. 双层历史模型 → 所有历史条目区分"作者定稿"与"世界内记载"，后者可挂 bias/缺环/伪造标记。
3. 纪元边界校验 → 每条纪元边界必须绑定一个"变化机制"事件（灾变/技术突破/政权更替），否则警告"无理由切换"。
4. 纪元状态差异 lint → 相邻纪元自动比对技术、政体、人口、贸易、宗教五项状态，差异不足 N 项时提示"疑似停滞"。
5. 分期命名模板 → 内置朝代系（夏商周式）、技术系（青铜时代式）、神话系（洪荒量劫式）三套纪元命名器，可混用但标注体系。
6. POD 卡片 → 架空世界引导创建"分歧点"实体：时间、地点、分岔事件、蝴蝶效应范围、与参照现实的对照说明。
7. 断代史/通史双视图 → 历史条目可按纪元切片（断代）或全时段贯通（通史）两种视图组织。

## 5. 对御书设计的启示

**数据结构建议**
- `Era { name_外/内, start, end, 分期依据: 政权|技术|神话|宗教, 变化机制事件ID, 状态向量: {技术, 政体, 人口, 贸易, 宗教}, 史观标签 }`；世界实体挂 `主导史观` 与可选 `POD` 字段。
- 历史条目统一 `canon_level: 作者定稿 | 正史 | 野史 | 讹传` 元数据，与 A01 的创世记录双层结构共用同一套字段。

**功能建议**
- 新建世界的"史观向导"：三选一（线性/循环/退化）后给出对应的纪元骨架模板与典型分期数量建议。
- "停滞检测"报告页：输出各纪元状态向量对比雷达图，直观暴露万年不变的世界。
- POD 对照视图：架空世界中并排显示"参照现实线"与"虚构线"的分岔节点。

**校验规则建议**
- Era 区间允许相邻但不允许重叠与留白（留白警告而非报错，鼓励补史）。
- 循环史观世界：每个"轮回纪元"必须至少存在一条"机制类事件"（气候/财政/凝聚力变化）。

**AI 提示词建议**
- "以年鉴学派三层时间（结构/局势/事件）分别为纪元 X 写三句话概述"，作为纪元条目的生成骨架。
- "为该纪元边界事件分别写出：作者真相、官方史书记载、民间传说三个版本"。

## 6. 领域内子主题备忘（可选）

- 世界内史学的体裁学：正史/野史/起居注/实录等中国史学体裁如何映射为虚构史书类型。
- 历史纪年法体系：年号、王位纪年、神历、创世纪元的换算与命名规则（与 C02 历法引擎衔接）。
- 辉格史观作为"世界内偏见"素材：胜利者书写的进步叙事本身可以是剧情素材。
- 神话分期与现实分期的接口：神话时代年表如何与王朝年表对接（洪荒流的具体做法）。
