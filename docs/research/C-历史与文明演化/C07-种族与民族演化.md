# C07-种族与民族演化

> 类别：C-历史与文明演化 ｜ 世界构建金字塔层级：L4 文明层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

种族与民族演化研究虚构世界中"人"的分类与流变，包含两条线：种族（species，生物学层面的智慧物种与非人种族）与民族（ethnicity，文化层面的族群认同），以及二者的起源、迁移、融合、分化、冲突与偏见。它与 B06 物种设计的区分：B06 管生理构造与生态位（"它靠什么活"），本领域管文明化之后的族群社会事实（"他们如何看待彼此"）；与 C10 的区分：C10 管单个文化的内部细节，本领域管族群之间的关系与长时段演化。它是"物种"走向"文明主体"的转换器，也是角色出身、对话称谓、冲突动机的高频引用源。

## 2. 核心知识框架

1. **种族/民族双层模型**：Race 是生物学事实（生育兼容性、体质、寿命），Ethnicity 是文化事实（语言、习俗、认同）。现实世界只有后者；奇幻世界把两者混编时必须分开建模——"精灵"是种族，"高等精灵/森林精灵/堕落的灰精灵"更像民族。
2. **Planet of Hats 反模式**：TV Tropes 定义为"整个种族共享单一特征"（精灵全优雅、兽人全野蛮）。Mythcreants 的解法：特征来自环境与历史而非天性、给种族加内部多样性（派系、异见者、地域差异），并把"天生性格"改写为"外界刻板印象"——读者视角的偏见而非客观设定。
3. **内部多样性的操作化**：World Anvil 等社区共识是给每个种族至少 3 个亚群体并制造内部分歧；SFWA 的多元文化指南强调不要把现实民族扁平化套用，警惕"异族=反派"的种族主义回声。
4. **民族演化机制**：Azgaar 的 culture sets 展示了算法化路径——以文化源点为种子按地形气候扩散聚类生成文化区。现实的迁移、隔离、融合、同化、征服可映射为挂在时间轴上的事件类型。
5. **体质-环境对应**：肤色、体型、耐寒等特征应回溯 B 类起源地气候；长距离迁移产生渐变（cline）而非硬边界，"一山一族"的整齐分布不可信。
6. **东方范式**：《山海经》以"形体+方位+神异+贡物"的条目式记录远方方国与异兽（羽民国、贯胸国），是族志式种族档案的东方原型；妖怪志怪传统还提供"种族=修行阶段"的流动性（人可化妖、妖可化人），种族边界可以是软的。
7. **种族关系与偏见主题**：通婚禁忌、纯血神话、替罪羊机制——种族主义可以作为主题被讨论，而不是设定里的默认装饰；"always evil"种族是近年社区重点反思对象。

## 3. 可转化为产品规则的关键实践

1. Race/Ethnicity 分离实体 → 种族条目只写生物事实并引用起源地；民族条目引用种族+语言+文化，允许多民族共享同一种族。
2. 亚群体底线 → 每个种族默认提供 3 个亚群体槽位（地域分支/教派分支/异见群体），留空触发"Planet of Hats 风险"lint。
3. 刻板印象字段分离 → "外界认知（偏见）"与"客观特征"分列两个字段，AI 生成时禁止把前者写成后者。
4. 族群演化事件枚举 → 迁移/征服/融合/分裂/同化/灭族六类事件挂 C02 时间轴，并联动语言（C09）与政体（C11）。
5. 体质一致性检查 → 外貌特征字段引用起源地气候带，明显不符则警告（可豁免，需填写解释）。
6. 方国条目模板 → 东方世界可选"山海经式"紧凑模板：形体/方位/物产/神异/贡物，一行一族，快速铺地图。
7. 种族关系矩阵 → 种族×民族的通婚容忍度、历史恩怨、互相称呼（含蔑称）字段，供对话生成与冲突生成直接引用。

## 5. 对御书设计的启示

**数据结构建议**
- `Race {生物分类引用B06, 体质特征[], 起源地引用, 寿命, 生育兼容性[], 超凡特征引用A类}`；`Ethnicity {种族引用[], 语言引用C09, 起源事件, 亚群体[], 对外关系[]}`——两者多对多，混血角色声明双族归属。
- `PerceptionBias {主体民族, 客体种族/民族, 内容, 真实度: 无稽|夸大|属实}`——偏见本身是可检索设定。

**功能建议**
- 种族关系矩阵视图：以热力图展示通婚容忍度与恩怨，点击格子展开历史事件依据。
- 族群迁移地图：按 Azgaar culture 层思路可视化民族分布随时代的变化，事件与地图动画联动。
- 方国快速铺档模式：表格化批量录入"一行一族"的山海经式条目，后续可展开为完整条目。

**校验规则建议**
- 天生性格 lint：种族条目出现"天性/生来/全部都"类全称判断且未标注为偏见 → 警告。
- 无起源 lint：任何 Ethnicity 必须有起源事件或迁入来源。
- 灭族时序检查：该族被记录灭族后仍有活跃角色的年代 → 报错或要求"幸存者"事件。

**AI 提示词建议**
- "为种族 X 写三个互相冲突的亚群体，每个回答'什么才是真正的 X'，并给出一个跨群体共识。"
- "把'兽人天生嗜血'改写为外界偏见，并给出真实的历史、地理与经济原因各一条。"

## 6. 领域内子主题备忘（可选）

- 混血儿的生理规则与文化认同（两套命名、两头不讨好的叙事位置）。
- 种族寿命差异对历史观与制度的影响：长寿种族作为活历史（联动 C01）。
- 妖怪修炼体系下的种族流动性与"化形"礼俗（联动 A02）。
- 使用现实民族原型的伦理边界与"架空距离"控制。
- 种族语言差异与翻译问题：通用语的存在及其政治含义。
