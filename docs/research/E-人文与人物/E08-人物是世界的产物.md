# E08-人物是世界的产物（出身/阶层/时代对人的塑造）

> 类别：E-人文与人物 ｜ 世界构建金字塔层级：L5 社会现状层 + 叙事层交叉
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

本领域研究**社会结构如何生产人物**：出身（地域/家族/阶层）、时代（物质条件/观念水位/制度）、行业（职业习惯/切口黑话）如何塑形一个人的行为逻辑、语言与欲望结构。层级定位特殊：它横跨 L5 社会现状层（物价、礼俗、阶层结构、律法等"世界的现状"）与叙事层（人物卡与正文），是"从起源构建世界"宗旨的核心交点——人物不是悬浮的设定件，而是世界各层参数的函数输出。边界区分：E02 管"人物是什么"，E08 管"人物为何必然如此"；日常生活的质感呈现归 E09。

## 2. 核心知识框架

1. **典型环境中的典型人物**（恩格斯《致玛·哈克奈斯的信》，1888）：现实主义=细节真实+真实地再现典型环境中的典型人物；"社会关系"构成人物外部的典型环境。这是"人物由世界生产"的经典理论锚点。
2. **人物性格三维度**（中国作家网文论）：外部环境维度与内心环境维度共同构成性格——学术上同样承认"环境内化"的过程。
3. **年代文的生产机制**（百度百科/网络文学研究）：以 1949—1990 年代为叙事时间，人物行为逻辑受票证制度、单位制、婚俗等时代参数硬约束——时代锚缺失即"年代文失真"。
4. **种田文的家宅叙事**（中国作家网，周敏）：从后宫到家宅、以"勤劳致富"为主线，人物的金钱观/时间观由小农经济逻辑塑形——阶层与生产方式直接生成行为模式。
5. **男频/女频的视角差异**（中国作家网）：同一题材下差异在叙事视角与爽点机制而非题材本身——社会结构还通过"读者结构"反向塑造人物的写法。
6. **平台分层与人物审美**（上观/番茄/晋江）：免费平台下沉读者偏好"赘婿/战神/甜宠"式人物起点设定；晋江的时代背景维度是官方"时代锚"字段的先例——市场即社会结构的镜像。

## 3. 可转化为产品规则的关键实践

1. 出身结构字段组（阶层/地域/时代/行业/家庭经济/教育路径） → 人物卡必填引用 L5 世界要素，不可手填自由文本（保证可校验）。
2. "出身→行为逻辑"映射 → 每条出身要素派生 1-3 条行为倾向、1-2 条语言特征、1 条金钱观/时间观（规则见下方交付）。
3. 时代锚检查（联动 E08 词汇域） → 角色禁用词汇域与其时代/行业锚绑定：年代文角色不得使用超出观念水位的词汇。
4. 阶层失真检测 → 金钱观/消费行为与出身阶层参数对照（赤贫者一掷千金需有剧情事件支撑）。
5. 观念水位线 → L5 层维护"本时代对 X（婚恋/尊卑/法律）的普遍观念"，人物逾越观念的行为必须标记"超前者/叛逆者"并触发后果推演。
6. 行业切口库 → 按职业生成专属词汇域与职业病动作（E07 声线卡的词汇域来源）。
7. "从世界长出人物"生成器 → 输入出身参数（村/阶层/年代/行业），AI 产出行为逻辑+欲望结构的草稿，作者修订后回写人物卡。
8. 社会流动轨迹 → 出身与现状的落差字段（赘婿/落魄贵族/寒门举子），落差本身生成初始冲突标签。

**"出身→行为逻辑"映射规则（核心交付）**

```yaml
origin_mapping:
  输入（引用 L5 世界要素）:
    阶层: 佃户 | 地主 | 官宦 | 市井 | 商贾 | 奴籍 ...
    地域: ref(村庄/城市)         # 气候→饮食→口音→忌讳
    时代: ref(年代锚)            # 决定物价/律法/观念水位
    行业: ref(职业)              # 决定切口、作息、身体痕迹
    家庭经济: 赤贫|温饱|殷实
    教育路径: 私塾|学徒|无
  派生规则:
    阶层 → 行为倾向: [对权威的默认姿态, 危机时的第一反应(囤粮/跑路/求人)]
    阶层 → 金钱观: 攒藏优先|流通生利|视金钱为污
    地域 → 语言特征: [口音词表(E07引用), 饮食禁忌, 邻里礼俗]
    行业 → 职业习惯: [切口黑话, 职业病动作, 作息]
    时代 → 观念约束: [婚恋观, 尊卑观, 法律风险表]
  冲突派生:
    出身落差 → 初始冲突标签(赘婿/寒门/落魄)
    两人出身差异对 → 预设摩擦场景(同桌不同食/称谓冲突)
  校验:
    失真检测: 行为/消费/词汇与出身参数矛盾 → 告警或要求事件支撑
```

## 5. 对御书设计的启示

**数据结构建议**
- L5 层新增 `社会现状要素`（物价表/观念水位/阶层结构/律法条目），人物卡的出身字段全部引用之；引用即获得该要素的全部下游校验。
- `origin_mapping` 规则存为可编辑规则表（默认模板+作品级覆写），派生结果（行为倾向/词汇域/金钱观）写回人物卡与声线卡。

**功能建议**
- "出身生成器"：在世界层任选村庄/阶层/年代组合，产出人物行为逻辑草稿——这是"从起源构建世界"宗旨的招牌功能。
- 观念水位时间轴：同一世界不同年代并存的观念参数对比，支持年代文与跨代题材。

**校验规则建议**
- 人物卡缺时代锚或阶层锚 → 阻断 AI 生成该角色的行为描写。
- 消费/称谓/观念越层：按映射规则比对，命中即告警并列出"可支撑的豁免事件"要求。
- 年代文类型标记作品：自动启用强校验（词汇域+物价+制度）。

**AI 提示词建议**
- 生成人物言行前注入"出身速览"：阶层姿态、金钱观、切口词汇、观念禁忌四行；指令 AI 用出身解释选择而非用现代默认值填充。
- 冲突场景生成时附带"双方出身差异对"标签，让摩擦从结构中自然长出。
