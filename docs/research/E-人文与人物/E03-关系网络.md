# E03-关系网络

> 类别：E-人文与人物 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

关系网络研究人物与人物之间的"边"如何被结构化、可视化并参与叙事校验：关系的类型学（血缘/恩义/敌对/暧昧……）、强度与方向、随剧情演变的时序、以及**知情可见性**（谁知道这段关系、读者是否知道）。边界区分：E02 是节点，E03 是边；E10 情感线是关系边的一个特殊子集（带节拍与结局承诺）；E08 关注关系背后的社会结构（家族/门派/阶层如何生产关系）。关系网络是御书"世界起源→人→情节"链条的中枢：大纲章节改动应能沿关系边传播影响。

## 2. 核心知识框架

1. **关系映射六步法**（WriteOnSisters）：从主角出发列关系→按功能分类（推动/阻碍/镜像）→标注冲突点→随大纲更新→定期查"孤立人物"→可视化。核心主张：关系图的目的是**暴露冲突与冗余**，不是画组织架构。
2. **Novelry 选角视角**：先问"每个角色为故事做什么"，关系是"人物功能的连线"；复杂关系（家族/师承/仇敌）需要台账化追踪。
3. **专用工具形态**：Soukanzu（带标签箭头的关系图）、Red Strings（面向小说家/编剧/世界观设定的关系图谱应用）、Milanote（人物关系板模板）——三者共同字段：两端人物、关系标签、方向、颜色/分组、自定义注释。
4. **雪花法第 5 步**：为每个主要人物写一段"以其为叙述者"的故事摘要——本质是要求作者从每条重要关系的**对侧视角**复述故事，强制关系双向化。
5. **AI 结构先例**：Dramatron 的人物集按层级组织并进入场景生成；Re3 的记忆机制可承载"关系状态"作为长期记忆槽位。
6. **社区实践**（r/authors 等）：写作者普遍用表格/看板追踪"谁认识谁、谁知道什么"；痛点是**知情差**（谁知道什么）比关系本身更易出错。

## 3. 可转化为产品规则的关键实践

1. 关系边数据化（见下方 schema） → `RelationshipEdge` 实体，两端引用人物卡。
2. 知情可见性字段 → 与 E02 前史秘密、E07 知识边界共用同一套"谁知情"枚举，驱动 POV 生成过滤。
3. 强度带符号数值 + 事件日志 → "关系演变时间线"自动绘制，检测突变（无事件支撑的强度跳变告警）。
4. 起止章节字段 → 关系死亡（决裂/死亡/失联）后自动停止该边的生成约束，防止"死而后复交"漏洞。
5. 孤立人物与冗余关系检测 → 图算法找"零边人物"与"功能重复边对"，联动 E04 配角管理。
6. 关系图 × 章节进度双视图 → 按章节回放网络演化（快照对比），服务长篇连载修改。
7. 雪花式双向校验 → 重要边要求填写"对方视角摘要"一句，未填提示。
8. 家族/组织自动聚合 → 血缘/从属边自动生成家族树与阵营图（联动 E08 阶层结构）。

**关系边 schema（核心交付）**

```yaml
relationship_edge:
  id: rel_001
  from: char_001            # 人物 id（有向）
  to: char_002
  类型: 血缘|婚姻|师徒|同门|上下级|盟友|敌对|仇杀|暗恋|情敌|债务|恩义|竞争|雇佣|邻居|自定义
  副标签: [亦师亦友, 名义夫妻]   # 可堆叠，复用网文关系词表
  强度: -85                  # -100~+100，负=敌对；正=亲密；|强度|≥60 进入"核心关系"
  方向性: 单向|双向           # 暗恋=单向；敌对可各自带强度(结构上拆两条)
  起始章节: ch_012            # 关系建立/揭示的章节锚点
  结束章节: null              # 决裂/死亡/退场时填写
  可见性:                     # 谁知情（枚举复用 E02 秘密系统）
    公开层: 全员知 | 圈内知 | 双方独知 | 仅单方知 | 读者知而角色不知
  演变日志: [{章节ref, 事件ref, 强度变化: -30, 备注}]
  伏笔钩子: [foreshadow_004]  # 可挂伏笔台账条目
```

## 5. 对御书设计的启示

**数据结构建议**
- 采用上文边 schema；强度与可见性为独立维度（敌对但公开 / 盟友但读者不知，均合法）。
- 演变日志引用事件/章节实体，形成"关系-情节"双向图谱，是后续一致性检查的基础。

**功能建议**
- 关系图画布：节点=人物卡（分级决定尺寸），边=类型着色+强度线宽；支持时间轴滑杆回放任意章节的网络快照。
- "知情差检查器"：按 POV 人物展开其可见关系子图，与 E07 知识边界共用；生成对白前自动裁剪。
- 雪花练习模式：为 |强度|≥60 的核心边生成"对方视角一句话"填空，完成后计入档案完成度。

**校验规则建议**
- 孤立人物：出场≥N 章仍零核心边 → 提示并入或裁撤。
- 幽灵关系：结束章节已填但后续章节出现该边互动 → 阻断或要求作者确认复活。
- 关系-情感线联动：标记为`暗恋/情敌`的边未关联 E10 CP 卡时提示。

**AI 提示词建议**
- 场景生成注入"在场人物两两之间的边摘要"（类型+强度+可见性），并对仅单方知情的关系给出"言不由衷"的写作指令。

## 6. 领域内子主题备忘（可选）

- 多角关系（三角/四角）的拓扑模式库与常见崩坏点。
- 家族树的代际建模与 E08 阶层/姓氏制度联动。
- 组织图（门派/公司/朝廷）从属边的自动推断。
- 关系强度自动估计：从正文对白/事件中提取（AI 反向解析）。
