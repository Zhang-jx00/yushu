# E01-人物弧光

> 类别：E-人文与人物 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

人物弧光（Character Arc）指人物在故事全程的**内在转变轨迹**：从起点信念到终点信念、从错误生存策略到（或进一步滑向）新的生存策略。本领域研究弧线的类型学（正弧/平弧/负弧）、转变的驱动机制（事件压力—内心反应）、转变节点的定位方法（与三幕/节拍表的耦合），以及弧光在主角、反派、配角上的差异化应用。边界区分：E02 人物档案建模是**静态快照**（起点状态），E01 是**动态过程**（状态如何变化）；E06 动机与欲望定义"驱动力是什么"，E01 定义"驱动力如何演变"。对"御书"而言，弧光是连接人物层与情节层的枢纽数据：大纲节拍改变时，弧线节点必须同步。

## 2. 核心知识框架

1. **Weiland 三弧线体系**（K.M. Weiland《Creating Character Arcs》系列）：以"人物相信的谎（Lie）/需要领悟的真（Truth）"为核心轴。正面弧：从 Lie 走向 Truth（拒绝 Truth→第一次试探→黑暗时刻→拥抱 Truth）；平坦弧（Flat Arc）：人物已持 Truth，用 Truth 改变世界，弧线转移到配角/世界上；负面弧：从 Truth 滑向 Lie，或陷在 Lie 中越陷越深（幻灭/僵化/邪恶三个子型）。Want（情节目标）与 Need（主题需要）的冲突是弧线引擎。
2. **英雄之旅的内在维度**：Reedsy 对 Vogler 12 阶段的讲解强调外在冒险与内在转变同构——"拒绝召唤"既是情节节点也是心理防御。
3. **故事曲线理论**：Vonnegut 把故事归纳为情绪起伏曲线（Man in Hole / Cinderella 等），为"弧光的情绪可视化"提供理论出处。
4. **McKee 选择论**：人物本性在压力下做出的选择才揭示并改变本性；场景价值翻转（生/死、爱/恨）是弧光的最小刻度。
5. **雪花法视角**：Randy Ingermanson 要求为每个主要人物写"一段式摘要"，含动机、目标、冲突、顿悟（epiphany）——顿悟即弧线终点的最早草稿。
6. **AI 模拟前沿**：Drama Machine（arXiv 2408.01725）用多智能体模拟人物动态发展，证明"弧线状态机"可以被参数化供 AI 生成时引用。

## 3. 可转化为产品规则的关键实践

1. 弧线类型枚举（正弧/平弧/负弧/混合弧/无弧-工具人） → 人物卡必填下拉字段，默认"待定"以强制作者思考。
2. Lie/Truth/Want/Need/Ghost 五字段 → 人物 schema 核心字段组，E02 引用。
3. 弧线节点打点（拒绝/试探/试炼/黑暗时刻/顿悟/验证） → 章节画布上的可拖拽标记，支持进度百分比。
4. 弧线阶段 × 结构节拍对齐检查 → 校验规则："黑暗时刻"未落在第三幕起点 ±15% 时提示。
5. 弧线一致性校验 → 若主角设为负弧，检测大纲是否存在"拥抱 Truth"式正弧转折并要求作者确认。
6. 每章弧光增量日志 → 每章结尾 AI 摘要"本章人物信念是否移动"，零移动章节连续 3 章以上告警（平弧除外）。
7. 反派弧线复用同 schema → E05 联动，负弧子型枚举（幻灭/僵化/邪恶）。
8. 弧光曲线可视化 → 按 Vonnegut 曲线绘制"情绪值/信念值"双折线，供诊断节奏。

## 5. 对御书设计的启示

**数据结构建议**
- 新建 `CharacterArc` 对象：`{arc_type: enum, lie, truth, want_ref, need_ref, ghost_ref, stage_pointer, beats:[{stage, chapter_ref}]}`，被人物卡与大纲双向引用；平弧人物需额外填 `truth_held` 与 `world_changed`。
- 弧线节点表允许"占位+待定"状态，但导出/生成前强制完成度检查。

**功能建议**
- "弧线追踪器"画布：横轴章节、纵轴信念值（Lie↔Truth 区间），支持把三幕/救猫咪节拍叠加显示，一眼看出弧线与结构的错位。
- 多人物弧线叠加视图：主角/反派/重要配角同图对照，检测"配角弧线抢戏"（斜率大于主角时提示）。

**校验规则建议**
- 结构-弧线对齐：黑暗时刻必须落在全书 65%-85% 区间；顿悟不得早于中点（混合弧需显式豁免）。
- 弧线-档案一致：负弧人物的 `truth` 字段不得为空且需写明"将失去什么"。
- 弧光停滞检测：连续 N 章人物信念值无变化且该人物非平弧 → 建议插入压力事件。

**AI 提示词建议**
- 生成场景时注入"当前弧线阶段卡"：人物此刻相信什么、抗拒什么、下一节点是什么，约束 AI 不写出超前的顿悟台词。
- 用 MRU 约束弧光微观呈现：感受→本能行动→言语的顺序（联动 E07）。

## 6. 领域内子主题备忘（可选）

- 混合弧（正弧主角+负弧伴侣）与双主角弧线同步问题。
- 救赎弧（redemption arc）的细分节拍与"代价"设计。
- 网文"反弧光"传统：升级流主角信念基本不变、以能力曲线替代信念曲线——御书需要"能力曲线"作为弧光的替代物。
- 短篇/单卷人物的最小可行弧线（3 节点版）。
