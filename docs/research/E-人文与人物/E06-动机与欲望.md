# E06-动机与欲望（Want/Need）

> 类别：E-人文与人物 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

动机与欲望研究人物"为什么行动"的分层结构：**Want**（有意识追求的外部目标，直接驱动情节）与 **Need**（无意识的内在缺乏，承载主题），以及两者的冲突如何构成内在矛盾；延伸到动机→目标→行动→反应（MRU）的传导链。边界区分：E01 关注转变的时间过程，E06 关注转变的**驱动力定义**；E02 把 Want/Need 存为字段，E06 定义这些字段的填写方法学与校验逻辑。对御书而言，Want/Need 是"人物→情节→主题"三层的耦合件：AI 生成情节时若只满足 Want 不触碰 Need，产出即"有事件无灵魂"。

## 2. 核心知识框架

1. **Want/Need 经典定义**（Weiland）：Want 是情节目标的直接等价物（有意识、可陈述、可失败）；Need 是主题价值的直接关联物（常无意识、与 Lie 相对）；人物弧的引擎 = "追求 Want 无法满足 Need，直至顿悟"。
2. **Want vs Need 与冲突**（The Novel Smithy）：外部 Want 制造情节冲突，内部 Need 制造人物冲突；两者的"错位"（want 解决了还是不幸福）是深层戏剧性的来源。
3. **人物之谎的推导**（Dabble）：Need 常以 Lie 的对立面出现——先定义人物相信什么谎，Need 即"谎的解药"。
4. **雪花法五要素**：动机（抽象）→目标（具体）→冲突（阻碍）→顿悟（Need 的实现）→叙述线；把动机写成"一句抽象+一件具体"的双层结构。
5. **反派变体**（iWrity）：反派同样有 Want，区别在于 Belief 扭曲——动机结构对正反派通用，仅解释框架不同。
6. **MRU 传导链**（Swain/Weiland）：动机刺激→感受→本能/行动→言语；动机在句子级也应该"先因后果"，保证读者体验因果顺滑。
7. **网文回报机制**：webnovel-handbook"每章承诺-进度-回报"——主角的 Want 必须被切成可连载的回报颗粒；期待感优先于爽点密度（S1 备忘）。

## 3. 可转化为产品规则的关键实践

1. Want/Need 双字段+冲突说明 → 人物卡必填（主角/重要配角），附"为什么 Want 无法满足 Need"一句话。
2. 动机双层结构校验 → Want 字段必须可拆为"抽象动机+具体目标"两行；只有目标没有动机时告警"纸片人"。
3. Want→情节耦合检查 → 主线大纲的每一幕至少推进一个核心人物的 Want 进度；进度表自动打点。
4. Need→主题耦合检查 → 全书 Need 主题词汇总生成"主题云"，与结局场景的兑现度人工确认。
5. 反派 belief 字段复用同一结构 → want/belief/want 的正当性叙述（联动 E05）。
6. MRU 句级约束 → AI 生成时按"刺激→感受→行动→言语"顺序产出反应段，校验器检测因果倒置。
7. 期待感管理 → Want 的重大兑现点（打脸/夺冠/告白）前必须有至少一个"预告章"（承诺），参考"删爽点并延后→追读率提升"实证。
8. 多人物欲望矩阵 → 所有核心人物的 Want 两两对照，检测"全组无人相争"的动力真空。

## 5. 对御书设计的启示

**数据结构建议**
- `Motivation` 对象：`{want: {abstract, concrete_target}, need: {abstract, opposing_lie_ref}, conflict_note, progress_log[]}`；主角/反派各强制一份，配角可选。
- Want 的 `concrete_target` 允许分叉（阶段目标链），每段挂章节区间，驱动进度条。

**功能建议**
- 欲望矩阵视图：行=人物，列=当前 Want/Need/进度%，按章节回放；一眼找出"动力真空章"。
- 期待感台账：重大兑现点自动生成"预告检查"——兑现前 3 章内是否出现过承诺/铺垫。

**校验规则建议**
- 主角 Want 与主线大目标（C 类情节层）未建立引用 → 警告"人物与主线脱钩"。
- Need 全书零兑现（结局场景未触碰主题词）→ 结局类型提示。
- MRU 顺序检查：AI 生成文本中"刺激后先说话后感受"的段落给出修订建议。

**AI 提示词建议**
- 生成章节时注入"本章欲望进度指令"：谁在本章推进 Want、谁受挫、Need 是否需要一次微妙的暗示（不点破）。
- 反派场景生成固定附带 belief 正当性模板，避免 AI 把反派写成无动机捣乱者。

## 6. 领域内子主题备忘（可选）

- 集体欲望（宗门/家族/文明级目标）与个人 Want 的嵌套。
- 欲望的阶段性更替（目标升级链）与"背叛旧目标"的戏剧处理。
- 无欲望主角（淡人/摆烂人设）在种田文、慢节奏日常文中的替代动力（外部事件+守护对象）。
- 读者代入视角下的欲望错位：主角 Want 与读者爽点不一致时的缝合策略。
