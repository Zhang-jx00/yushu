# E07-人物声线一致性

> 类别：E-人文与人物 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

声线（Character Voice）指区分不同角色言语与内心叙述的可辨识特征：词汇选择、句长节奏、口头禅、称呼系统、语气习惯与**知识边界**（角色只能说其知道的事）。本领域研究：如何为角色定义声线、如何在长篇连载中保持声线不漂移、以及如何用规则+AI 双轨检测声线一致性。边界区分：叙述者声线（作者文风）归入 F 类文风领域；POV 纪律（谁的眼睛/谁的内心可写）作为声线的上游约束在此一并覆盖，因其与"知识边界"同源。

## 2. 核心知识框架

1. **声线风格圣经**（webnovel-handbook）：把每个主要人物的言语风格写成结构化"圣经"文档（词汇偏好、句式、禁词、称呼表），生成与校验共用——中文网文工具化声线的直接先例。
2. **MRU 言语位置**（Swain/Weiland）：言语是"感受→本能行动→言语"反应链的第三环；声线不只是"说话像谁"，还包括"在情绪压力下怎么说"——反应顺序本身也是声线。
3. **闻声知人**（Reedsy 对白指南）：撤掉对话标签仍能认出说话人是对白的第一标准；手段包括词汇域、句长差、语气词、标点习惯。
4. **声线采集法**（Now Novel）：偷听真实语音、按"该角色不会用的词"反向删改、避免音译口音等刻板化处理。
5. **POV 纪律**（Anne R. Allen / Darling Axe）：一场一人称（one head per scene）；头跳（head-hopping）破坏的正是声线与知情边界——"角色能否知道/看到/感觉到"是社区检验口诀。
6. **长文一致性技术**（Re3/Dramatron）：把人物设定放入持久记忆并在生成时按需检索，是对"声线漂移"的工程对策。

## 3. 可转化为产品规则的关键实践

1. 声线卡模板（词汇域/句长区间/口头禅/称呼表/禁词/语气习惯） → 人物卡外挂对象，AI 生成与校验器共用。
2. 闻声知人测试 → 工具内置：遮蔽对话标签让作者盲认说话人，识别率即声线区分度评分。
3. 知识边界校验 → 对白内容比对该角色的"知情集合"（出场章节∪关系可见性∪情报事件），越界即告警。
4. POV 一场一人检查 → 场景卡声明 POV 人物；检测正文中出现非 POV 人物的内心直述（"她想""他暗忖"）。
5. 称呼一致性 → 全书称呼映射表自动回检，A 对 B 的称呼随剧情升级（陌生→挚友）须有过渡事件支撑。
6. 口头禅配额 → 每角色 0-3 个高频特征词；超过配额判定"刻板化"，低于下限不强制。
7. 时代/方言词汇过滤（联动 E08） → 角色词汇域与其出身/时代锚绑定，越代词汇告警。
8. 声线漂移检测 → 按卷统计各角色句长分布与词频，分布突变（非剧情原因）提示复核。

**声线检查规则（核心交付）**

```yaml
voice_rules:                        # 每角色一份
  口头禅: ["啧", "有意思"]           # 0-3 个；生成时注入，检测漂移
  句长: {平均区间: [8, 18], 超限告警: ±60%}   # 学者 18-28 字，莽夫 4-10 字
  称呼表:                            # A→B/C/D 映射，随剧情阶段可变
    对主角: ["那小子" → "兄弟"]      # 需挂过渡事件
    对长辈: ["老东西"]
  词汇域: {惯用: [商贾切口, 算账比喻], 禁用: [现代学术语]}   # E08 交叉
  语气习惯: {句末语气词: "罢了", 标点癖: 反问多}
  知识边界: {不可提及: [未出场事件, 他人秘密(可见性≠公开)]}
  MRU 检查: 言语必须居于反应链第三环
```

## 5. 对御书设计的启示

**数据结构建议**
- `VoiceCard` 按上文 schema 独立存储并被人物卡引用；`称呼表`与 E03 关系边共享"阶段"轴（关系演变触发称呼候选变化）。
- `知情集合` 作为派生视图实时计算：出场章节∪情报事件，供生成前过滤。

**功能建议**
- 声线盲测小游戏：随机抽 10 句历史对白遮名让作者认人，低分角色的声线卡进入"待强化"队列。
- 声线卡自动草拟：用 AI 从该角色已有台词统计句长/词频/口头禅，生成草稿供作者修订。

**校验规则建议**
- 四道硬校验：知识边界越界（阻断）、非 POV 内心直述（警告）、称呼表外称呼（警告）、禁用词汇域命中（警告）。
- 群像同场检查（联动 E04）：同一场景内声线相似度＞阈值的两角色须错开台词量或提示强化区分。

**AI 提示词建议**
- 生成对白时逐角色注入声线卡摘要（口头禅、句长、称呼、语气），并附加"本场知情范围"；要求输出保留说话人标记以便回检。
- 修订模式固定提示词："先查称呼与知情，再调语气，最后润色修辞"——与校验器检查顺序一致。
