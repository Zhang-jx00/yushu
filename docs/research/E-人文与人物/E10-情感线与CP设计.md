# E10-情感线与 CP 设计

> 类别：E-人文与人物 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

情感线（感情线）与 CP（Character Pairing）设计研究"两人（或多人）关系作为一条独立情节线"的构造方法：相识→贴近→受阻→黑暗时刻→重大姿态→结局的节拍结构、tropes（先婚后爱/破镜重圆/宿敌成双等）的标签化复用、感情线与主线的交织方式，以及无 CP 模式。边界区分：E03 管"关系边的数据"，E10 管"某条特定关系线的戏剧结构"；甜宠/纯爱/百合等中文语境频道与标签体系是本领域的本地化重点。在御书中，情感线应是**可开关的独立层**——S1 种子库结论：感情线形态应做独立开关而非频道属性。

## 2. 核心知识框架

1. **Romancing the Beat 四阶段**（Gwen Hayes，Campfire/First Draft Pro 解读）：Setup（相识 meet-cute+黏合理由 adhesion）→Falling（靠近与升温）→Retreating（退缩：黑暗时刻/误解/秘密曝光）→Resolution（重大姿态 grand gesture+结局）；大 gesture 要求人物付出牺牲，是"人设性动作"而非通用桥段。
2. **Tropes 词表**（Reedsy 100+ Romance Tropes）：meet-cute、enemies-to-lovers、fake dating、second chance 等——tropes 即"情感线模板的标签包"，可组合（先婚后爱+双向暗恋）。
3. **中文标签体系**（晋江/豆瓣）：晋江五层正交分类（原创/衍生×言情/纯爱/百合×时代×题材×风格）+无 CP 子分类；豆瓣阅读情感标签（破镜重圆、先婚后爱、社会派）——中文 tropes 已平台化，可直接建模为受控词表。
4. **无 CP 与群像形态**（NGA 观察）：纯爱频道含 BL 与无 CP 子分类；无 CP 文以事业线/群像替代感情线——产品需一等公民支持。
5. **读者承诺词**（上观/番茄）：甜宠、双洁、HE/BE——这些是**对读者的契约**，写崩即口碑崩盘，必须显式登记并校验兑现。
6. **节奏经验**（S1 知乎/种子备忘）：感情线推进可借用爽点算法（压抑蓄力→暗示期待→释放）；感情线的黑暗时刻宜与主线危机交织以互相抬升。

## 3. 可转化为产品规则的关键实践

1. CP 卡实体 → 双方人物引用、关系边引用（E03）、tropes 标签包、节拍表、结局承诺（HE/HFN/BE/开放）。
2. 情感节拍表（四阶段 12 拍） → 章节画布打点：初遇/黏合/初次靠近/升温/误会/秘密/黑暗/牺牲式姿态/结局确认，缺关键拍提示。
3. tropes 受控词表 → 采用"中文平台标签+英文 tropes"双语词表，支持组合标签与反查（标了"破镜重圆"必须存在"破裂事件"）。
4. 黑暗时刻与主线交织校验 → 感情线 Retreating 拍与主线低谷的章节距离检测，过远提示"两条线各玩各的"。
5. 承诺词登记 → 双洁/甜宠/无误会等承诺写入作品元数据，生成与校验按承诺收紧（如"无误会"则禁用误会型黑暗拍）。
6. 无 CP 模式 → 关闭感情节拍表，E09 日常/E04 群像/事业线替代感情线位置。
7. 感情温度计 → 关系强度（E03）按章节可视化，升温/降温与节拍对齐检查。
8. 伏笔联动 → 定情信物/旧约/初遇回环登记为伏笔条目，结局前回收提醒。

## 5. 对御书设计的启示

**数据结构建议**
- `CPLine` 对象：`{members: [char_id, char_id], edge_ref, tropes: [受控词表], beats: [{stage, chapter_ref?}], ending_promise: HE|HFN|BE|开放, 承诺词: [甜宠, 双洁, 无误会], 无CP: bool}`；与 E03 关系边共享强度数据但独立承载戏剧节拍。
- tropes 词表带 `前置事件类型` 与 `结局约束` 元数据（"破镜重圆"→前置需破裂事件；"先婚后爱"→起点为婚姻事件）。

**功能建议**
- CP 线画布：四阶段泳道 + 章节滑杆，感情温度计（E03 强度）叠加显示；支持多条 CP 线并行与交叉点标注。
- trope 组合器：勾选标签（先婚后爱+宿敌+追妻火葬场）自动生成节拍草稿与潜在黑暗时刻清单，作者确认后入线。
- 无 CP 作品模板：隐藏感情节拍，显式启用事业线/群像线占位。

**校验规则建议**
- trope 一致性：已标 tropes 的前置事件缺失 → 阻断发布；结局承诺（HE）与最后节拍不符 → 告警。
- 承诺词兑现：标"无误会"作品出现误会型 Retreating 拍 → 强提醒；标"甜宠"作品黑暗时刻占比超阈值 → 提示。
- 感情线-主线交织：两线低谷相距 >N 章 → 提示互相借力。

**AI 提示词建议**
- 生成感情戏时注入：当前节拍阶段、双方 tropes 约束下的行为逻辑（宿敌线的示好须带别扭感）、承诺词红线、双方声线卡；禁止 AI 引入与已标 tropes 冲突的桥段。
