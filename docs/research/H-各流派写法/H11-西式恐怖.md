# H11-西式恐怖（哥特 / 克苏鲁 / 宇宙恐怖）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究西方恐怖谱系三大支柱的写法：哥特恐怖（古宅家族、疯狂与家族秘密、恐怖与浪漫交织）、宇宙恐怖/克苏鲁（未知与人类渺小、禁忌知识、不可名状之物）、民俗恐怖（孤立社群+乡土环境+扭曲信仰，作为与 H10 的对照系）。另覆盖心理恐怖、躯体恐怖等子类供混搭。边界：中文语境的本土化写法归 H10；规则怪谈作为叙事装置归 H12；docs/05 §8.1 已给出子类映射表（cosmic/gothic/folk/psychological/body → 民俗志怪+黑深残/虐恋），本文档补足写作技法侧。与中式恐怖的根本差异：恐惧来源是宇宙冷漠、认知崩塌与家族罪孽，而非人情伦理与规矩。

## 2. 核心知识框架

1. **宇宙恐怖五要素**（Dabble《How to Write Cosmic Horror》）：存在性恐惧而非血腥；不可知性（对不可知事物的认知导向疯狂）；人类渺小（人在冷漠宇宙力量面前如虫子可被碾碎）；异形存在（eldritch abomination、旧日支配者级神祇）；悲剧结局（死亡/疯狂/孤立，威胁终将复苏）。
2. **经典套路与写作要点**：禁忌知识（求知即惩罚）、古老文本与神器（连接两个世界的通道）、孤立（心理+物理双重隔绝）、不可靠叙述者；主角通常是理性的求知者（学者/科学家），面对的力量对其漠不关心——"角色对抗超自然"而非角色对抗角色。Writer's Digest 三要点：超越"让可爱角色陷入危险"；主角必须对"某件大事"是错的——世界观崩塌本身就是恐怖。
3. **写作戒律**：不要解释一切（Royal Road 社区共识：解释越多恐怖越少）；敬畏感优先于血腥（awe over dread over gore）；TV Tropes 警告：不要把宇宙实体硬塞进无关故事而不做整合。
4. **哥特双支柱**（畅销哥特作家 Laura Purcell 访谈）：atmosphere（场景自带"被诅咒的重量"，地点本身像闹鬼）+ ambiguity（超自然事件保留自然解释的余地）；经典元素=阴郁天气、衰败建筑、家族秘密、疯狂遗传、恐怖与浪漫交织。
5. **民俗恐怖三要素**（Wikipedia: Folk horror）：孤立社群+乡土环境+扭曲的信仰/习俗；与 H10 的差异在于视角——西式民俗恐怖的恐怖来自"社群本身就是加害者"（如《异教徒》），而非"禁忌规则约束个人"。
6. **子类谱系**（NoFilmSchool 35 恐怖子类）：psychological（偏执/不可靠叙事）、body（躯体变形恐惧）、slasher（最终女孩套路，常用作无限流副本素材）——为混搭与副本设计提供菜单。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 神话体系预设"不可名状原则"：旧日存在不设数值化属性与完整外观 → 力量体系卡在恐怖包下自动降级为"现象记录"。
2. 认知代价机制：设定"知道越多越危险"的全局规则（理智/人性值）→ 世界向导的恐怖包预填项。

**设定卡 schema 扩展（西式恐怖特有卡）**
3. 禁忌知识卡（文本/神器：内容残缺度/阅读代价/已读者下场）→ 宇宙恐怖的核心道具。
4. 异形存在卡（只允许写现象与目击侧写：目击记录/间接痕迹/幸存者证言；禁全貌字段）。
5. 家族秘密卡（哥特：罪孽/世代惩罚/披露节奏表——何时透露、透露到哪一层）。

**校验规则**
6. 不可名状校验：对旧日存在的描写若出现完整外观或能力数值 → warn"神秘感泄压"。
7. 认知代价守恒：获知真相/接触禁忌知识必须伴随理智或人性损失 → error。
8. 含糊度校验（哥特）：超自然事件若无自然解释的留白通道 → warn"哥特含糊性不足"。

**写法指南与节拍**
9. 宇宙恐怖节拍表：理性求知者 → 异常累积 → 世界观崩塌（主角发现自己是错的）→ 孤立 → 悲剧收束（威胁复苏钩子）。
10. 恐怖情绪五级阶梯：日常 → 违和 → 恐惧 → 敬畏 → 绝望；逐级递进不可跳级，gore 只允许出现在低阶梯位。

**读者期待与雷点**
11. 期待=敬畏感/未知压迫/氛围沉浸/世界观的真相分层揭示；雷点=解释一切、主角光环战胜旧日存在、以血浆代替 dread、设定堆砌压过剧情（docs/05 §8.3 克苏鲁流雷点同源）→ taboos 清单。

**AI 提示词倾向**
12. 生成旧日存在相关场景时强制"感官侧写+缺失感"模板（只写声音/影子/反应，不写本体）；提示词禁令：不给怪完整描述与数值。
13. 不可靠叙述者模板：叙述与"事实层"分离存储，生成时按视角注入已知/未知矩阵（联动 H13 线索矩阵）。

## 5. 对御书设计的启示

**数据结构建议：西式恐怖派系包核心卡 schema**

```yaml
# schemas/异形存在卡.yaml —— 不可名状原则的结构化落地（西式恐怖特有）
extends: core/setting-card
fields:
  name: {type: string}           # 称谓（可以只是"那东西"）
  manifestations: {type: array}  # 目击侧写：声音/影子/气味/幸存者证言（允许）
  true_form: {type: null}        # 禁止字段：完整外观与数值（schema 层面不提供）
  knowledge_cost: {type: string} # 认知代价（理智/人性损失规则）
  awakening: {type: object}      # 苏醒条件与复苏钩子（结局用）
```

**功能建议**
- 恐惧分级器：按五级情绪阶梯给章节标注当前层级，检测跳级。
- 真相分层视图：家族秘密卡/禁忌知识卡按"披露节奏表"生成揭示时间线，防止一次性泄底。

**校验规则建议**
- `no-true-form`：检测对旧日存在的全貌描写（warn）。
- `knowledge-has-price`：角色获知真相后若无状态损失 → error。
- `gothic-ambiguity`：超自然事件章末若无自然解释岔口 → warn（哥特包启用）。

**AI 提示词建议**
- 恐怖包提示词附加禁令块："不解释一切；敬畏优先于血腥；旧日存在只写侧写"。
- 生成哥特场景时注入氛围双要素清单（场景重量+含糊性），强制景物衬托先行。
