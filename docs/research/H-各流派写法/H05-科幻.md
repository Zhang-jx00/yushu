# H05-科幻（星际 / 机甲 / 赛博朋克 / 废土）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"科幻"世界维的写法，覆盖四个主要子类：星际（太空歌剧，帝国/舰队/权谋）、军事科幻（未来战争与士兵视角，含机甲）、赛博朋克（high tech, low life）、废土（文明崩塌后的生存与秩序重建）。对应 docs/05 世界维"科幻"条目与 §8.1 SF 子类映射（space opera/hard SF/cyberpunk/post-apocalyptic/military SF）。与 H01/H04 的边界：科幻的合法性来自科技自洽与因果推演，"科技水平前后矛盾"是第一雷点；世界观构建先于情节是其区别于网文其他大类的工程特征。

## 2. 核心知识框架

1. **硬度光谱**：硬科幻（真实科学推演）—软科幻（社会科学命题）—太空歌剧（大尺度冒险权谋）共用一个连续谱；御书应以"硬度"字段让作者声明自洽等级，决定校验强度。
2. **军事科幻要素学**：七要素框架——州际冲突史背景、政治/战略/战术的正确配比、写实军人塑造（Dan Koboldt：军衔纪律、恐惧与疲惫、命令链）；世界构建被 MasterClass 列为军事科幻第一要素；指挥层级可参照 Worldbuilding Stack Exchange 的军事结构问答建模。
3. **太空歌剧分层法**：分层构建银河——星地理（星区/航线）、政治（帝国/联邦/巨企）、技术（对社会的塑造）、文化历史四层，并"建了就不许改"（Laterpress 一致性原则）；帝国等结构参照历史但不可镜像（SFWA）；宏大冲突必须落到个人利害（Chapter Blog）。
4. **赛博朋克母题学**：核心命题"high tech, low life"（Campfire Codex 定义：尖端科技与社会溃败的对照）；必备母题=巨企治国、黑客、身体改造、城市垂直分层、技术分配不均（World Anvil 十大母题、r/worldbuilding 社区共识）。
5. **废土工程学**：世界构建先于情节（beehiiv 指南）；末世起因决定新社会规则（Zainah Yousef：结构优先于景观）；生存物流（水/食物/燃料）是冲突引擎；"废墟是失落更好世界的痕迹"（r/worldbuilding）。
6. **硬科学参考**：Atomic Rockets（Project Rho）是飞船设计/太空战/轨道力学的事实标准参考，连软科幻写作者也被社区推荐一读。
7. **网文特有变体**：黑科技流/科技树流（论文-专利-量产循环，docs/05 §8.3）与机甲竞技化，可视为本维与"系统流/黑科技流"手法维的叠加。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 科技树基线先行：列出"有什么技术/没有什么技术"及其连锁社会影响 → 世界向导第 1 步生成科技树卡（缺失技术同样入卡）。
2. FTL/通信规则一次性定死（是否超光速、延迟多少、代价）→ 全局常量，进项目级"物理常数表"。
3. 废土项目必填"末世起因→新规则"因果链 → 世界预设模板。

**设定卡 schema 扩展（科幻特有卡）**
4. 科技树卡（tier/前置依赖/解锁的社会影响）→ docs/05"科技树卡"落地。
5. 星舰/机甲卡（规格/乘员/武器/能耗/维护短板）→ 战斗与后勤情节物料。
6. 巨企/势力卡（业务版图/武装/与政府关系）+ 文明等级卡（卡尔达肖夫式刻度）。
7. 义体改造卡（功能/排异/维护成本/人性代价字段）→ 赛博朋克专属代价建模。
8. 废土物资卡（水/粮/燃料/弹药：存量与消耗率）→ 生存压力引擎。

**校验规则**
9. 科技一致性：已出现科技凭空消失/使用未解锁前置的科技 → error。
10. 物理约束：违反已设定光速/通信延迟的情节 → error（可按硬度字段降级为 warn）。
11. 指挥链校验：下级越级下达战术命令且无授权说明 → warn。
12. 物资守恒：消耗品不减、无限弹药 → error（废土/军事科幻共用）。

**写法指南与节拍**
13. 军事任务循环：简报-行动-伤亡-复盘 → 节拍表模板。
14. 太空歌剧双尺度节拍：舰队战（文明尺度）与主角个人利害交替推进。
15. 废土物资压力节拍：每个安全期后必须安排一次短缺危机。
16. 赛博朋克"一单一命"结构：委托-背叛-反噬，每单付出人性/身体代价。

**读者期待与雷点**
17. 期待=想象力震撼、设定自洽、专业质感；雷点=科技前后矛盾、士兵超能力化、废土写成风光片、赛博朋克只剩霓虹没有代价 → taboos 清单。

**AI 提示词倾向**
18. 提示词强制注入"当前科技树层级+禁用技术清单+物资余额"→ 防科技漂移与物资通胀。
19. 设定揭示遵循"只给必要信息，留白让读者推断"（NCW 原则）→ AI 输出的信息密度控制参数。

## 5. 对御书设计的启示

**数据结构建议：科技树卡（科幻派系包第一卡）**

```yaml
# schemas/科技树卡.yaml
extends: core/setting-card
fields:
  tier: {type: integer}
  requires: {type: array}          # 前置科技 id（依赖图，供校验与生成约束）
  social_impact: {type: string}    # 该技术对社会的连锁影响（worldbuilding 必填）
  banned: {type: boolean, default: false}  # 本项目明示不存在的技术（负面清单）
hardness: {enum: [hard, soft, opera]}    # 硬度声明 → 决定校验强度
```

**校验规则建议**
- `tech-dag`：科技使用事件必须命中已解锁节点，且解锁路径满足 requires 依赖（拓扑检查）。
- `physics-const`：光速/延迟/重力常量表一经设定，情节违反即按硬度分级报错/警告。
- `supply-conservation`：物资卡消耗流水守恒（废土/军事共用）。

**写法指南与节拍建议**
- 按子类挂载节拍包：milsf=任务循环；space opera=双尺度交替；废土=物资压力波；赛博朋克=委托反噬环。
- 每个节拍包附"伤亡/代价兑现表"：科幻的爽点必须支付逻辑代价。

**读者期待与雷点**
- taboos.yaml：科技矛盾/超能力士兵/风光片废土/无代价霓虹；附 Atomic Rockets 式"常识锚点"提示句。

**AI 提示词建议**
- 续写状态块："当前科技层级 {tier}｜禁用技术 {banned}｜物资 {supply}｜任务命令链 {chain}"；输出要求"新设定只以角色视角必要信息呈现"（NCW）。
