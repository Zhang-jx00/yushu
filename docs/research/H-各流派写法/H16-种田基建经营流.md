# H16-种田基建经营流（种田 / 基建 / 领主流 / 经营积累）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

种田基建经营流是以"经营、发展、慢节奏积累"为核心的手法维流派：主角从小处（种田/打猎/开荒/囤货）逐步做大，爽点来自"从无到有的建设里程碑"而非打脸反转。docs/05 §3 已有摘要条目（种田基建流/领主流），本文档合并调研种田文、基建文、领主流三个层次：种田文偏家宅与生活流（中国作家网周敏：从后宫到家宅叙事、"勤劳致富"主线）；基建文偏"改造世界"（修路建城、科技树、社会组织建设）；领主流偏势力经营（人口、资源、内政外交、战争）。社区流派梳理指出：几乎所有历史文都带基建种田元素，区别在侧重比例——因此本流派是高度可叠加的"底座手法包"。世界维跨度大（古代归 H09/H17、异世界归 H-异世界、末世基地归 H-末世文档），本文档只写经营手法共性：资源体系、建设里程碑、阶段冲突、积累感节拍。边界：年代文（1949-1990）有独立题材知识库，本文档不展开。

## 2. 核心知识框架

1. **三段式流派光谱**：种田（生活流，家宅/村庄/店铺，人情味与烟火气）→ 基建（改造流，路桥城防/工坊/制度，细节丰富且具备可操作性——红袖百科对典型基建流写法的定位）→ 领主（势力流，人口/兵源/疆域/争霸）。知乎书评总结领主类常见结构："前期奇幻冒险+中期经营种田精彩，后期领主争霸相对逊色、整体质量下降"——后期争霸稀释经营质感是该流派通病。
2. **标杆样本《临高启明》**：中国作家网分析其为"群像小说"——主角不是单一人物、叙事非单线，与其论坛集体创作的诞生方式直接相关；知乎的数据分析帖对正文 292 名元老做了业务领域/政治倾向/行政级别的统计。启示：种田基建流的复杂度上限是"组织叙事"——势力大了以后，叙事单位从主角变为组织与分工。
3. **资源体系是流派心脏**：粮食/人口/金钱/原料/技术五账本；基建流的"细节可操作性"指产量、工艺、成本链路经得起推敲（读者会算账）；雷区样本是"氮磷钾不出来"式常识错误——数据与设定要经得起推敲是平台答疑的明确要求。
4. **阶段冲突循环**：红袖百科样本（《开局朝廷送媳妇》）展示典型节奏——内政建设期 → 外部威胁（山匪/官府腐败/邻村倾轧）→ 解决并扩张 → 新一轮建设。冲突不是打断经营，而是"验证建设成果"的考卷：粮仓防了匪、制度经了灾。
5. **平台定位**：七猫作家专区答疑将种田/基建文定位为"剧情轻松简单、生活气息更足，男频女频都可以写，受众范围很大"的现实向品类；晋江、番茄、起点均有种田经商标签体系（晋江"种田经商"细分标签）——它同时是免费平台的流量品类与付费平台的口碑品类，写法要求随平台分化（免费端快节奏囤货爆点，付费端慢火细节）。
6. **日常戏写法**：日常不能只是"吃饭睡觉"——要有人物互动和伏笔，对话要推进剧情或揭示性格；积累感来自"微小改善的连续记录"（第一次丰收/第一间瓦房/第一笔外销），而非数值跳变。开篇要快速给出金手指/资源与初始困境，建立"从无到有"的期待。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 初始资源档案：开局的一亩三分地/一间铺子/一座村落的资源清单与负债表 → 世界向导首屏。
2. 环境承载卡：气候、地力、物产、季节历法 → 种田节奏（播种-收获周期）的时间坐标系，可复用 S3 的自定义历法思路。
3. 邻里与市场圈：周边势力/集市/官府关系图 → 外部威胁与销路的来源库。

**设定卡 schema 扩展（领地资源卡/建设里程碑）**
4. 领地资源卡（资源类型/存量/产能/消耗/存储上限）→ 五账本的产品化，支持按时间步长推演。
5. 建设里程碑卡（项目名/前置条件/工期/投入/产出/影响事件）→ "从无到有"爽点的登记单元。
6. 技术与工艺卡（技术项/所需材料/工序/失败风险/时代合理性标注）→ 基建流"细节可操作"的知识库载体。
7. 人情往来卡（人物关系/恩义/人情债务）→ 种田文烟火气的最小记录单元。

**校验规则**
8. 资源守恒校验：建设中消耗量 > 库存且无补充事件 → error"资源透支"。
9. 产能合理性：亩产/工期/人口劳力超出时代与土地承载力 → warn"数据穿帮"。
10. 工期冲突：同一时期人力被多个建设项目超订 → warn。
11. 里程碑空转：连续 N 章无任何建设进展或冲突事件 → warn"经营停滞，流水账风险"。

**写法指南与节拍**
12. 开局节拍：初始困境（缺粮/负债/流放）→ 金手指或资源起点 → 第一个可兑现的小胜利（三章内）→ 放大期待的新目标。
13. 阶段循环节拍：建设蓄力 → 外部考验（天灾/人祸）→ 成果兑现 → 势力扩容；每卷完成一次"村庄→镇→县→郡"级别的舞台升级。
14. 日常段落配比：每章至少 1 个"微小改善"记录点 + 1 次人物互动伏笔；日常戏占比高但不得连续两章无事件推进。

**读者期待与雷点**
15. 期待=积累的踏实感/建设成就感/烟火气人情味/技术降维打击/白手起家逆袭；雷点=数据常识错误、节奏过缓无冲突、后期争霸稀释经营质感、配角工具化、金手指资源凭空出现 → taboos 清单。
16. 男频/女频差异在侧重而非题材：男频偏基建领主扩张，女频偏家宅美食市井（docs/05 §5 与七猫定位一致）→ 派系包按频道给侧重预设。

**AI 提示词倾向**
17. 生成种田日常时强制注入"资源状态块"（当期库存/在途项目/季节）与"人情账"摘要，防 AI 写出凭空粮食与无来由的丰收。
18. 基建描写提示词要求"工序可复述"：输出须含材料-步骤-风险三要素；禁止直接给出超越时代的技术结论。

## 5. 对御书设计的启示

**数据结构建议：种田基建派系包核心卡 schema**

```yaml
# schemas/领地资源卡.yaml —— 经营流的资源账本（可按时间步长推演）
extends: core/setting-card
fields:
  ledgers:                       # 五账本：粮/人/钱/料/技
    grain: {type: number}
    population: {type: number}
    money: {type: number}
    materials: {type: object}    # 按原料细分
    tech: {type: array}          # 关联技术与工艺卡
  capacity: {type: object}       # 土地/仓廪承载力（合理性校验依据）
  era_baseline: {type: string}   # 时代产能基线（防数据穿帮）
```

配套：建设里程碑卡（prereq/duration/input/output/events）、人情往来卡（relation/favor/debt）。

**功能建议**
- 资源推演器：输入章节事件（丰收/匪患/徭役）自动结算五账本，产出"资源曲线+里程碑时间轴"。
- 舞台升级路线板：村庄→镇→县→郡的扩张路线图，每级挂里程碑卡与外部威胁预设。

**校验规则建议**
- `ledger-conservation`：资源透支/超产 → error。
- `yield-plausibility`：亩产、工期超时代基线 → warn。
- `labor-overbooking`：人力超订 → warn。
- `progress-stall`：连续 N 章无建设进展 → warn。

**AI 提示词建议**
- 状态块注入：库存/项目/季节/人情账四要素；AI 产出的建设描写必须含材料-步骤-风险。
- 按频道切换侧重预设：男频默认基建领主权重，女频默认家宅市井权重，共用手同一账本 schema。
