# H01-玄幻（东方玄幻 / 异世大陆 / 王朝争霸）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究男频第一大赛道"玄幻"的写法：架空东方高魔世界（异世大陆）中，以境界升级为主线、以打脸爽点为情绪引擎、以地图逐卷扩大为空间结构的类型。覆盖起点"玄幻"频道下的东方玄幻、异世大陆、王朝争霸三个主要子类。边界：不覆盖西方奇幻（H04）、修真体系（H02，境界虽形似但驱动机制不同）；手法维叠加项（系统流/废柴流/退婚流）在 docs/05 流派总表第 3 节，本文档只处理"世界维=玄幻"时的共性写法。玄幻是御书派系包的第一个落地对象，其境界体系卡与战力校验在 G06 已给出工程草案，本文档补足写法侧输入。

## 2. 核心知识框架

1. **境界体系结构学**：主流做法是"一到九大阶 + 第十阶（神/仙级）"，每阶内部再分小阶段（九星九层，或初期/小成/大成/圆满）；个性创新只能落在命名与细分逻辑上，否则沦为换皮。境界不只是背景板：每一重都应在剧情、战斗、资源获取上有实际作用（红袖添香《源海之主》"炼体九重"案例）。
2. **爽感机制**：爽感三要素=代入感/畅快成就/爽点；通用算法为"压抑蓄力→暗示期待→集中释放→新循环"，且期待感 > 爽点密度（有"删 1/3 爽点并延后，追读率 35%→67%"的实证）。
3. **节拍工程**：黄金三章=首因效应（平台编辑视角确认未过时）；每章保证一个情绪波动点；"叠加爽点"操作法；断章=情绪高点切断留钩。
4. **地图动力学**：地图逐卷扩大（村→城→国→大陆→界）是空间骨架；"地图越写越小"是公认雷点。王朝争霸子类在此之上叠加势力棋盘（宗门/王朝/家族）与领土收益逻辑。
5. **演化链**：《斗破苍穹》等定型的退婚流/废柴流开局 → 系统流叠加（面板数值化升级）→ 玩法化反套路（如"嘲讽-受击-升级"把打脸变成经验值，《最强的系统》）。流派自带年代字段，收录规范见 docs/05 §6。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 力量体系=世界底层法则，必须先于剧情建档（今日头条教程：设定明确境界划分与升级路线，作者才能"沿力量体系路线有序行文"）→ 世界向导第 1 步强制生成境界体系卡。
2. 大陆地理按"主角活动半径"分层预设 → 地图分卷解锁视图。

**设定卡 schema 扩展（玄幻特有卡）**
3. 境界体系卡（realms: name/tier/lifespan/combat_power，见 G06 YAML 草案）→ 派系包 schema_extensions。
4. 资源卡（丹药/法宝/天材地宝：品阶、稀缺度、对应境界）→ 打脸与机缘情节的物料库。
5. 宗门势力卡（等级/功法/供奉/资源产出）→ 王朝争霸子类的势力棋盘底座。

**校验规则**
6. 战力单调性：境界提升但战力下降 → error（G06 `power-no-regress` 规则）。
7. 地图范围校验：新卷核心冲突地理若完全落在已探索范围内 → warn"地图未扩大"。

**写法指南与节拍**
8. 黄金三章模板（身份困境+金手指亮相+首次小打脸）→ 开篇设计模板库（联动 F11）。
9. 升级爆点节拍表：每章 1 个情绪波动点、每 10-15 章一次小爆点、卷末大突破+大打脸 → 节拍表 YAML。

**读者期待与雷点**
10. 期待=升级感/装逼打脸/地图扩大；雷点=战力崩塌、地图越写越小、金手指通胀、反派降智 → 派系包 taboos 清单与雷点 lint。

**AI 提示词倾向**
11. 生成战斗/突破场景时强制注入"当前境界-对手境界-差距"上下文 → 提示词模板携带结构化状态。
12. 打脸名场面按"压抑细节回放→底牌揭示→围观反应→余波"四段生成 → 爽点模式库（G05 结构）。

## 5. 对御书设计的启示

**数据结构建议：玄幻派系包核心卡 schema**

```yaml
# schemas/资源卡.yaml —— 打脸与机缘的物料库（玄幻特有）
extends: core/setting-card
fields:
  kind: {enum: [丹药, 法宝, 天材地宝, 功法]}
  grade: {type: string}          # 品阶：黄阶/玄阶/…或一至九品
  rarity: {enum: [常见, 稀有, 绝世, 传说]}
  usable_realms: {type: array}   # 可使用的境界 tier 列表（用于校验越级使用）
  plot_hooks: {type: array}      # 关联的机缘/争夺事件
```

**校验规则建议**
- `realm-order`：境界 tier 单调递增且无重名（项目级 lint）。
- `power-no-regress`：直接复用 G06 战力防崩塌规则，玄幻为默认启用流派。
- `map-expansion`：卷级大纲生成后检查核心冲突地理是否超出上一卷范围。

**写法指南与节拍建议**
- 节拍表 YAML：`{cadence: {per_chapter: 情绪波动点, per_10_15ch: 小爆点, per_volume: 大突破+大打脸}}`。
- 开篇模板库内置"退婚流/废柴流/系统流"三种黄金三章变体，选派系包后自动挂载。

**读者期待与雷点**
- taboos.yaml：战力崩塌/地图收缩/金手指通胀/反派降智四条，每条附一句读者原话级解释（用于 AI 生成时的负面约束）。

**AI 提示词建议**
- 续写模板注入状态块："当前主角境界{realm}（战力{cp}），对手境界{rival_realm}，本章目标：{压抑|释放|蓄力}"；战力数据由境界体系卡实时提供，防止 AI 写出战力漂移。
- 打脸生成模板强制四段结构，并在结尾自动生成断章钩子候选。
