# H10-中式恐怖（民俗 / 志怪 / 灵异）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究民俗志怪世界维下的恐怖基调写法：以民俗禁忌（红白喜事、祭祀、节庆、风水行规）、志怪谱系（《搜神记》《聊斋志异》《阅微草堂笔记》一脉）与当代灵异/都市怪谈为素材源，以"人情的异化与规矩的不可违"为恐惧内核的类型。边界：规则条文式恐怖（规则怪谈）归 H12；西式哥特/克苏鲁归 H11；中式化克苏鲁（克苏鲁流/SCP 流）在 docs/05 §8.3 有条目，其"本土化"写法可反向参考本文档。中式恐怖与西式的根本差异：怕的不是宇宙冷漠，而是"祖传的规矩不容置疑+人心比鬼可怕"，因此禁忌体系与民俗逻辑是第一设定对象。

## 2. 核心知识框架

1. **氛围高于情节**：洛夫克拉夫特《文学中的超自然恐怖》（中文社区有译本连载，The Ring of Wonder）——怪奇文学的检验标准不是情节严丝合缝，而是"某种特定感觉的营造"，氛围才是重中之重。这一原则在中式恐怖中同样成立且更依赖日常质感（红烛、纸扎、寿衣、老井）。
2. **克制叙述法**：SCP 中文社区写作经验——恐惧感塑造靠"对异常场景的平静叙述"，多用具象描述而非抽象联想，让读者自行感知；中文写作课总结的手法包括内心独白、景物衬托、留白（不明写怪物，让读者想象）。
3. **禁忌规则体系**：中式恐怖的核心装置是"禁忌"（不能回头/不能应声/不能拆红布/不能看新娘），禁忌须有民俗来历（丧葬、祭祀、巫傩、行业规矩），违反必有后果，破忌必有代价——禁忌的"来历-后果-解除条件"三件套构成世界自洽核心。
4. **民俗素材库**：民间传说、宗教信仰、传统节日与地域差异是恐怖素材的富矿（民俗恐怖创作分析）；乡土怪谈与城市怪谈双线并行，本土元素更易引发代入（本土克苏鲁《长江之神》作者访谈）。
5. **志怪传统的现代转写**：聊斋式"物性-人性"互文（鬼狐有性格）；邪祟体系带因果代价逻辑（撞客、替身、报应），鬼怪往往承载人伦悲剧——中式恐怖的高阶形态是"鬼事即人事"。
6. **铺垫原则**：铺垫是"写作者带给读者的记忆"（盐言作者助手），前文埋下的具体细节是后文惊吓效果的基础；网文万订作者经验帖亦强调氛围与铺垫的节奏管理。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 地域民俗库先行：地域/习俗/禁忌/来历四字段建档 → 世界向导提供"乡土/城市"双民俗预设模板。
2. 邪祟体系预设：类型/弱点/触发禁忌/代价规则，明确"哪类问题能用民俗手段解决、哪类不能"→ 恐怖世界的规则边界。

**设定卡 schema 扩展（中式恐怖特有卡）**
3. 诡异档案卡（现象描述/目击记录/关联禁忌/真伪存疑度）→ docs/05 §2 民俗志怪行"诡异档案卡"的落地。
4. 禁忌规则卡（taboo：内容/违反后果/来历/解除条件——解除条件必须稀缺且付代价）。
5. 场景氛围卡（意象清单：纸扎/红烛/寿衣/镜/井/走廊+感官描写要点）→ 氛围密度校验的依据。

**校验规则**
6. 禁忌一致性：同一禁忌在不同章节的违反后果冲突 → error（恐怖世界观的硬自洽）。
7. 代价守恒：破忌/退邪必须付出对等代价，"无代价破解" → error。
8. 氛围密度校验：恐怖高潮章节内具象诡异细节数量低于阈值 → warn"直白吓人，缺铺垫"。

**写法指南与节拍**
9. 恐怖三段节拍：日常异常（违和细节）→ 平静叙述揭示 → 留白收束；禁 jump scare 堆砌。
10. 铺垫清单：每个高潮惊吓点生成前，列出必须回收的前文细节（记忆锚点），缺项 → 生成阻断。

**读者期待与雷点**
11. 期待=民俗考据感/禁忌压迫感/"人心比鬼可怕"的人伦恐怖；雷点=恐怖无逻辑、禁忌随意破解、鬼怪卖萌洗白、全靠突然惊吓、民俗细节错用冒犯读者 → taboos 清单。

**AI 提示词倾向**
12. 恐怖场景生成强制三原则：平静克制叙述、具象细节、留白；负面禁令：禁止直接描写邪祟全貌、禁止用感叹号制造恐慌。
13. 生成时注入当前场景氛围卡与已激活禁忌状态，防止 AI 写出"随手破忌"。

## 5. 对御书设计的启示

**数据结构建议：中式恐怖派系包核心卡 schema**

```yaml
# schemas/禁忌规则卡.yaml —— 中式恐怖的自洽核心（民俗志怪特有）
extends: core/setting-card
fields:
  content: {type: string}        # 禁忌条文（"子时之后不可应门"）
  origin: {type: string}         # 民俗来历（丧俗/祭祀/行业规矩）
  consequence: {type: string}    # 违反后果（须全篇一致）
  release: {type: object}        # 解除条件（必须稀缺且带代价）
  region: {type: ref}            # 关联地域民俗库条目
  status: {enum: [未触发, 已警告, 已违反, 已解除]}
```

**功能建议**
- 民俗素材库+地域筛选：按故事地域自动过滤可用习俗/禁忌，避免南北习俗混用穿帮。
- 禁忌状态面板：正文中禁忌被提及/警告/违反时自动更新状态，供续写与校验读取。

**校验规则建议**
- `taboo-consistency`：禁忌后果全篇一致性检查（error 级）。
- `price-conservation`：破忌必付代价检查（error 级）。
- `atmosphere-density`：恐怖章节具象细节密度检查（warn 级），判定词表来自场景氛围卡。

**AI 提示词建议**
- 恐怖场景模板首行注入禁令块："平静叙述；不写怪物全貌；不使用突然惊吓句式"。
- 高潮章生成前强制输出铺垫清单，缺记忆锚点则要求先补铺垫章。
