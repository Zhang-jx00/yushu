# H07-现实都市（职场 / 商战 / 官场 / 年代文）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"现实都市"世界维的写法：低魔或无魔、以人文逻辑与行业真实感驱动的四个主要子类——职场（个人在组织内的晋升与人情）、商战（企业间博弈）、官场（权力结构中的升迁与规则）、年代文（1949-1990 年代叙事时间的类型，百度百科官方定义）。对应 docs/05 世界维"现实都市"条目。与 H06 超凡都市的边界：本流派没有金手指兜底，冲突全部来自行业逻辑、商业逻辑与制度规则；"违背常识的商业逻辑"是第一雷点，时代违禁细节是年代文第一雷点。

## 2. 核心知识框架

1. **行业真实性方法论**：商战小说标杆《输赢》（付遥）被称"中国第一部可用于培训的商战小说"，其根基是作者 IBM/戴尔的真实行业经验——行业经验打底是本流派的第一写法共识；行业文创作要点包括"人物塑造黄金三角""专业性与可读性平衡""行业细节避坑"（CSDN 金融职场小说创作分析）。
2. **商战逻辑学**：商战=信息战+资源战，围绕产品、渠道、资本、人四个要素展开；商业逻辑必须自洽并能支撑剧情冲突，专业细节要"讲人话"呈现（付遥访谈与案例复盘）。
3. **官场书写传统**：上溯清末《官场现形记》《二十年目睹之怪现状》的谴责小说传统，改革开放后转向"剖析"（中国作家网《复兴之路》脉络）；核心技法=规则描写（明规则+潜规则）+人物心理+犀利对白（黄晓阳"官场生存指南"式写作）；刘震云式权力书写示范了从政治批判到权力文化多方位反思的深度。平台侧注意：官场题材受审查约束，网文平台多归入"现实"频道且偏"想象性爽感"表达（中国文艺评论网对网文官场/职场文的类型分野观察）。
4. **年代文考据学**：叙事时间 1949-1990（百度百科定义）；细节素材库=票证经济（粮票 1955 年发行至 1993 年废止、全国粮票与地方粮票之别、农民无粮票等易错点）、物价锚点（"一个烧饼 2 两粮票+7 分钱"式精确细节最具真实感）、时间坐标（知青上山下乡约 1962-1979、返城潮 1978-1980 前后、大城市单位分房体系）；写作者共识是"引用具体价格+票面数额"营造时代质感。
5. **类型分野**：写实向（社会派，豆瓣阅读标签体系）与代入爽感向（逆袭商战、年代经营）共用本世界维，基调维取值不同、校验强度不同——写实向行业硬伤零容忍，爽感向可放宽商业奇迹但需"代价解释"。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 年代文强制生成"年代坐标锚点五表"：政策/物价/票证/住房/工资 → 世界向导年代文预设核心件。
2. 行业生态图先行（竞争格局/职务序列/上下游/行话表）→ 世界预设行业模板。
3. 城市地理写实（真实路名可虚化但空间逻辑须成立）→ 地点库（B04）现实模式。

**设定卡 schema 扩展（现实都市特有卡）**
4. 公司商业卡（股权结构/产品线/现金流/竞争对手/融资事件）→ docs/05"公司商业卡"落地。
5. 职位序列卡（层级/职权边界/汇报关系）→ 职场与官场共用的权力底座。
6. 年代物价卡（年份×物品×价格×票证要求）→ 时代细节物料库。
7. 人物履历卡（教育/任职/调动时间线，履历连续性校验的载体）。
8. 政策事件卡（真实或虚构政策：生效时点/影响行业/人物反应钩子）。

**校验规则**
9. 年代 lint：时代违禁词检测（1978 年语境出现手机/互联网，1990 前出现连锁超市等）→ error（词表随年代坐标自动切换）。
10. 商业逻辑校验：盈利模式/资金流无来源的"商业奇迹" → warn（写实向 error）。
11. 职权边界校验：越级行权（科长批部长级事项）且无授权说明 → warn。
12. 履历一致性：人物履历卡时间线冲突（任职重叠/学历时点矛盾）→ error。

**写法指南与节拍**
13. 商战项目循环：竞标-公关-危机-翻盘 → 节拍表模板；翻盘必须消耗前期铺垫的资源/信息。
14. 职场三线节拍：职级线/能力线/人脉线交替推进，单线独走即失衡 → 大纲模板。
15. 年代文经营积累里程碑（从摆摊到厂区/公司的台阶）+ 时代大事件作卷级转折 → 年代大纲模板。
16. 官场晋升台阶表与禁区（可写与不可写的边界标注）→ 制度知识库。

**读者期待与雷点**
17. 期待=代入感、行业揭秘、逆袭、年代烟火气；雷点=违背常识的商业逻辑、行业硬伤、年代穿越细节、官场题材红线 → taboos 清单。

**AI 提示词倾向**
18. 提示词自动注入"年代禁用词表+物价表+在场人物职权边界"→ 防时代穿越与权力越界。
19. 行业术语表随行业选择挂载，要求"术语首次出现给一句人话解释"→ 专业性与可读性平衡。
20. 写实向基调下禁用"金手指式巧合"，冲突解决必须来自已铺垫资源 → AI 生成约束。

## 5. 对御书设计的启示

**数据结构建议：年代坐标锚点（年代文派系包核心件）**

```yaml
# presets/decade-anchor.yaml —— 年代文世界预设的锚点表
decade: 1978
anchors:
  policy:  [改革开放启动, 知青返城潮开始]
  price:   [{item: 烧饼, cost: "7分", coupon: "2两粮票"}, {item: 自行车, cost: "约150元+工业券"}]
  coupon:  [全国粮票, 地方粮票, 布票, 工业券]     # 供违禁词与物价校验引用
  housing: [单位分房, 大杂院]
  wage:    {worker: "约40元/月"}
banned_words_by_era:                      # 年代 lint 词表
  before_1978: [手机, 互联网, BP机]
  before_1990: [连锁超市, 网购]
```

**校验规则建议**
- `era-anachronism`：章节时间戳与 banned_words_by_era 词表交叉检测 → error。
- `biz-logic`：商战事件的资金/信息来源必须可回溯到已铺垫卡（公司卡/人物履历/政策事件）。
- `authority-boundary`：行动事件匹配职位序列卡的职权范围，越界 → warn。
- `resume-consistency`：履历时间线拓扑检查（无重叠、无倒流）。

**写法指南与节拍建议**
- 按子向挂载节拍包：商战=项目循环；职场=三线交替；官场=台阶+禁区；年代=里程碑+大事件卷转折。
- 行业知识库挂载点：选行业（IT/金融/制造/快消）即挂对应行话表与职务序列模板。

**读者期待与雷点**
- taboos.yaml：商业逻辑硬伤/行业细节硬伤/年代穿越/题材红线；写实向项目把"商业奇迹无代价"升级为 error。

**AI 提示词建议**
- 续写状态块："当前年份{year}｜在场人物职权{authority}｜可用资源/信息{assets}"；生成要求"冲突解决方案必须引用已铺垫资源"，行业术语首现附人话解释；年代文追加"禁用现代口语"文风开关。
