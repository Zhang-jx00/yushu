# H14-穿越重生流（穿越古代 / 异世界穿越 / 重生 / 快穿）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

合并调研手法维的"跨世界超级流派"：穿越流（现代人穿古代/异世界，含日系转生/转移）、重生流（带记忆重来一生）、穿书（进入小说/游戏，含恶役千金）、快穿（多任务世界单元剧）。它们的共同叙事装置是"信息差金手指"——主角带着超出当前世界的记忆/知识行动。世界维随目标世界变化（古代归 H09、异世界归 H-异世界文档），docs/05 §3 已有手法维摘要条目（穿越流/重生流/快穿），§8.2 有日系 isekai 谱系表，本文档只写手法共性：金手指类型学、适应期写法、先知优势管理、任务世界结构。边界：无限流副本虽也是"跨世界"，但其规则学习装置归 H12。

## 2. 核心知识框架

1. **金手指类型学**：穿越文最常见路数是"开金手指"——利用现代人领先古人的经验与知识达成目的（知乎《回明》研究帖）；近年主流是**知识型金手指**（种田/冶金/医学/军事推演），重逻辑推演、避免无脑爽（红袖添香百科对"知识型穿越"的定位）；社科院评价体系指出金手指是满足读者"逃离现实、实现理想"心理的核心机制——即金手指必须有心理补偿功能而不只是功能外挂。
2. **约束金手指**：硬核流穿越文的通行手法是给知识变现设限（知识无法直接复现、缺少工业基础、材料与工艺不达标），限制本身制造剧情。
3. **适应期写法**：通过"知识错位"（能背《诗经》却不知其为秘典）、身体/身份不适、语言习俗差异制造真实感与戏剧冲突，而非让主角一穿越就开挂（QQ 阅读《妻为君纲》案例）。
4. **重生流机制**：先知优势（预知商机/阴谋/灾难）、弥补遗憾（"重来一次"满足人类对"后悔药"的深层心理需求）、复仇布局（前世仇人逐个打脸，节奏前置、开局即高冲突）；趋势（盐言故事专题分析）：单纯先知复仇向"重生带来的心理与选择深度"进化。核心熵增机制=蝴蝶效应：主角每改写一次事件，原记忆可信度衰减。
5. **快穿结构**：单元剧——每个任务世界有独立人设/世界观/任务目标（攻略/逆袭/虐渣/弥补遗憾），完成后进入下一世界；写作技巧文（asp23 快穿攻略方法论）强调女主与系统的关系要"变质"：系统从第一世界的金手指/救命稻草逐渐成为第 N 世界的"噪音"，主角开始质疑任务逻辑（去剧本化反杀）——系统关系演化即角色成长弧；跨世界主线（系统真相/执念对象）负责整书黏合。
6. **日系对照**（docs/05 §8.2）：異世界転生/転移、なろう系模板（转生+外挂技能+状态面板+成り上がり）、悪役令嬢（穿书+宅斗，回避破灭 Flag）、ざまぁ（≈重生复仇）——中文流派与日系谱系几乎一一对应，模板字段可互译。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 穿越前世界档案：主角来源时代的知识/技能清单=金手指原料库 → 世界向导第一步生成。
2. 重生时间锚点：回到哪一年、原时间线事件轴（原历史/前世事件表）→ 所有先知情节的坐标系。

**设定卡 schema 扩展（穿越重生特有卡）**
3. 先知优势卡（prophecy：事件/记忆原文/蝴蝶效应衰减度/已使用次数）→ docs/05 §3"先知优势管理规则"的落地。
4. 知识变现卡（知识项/所需前置条件/变现路径/风险与代价）→ 硬核流限制的显式化。
5. 快穿任务卡（任务世界：目标/失败惩罚/本世界身份/完成判定/主线线索）→ 单元剧结构的最小单元。

**校验规则**
6. 蝴蝶效应追踪：主角已改写大事件后仍按原记忆行动 → warn"先知优势未衰减"；连续使用同一条先知 → warn。
7. 知识变现前置校验：变现在缺少前置技术/工业基础时 → error"金手指越级"。
8. 快穿人设一致性：跨世界核心人格漂移（动机/说话方式突变且无剧情解释）→ warn"人设漂移"（docs/05 §3 快穿雷点同源）。

**写法指南与节拍**
9. 重生开局节拍：死亡/执念闪回 → 重生锚点（回到命运转折点）→ 首个先知验证（建立可信度）→ 第一次改命；三章内完成。
10. 快穿单元剧节拍：入场（身份+任务）→ 任务展开（可反套路）→ 完成/翻车 → 主线钩子 → 离场；每 2-3 世界推进一次主线。

**读者期待与雷点**
11. 期待=先知爽感/弥补遗憾/知识变现/虐渣打脸/破灭 Flag 回避；雷点=先知滥用导致无悬念、适应期无代价、金手指通胀、任务世界人设漂移、穿越者以现代价值观傲视古人却无反思 → taboos 清单。

**AI 提示词倾向**
12. 重生场景生成注入"原记忆 vs 当前世界差异"状态块（哪些事件已改写、可信度几何），防止 AI 写出失忆式先知。
13. 快穿生成携带"核心人格卡+本世界身份卡"双上下文；系统对话按系统关系阶段（金手指期/怀疑期/去剧本期）调整语气。

## 5. 对御书设计的启示

**数据结构建议：穿越重生派系包核心卡 schema**

```yaml
# schemas/先知优势卡.yaml —— 信息差金手指的管理单元（穿越重生特有）
extends: core/setting-card
fields:
  event: {type: string}          # 原记忆事件（"今年七月黄河决口"）
  original_text: {type: string}  # 记忆原文（前世所见/原著情节）
  decay: {type: number}          # 蝴蝶效应可信度 0-1（每改写一次衰减）
  used_count: {type: integer}
  anchors: {type: array}         # 该事件在时间线上的锚点（关联重生时间锚点）
```

**功能建议**
- 时间线分叉视图：原时间线（虚线）与已改写事件（实线）并列，先知卡衰减度自动重算。
- 快穿任务板：任务卡看板（进行中/已完成/翻车），主线线索进度条独立于任务世界显示。

**校验规则建议**
- `prophecy-decay`：改写事件后引用原记忆行动 → warn；decay 低于阈值后引用 → error。
- `knowledge-prereq`：知识变现卡缺前置条件 → error。
- `persona-drift`：快穿跨世界人格一致性检查（基于核心人格卡 diff，warn）。

**AI 提示词建议**
- 续写状态块："当前时间{t}，已改写事件{events}，先知可信度{decay}，本世界身份{id}"。
- 适应期模板强制"错位感"描写（知识知道但语境不对），禁令：不得开篇即无双碾压。
