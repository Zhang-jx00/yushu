# H20-同人衍生·轻小说·短篇短剧（衍生同人 / 日系轻小说 / 短篇 / 短剧剧本）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

本文档合并调研三类"轻体量"形态：①同人衍生——基于既有作品/人物的二次创作（晋江"衍生"、起点"衍生同人"、飞卢同人站皆有独立频道，番茄男频同人占大盘前三）；②轻小说——日系谱系的"角色驱动、人设优先、做减法"写法（docs/05 §8.2 なろう系谱系为其套路层）；③短篇与短剧——短篇（单篇 1-10 万字的快节奏完整故事）与微短剧剧本（竖屏 60-120 秒/集，"3-15-45"节奏法则）。三者共性是"小单元、强钩子、快反馈"：同人靠原作情感存量，轻小说靠人设辨识度，短篇短剧靠钩子密度。边界：同人中的 OOC 检查是本流派独有的校验维度；短剧的手法本质是网文爽点循环的影视化（管平潮："短剧是网络小说的视觉具象"），故短剧剧本结构可反哺网文"黄金一章"写法。版权合规（同人商用红线）是本流派特有的平台规范层。

## 2. 核心知识框架

1. **同人类型学与边界**：狭义同人=二次创作（Scribd 收录的粉丝群体研究：广义可含原创，但通行定义为基于原文本的挪用与再创作）；仅"借鉴设定"（起名风格/故事结构）而无原作角色出场的作品不算同人（社区科普共识）。詹金斯"盗猎者"理论描述粉丝对原文本的挪用本质。晋江论坛讨论给出转化路径：只喜欢背景设定而不喜欢原作角色 → 借背景写自己的人物，减少原著角色戏份即转原创。
2. **OOC 是同人的第一雷点**：萌娘百科定义 OOC（Out of Character）=二次创作中人物塑造偏离原作设定/形象；且高人气 OOC 作品会误导新读者、反向污染社区对角色的共识（同人圈"OOC 洗脑"现象）。现实冲突案例（蓝鲸财经报道晋江同人文影视化争议）：抹黑原著女主、过度 OOC、梦女设定引发粉丝抵制。防范方法论：角色卡对齐原作（说话方式/动机边界/关系网/知识范围）+每章 diff 检查。
3. **同人版权红线**：同人创作在法律上属灰色地带，关键变量=是否授权、是否商用、是否实质性相似（搜狐汇编的同人著作权裁判规则）；SE 清理收费同人（蒂法下架事件）确立"收费即商业行为，'为爱发电'不是免责金牌"；国产 IP 方加强版权管控后商业同人收窄。平台侧：晋江衍生分类有自己的发文与审核规则，飞卢独立同人站以"穿越+系统+同人"快餐流为主。
4. **轻小说的"轻"**：腾讯云《数据库时代的轻小说》概括其本质——集中表现人物关系、简化背景设定、突出主要情节与角色价值；"轻"在于去除非核心元素。写法要点：人设辨识度优先于世界观复杂度（角色原型模板+关系网）；节奏张弛=日常回与剧情回交替（知乎节奏讨论：快节奏推情节、细腻描写塑人物，日系风险是细腻转拖沓）；开篇尽早给钩子（悬念/反转/压力）提升追更率。docs/05 §8.2 的なろう系模板（转生+外挂+面板+成り上がり）即轻小说的工业化套路层，字段可互译。
5. **短剧节奏法则**：竖屏短剧骨架=前 3 秒钩子、前 15 秒冲突、前 45 秒首次兑现/反转（"3-15-45"法则）；单集 60-120 秒、场景 ≤5 个；每集结尾设悬念/情绪吊桥留人。反转的检验三要素（鬼手剪辑方法论）：改变前的理解、触发证据、改变后的行动——缺一项只是新信息不是反转。平台数据侧：第一集与前十集决定完播率与流量分发（"批量复制爆款"分析），战神/赘婿/豪门复仇/甜宠虐渣是改编高频题材（docs/05 §9 已备案）。
6. **短篇结构**：短篇=单线+单一情绪目标+结尾反转或情绪释放；钩子前置（首段即冲突），删繁就简（轻小说"做减法"原则同源）；豆瓣阅读已设"短剧漫剧向"专区——短篇-短剧一体化已成平台正式形态，同一故事文本应可降级导出为短剧分集大纲。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 原作设定库引用（同人）：原作名/世界观摘要/角色卡（性格/说话方式/动机边界/关系网/知识范围）/时间线锚点 → 世界向导第一步，角色卡对齐是 OOC 校验的基准。
2. 衍生改造声明：AU 程度（原世界观/平行 AU/架空 AU）/时间点/原创角色清单 → 决定原作约束的松紧档位。
3. 轻小说人设包：角色原型（属性/萌点/口癖/反差点）+关系网图 → 人设驱动叙事的种子库。

**设定卡 schema 扩展（原作设定库引用/作品资源卡）**
4. 原作角色卡（canonical 性格标签/台词风格样本/行为边界/关系约束）→ OOC 校验的参照系，与通用人物卡双轨存储（canonical vs 本作演绎）。
5. 剧情锚点卡（原作事件/原发生时间/本作改动/偏移度）→ 复用 H14/H17 的分叉视图。
6. 短剧分集卡（集号/时长/场景数/3 秒钩子/15 秒冲突/45 秒兑现/结尾吊桥）→ 短剧结构的最小单元。
7. 作品资源卡（轻小说/短篇：卷册/单元回/情绪目标）→ 与 H19 作品资源卡同构复用。

**校验规则**
8. OOC 检查（同人核心 lint）：本作角色言行偏离 canonical 角色卡且无 AU 声明解释 → warn"疑似 OOC"；抹黑/丑化原作主要角色且无 AU 声明 → error"角色崩坏"。
9. 原作一致性：引用与原作时间线/设定矛盾（人物在未登场时间点出场、使用未获得的能力）→ error"原作穿帮"。
10. 版权合规提示：项目标记"商业发布"且含同人 IP → warn"商用授权风险"（提示核实授权状态）。
11. 短剧节奏校验：分集卡缺 3 秒钩子或 45 秒兑现 → warn"节奏不达标"；反转缺三要素之一 → warn"伪反转"。

**写法指南与节拍**
12. 同人开篇节拍：30 字内锚定原作关系（让读者认出这是哪部作品）→ 差异点/金手指登场 → 首个"原作剧情偏移"钩子。
13. 轻小说单元节拍：日常回（人设互动+关系推进）→ 剧情回（事件+主线推进）交替，1-2 日常配 1 剧情回；每卷结尾给关系网一个确定性变化。
14. 短篇/短章节拍：首段钩子 → 三次情绪波动点 → 反转（三要素齐备）→ 情绪释放收尾；网文侧对应"黄金三章压缩为黄金一章"的免费端写法。

**读者期待与雷点**
15. 期待=原作角色的"另一种可能"（补完/翻案/IF 线）/嗑糖与名场面复刻/人设反差萌/短剧的高频打脸；雷点=OOC、抹黑原作角色、蹭原作名气却无原作味道（借设定骂同人）、轻小说设定堆砌压过人物、短剧反转无铺垫 → taboos 清单。
16. 圈层礼仪：同人作品需声明原作与 CP、标注 AU 与雷点（预警文化）→ 派系包内置"文案声明模板"生成器。

**AI 提示词倾向**
17. 同人续写双上下文：canonical 角色卡（台词风格样本+行为边界）+本作演绎偏差记录，AI 输出逐段标注与 canonical 的偏离度供 OOC 校验。
18. 轻小说/短剧模板化提示词：人设包驱动（口癖/反差点约束对白）；短剧分集生成强制输出"3 秒钩子/15 秒冲突/45 秒兑现"三行结构，反转须含三要素。

## 5. 对御书设计的启示

**数据结构建议：同人/轻小说/短剧派系包核心卡 schema**

```yaml
# schemas/原作角色卡.yaml —— 同人 OOC 校验的参照系（与通用人物卡双轨）
extends: core/character-card
fields:
  source_work: {type: string}    # 原作名与版本
  canonical_traits: {type: array}    # 原作性格标签
  speech_samples: {type: array}      # 台词风格样本（对白校验语料）
  behavior_boundaries: {type: array} # 行为边界（绝不会做/绝不会说）
  relations: {type: object}          # 原作关系约束
  deviation_log: {type: array}       # 本作演绎偏差记录（联动 AU 声明）
```

配套：剧情锚点卡（原作事件/偏移度）、短剧分集卡（hook/conflict/payoff/cliffhanger）、AU 声明字段（项目级）。

**功能建议**
- 原作设定库导入向导：录入原作名→批量建 canonical 角色卡→设定 AU 档位，后续所有角色言行校验自动挂载。
- 短剧分集板：短篇文本一键拆分为分集卡（钩子/冲突/兑现/吊桥四字段），反向支持"短篇→短剧大纲"导出。
- 文案声明生成器：按项目配置（原作/CP/AU/雷点）自动产出平台合规文案头。

**校验规则建议**
- `ooc-drift`：言行偏离 canonical 卡且无 AU 解释 → warn；丑化主要角色 → error。
- `canon-consistency`：原作时间线/能力引用矛盾 → error。
- `fanfic-license`：商用标记+同人 IP → warn 授权风险。
- `short-drama-pacing`：分集缺钩子/兑现 → warn；反转缺三要素 → warn。

**AI 提示词建议**
- 同人续写注入"canonical+偏差"双上下文，输出逐段附偏离度标注；对白生成受 speech_samples 约束。
- 轻小说按人设包驱动对白（口癖/反差点）；短剧分集强制三行结构输出，免费端网文模板提供"黄金一章"压缩版节拍。
