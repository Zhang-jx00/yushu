# H04-西方奇幻（剑与魔法 / DND / 领主流 / 黑暗奇幻）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"西幻"世界维的写法：剑与魔法（Sword & Sorcery）、高/低奇幻、DND 游戏规则血统、领主流（领地经营）、黑暗奇幻（Dark Fantasy/Grimdark）五个主要子类。对应 docs/05 世界维"西幻"条目与 §8.1 西方子类映射表（high/low/dark/grimdark/S&S/cozy/portal → 御书世界维+基调维组合）。与 H01 的边界：西幻的种族-职业-神祇体系、第二世界自洽要求、西式社会结构（贵族/教会/行会）是独有约束；中式思维穿帮是本流派第一雷点。

## 2. 核心知识框架

1. **子类光谱**：从高奇幻（第二世界史诗善恶对抗）到剑与魔法（小尺度雇佣英雄、动作驱动、pulp 传统）、到 grimdark（道德灰色、暴力写实、拒绝理想化贵族），子类决定基调维取值——grimdark 是"黑暗奇幻拉满"的极端（Kindlepreneur 区分），选型即定调。
2. **魔法体系设计准则**：Sanderson 三定律——读者对魔法的理解度与可解冲突能力成正比、限制>能力、先深挖已有体系再新增；魔法应有成本与边界，而非问题解决器。
3. **第二世界自洽方法论**：Wrede 七板块问卷（世界/物理历史/魔法法师/民族习俗/社会组织/商业贸易/日常生活）是引导式建档蓝本；地理用 Azgaar 分层生成管线（heightmap→气候→文化→国家→宗教→外交→贸易）保证上下游依赖自洽。
4. **DND 血统**：种族/职业/阶职模板源自 DND；"战役→小说"转化是成熟方法（World Anvil 指南）；版权边界明确——Faerûn 等设定写同人需注意许可（DND Beyond 社区讨论），御书应把"原设定引用 vs 原创"做成字段。
5. **Grimdark 美学**：暴力服务叙事而非猎奇（Writing Stack Exchange 争论的共识侧）、灰色道德、废墟感与代价真实（Grimdark Magazine 的巫师 3 案例法）。
6. **领主流工程**：领地=人口/资源/建筑/军事四本账，经营与战争交替推进（docs/05"领主流"行：内政数据混乱是第一雷点）。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 魔法体系先建"要素-消耗-反噬-禁区"四字段再写剧情（Sanderson 第一定律）→ 世界向导西幻预设第 1 步。
2. 种族文化差异必须超过"耳朵尖"级（价值观/历法/饮食/称谓）→ 种族卡强制文化字段。
3. 帝国/王国结构参照真实历史"作为灵感而非镜像"（SFWA 太空王室法同样适用）→ 政体模板带历史参照提示。

**设定卡 schema 扩展（西幻特有卡）**
4. 魔法体系卡（要素/消耗/反噬/禁区）→ grimdark 与史诗共用。
5. 种族卡（寿命/文化/称谓表）+ 职业阶职卡（DND 式等级但叙事化）。
6. 领地卡（人口/税收/粮储/兵源/建筑队列）→ 领主流经营模板核心。
7. 神祇卡（神职/教义/圣职体系/神术代价）→ 联动 C08 宗教设计。

**校验规则**
8. 魔法 lint：违反已登记"禁区/消耗"的施法 → error（Sanderson 三定律的机检化）。
9. 寿命-年表联动：长寿种族角色参与的历史事件需通过年龄检查。
10. 领地收支守恒：军费/建设超过税入且无借贷事件 → error。
11. 中式穿帮检测：西幻文本中出现科举/武林/皇上等中式制度词 → warn（词表可扩展）。

**写法指南与节拍**
12. S&S 单元冒险结构（委托-遭遇-反转-报酬，pulp 短章节奏）+ 史诗三部曲结构 → 两套大纲模板。
13. 领主流"建设里程碑+战争节拍"交替 → 节拍表。
14. grimdark"无安全屋"原则：任何据点都可能失守，代价必须兑现 → 基调维节拍差异。

**读者期待与雷点**
15. 期待=异域史诗感、冒险自由、规则清晰的力量体系；雷点=中式思维穿帮、力量体系混乱、grimdark 为黑而黑、DND 数值硬搬进叙事 → taboos 清单。

**AI 提示词倾向**
16. 生成时注入种族称谓表与魔法禁区清单 → 防术语穿帮与魔法越界。
17. 战斗场面用 D20 编舞法（把回合行动转译为连续动作）→ 战斗提示词模板（Alison Lyke 法）。
18. grimdark 场景提示词强制"代价句"收尾 → 防止爽文化。

## 5. 对御书设计的启示

**数据结构建议：魔法体系卡（西幻派系包第一卡）**

```yaml
# schemas/魔法体系卡.yaml
extends: core/setting-card
fields:
  elements: {type: array}        # 要素（法术位/元素/仪式）
  cost: {type: string}           # 消耗（体力/材料/记忆/寿数）
  backlash: {type: string}       # 反噬（失败代价，grimdark 必填）
  forbidden: {type: array}       # 禁区（不可施展之事，供校验与 AI 负面约束）
  hardness: {enum: [软魔法, 硬魔法]}  # Sanderson 光谱定位
```

**校验规则建议**
- `magic-lint`：施法事件匹配 forbidden 清单 → error；未声明消耗 → warn。
- `chinese-leak`：西幻项目的中式制度词检测（可关，翻译腔作品例外）。
- `domain-ledger`：领地收支与人口变动守恒（复用 C12 经济校验）。

**写法指南与节拍建议**
- 按子类挂载节拍包：S&S=单元冒险快节奏；High Fantasy=三卷史诗；领主流=里程碑+战争；grimdark=代价兑现表。
- 战役导入器：支持从 TTRPG 笔记（DND 式战役记录）批量转设定卡（World Anvil 方法的工具化）。

**读者期待与雷点**
- taboos.yaml：中式穿帮/力量体系混乱/为黑而黑/数值硬搬；每条附检查示例句。

**AI 提示词建议**
- 生成模板注入三件套：称谓表 + 魔法禁区 + 领地现状；grimdark 包追加"本场景必须付出可见代价"的硬约束；S&S 包要求 pulp 式短段与动作动词密度。
