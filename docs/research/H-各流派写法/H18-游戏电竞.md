# H18-游戏电竞（虚拟网游 / 游戏异界 / 第四天灾 / 电竞）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

游戏维流派覆盖四条赛道：虚拟网游（玩家进入全息/VR 游戏，早期起点游戏分类主力）、游戏异界（穿越进游戏世界或游戏现实化）、电竞（职业联赛、战队生态、退役逆袭，《全职高手》为定型作）、第四天灾（主角作为幕后主神/策划把"玩家"引入异世界当劳动力，《地下城玩家》为开山作，萌娘百科定义其三要素为"游戏系统+无限复活+无视规则"）。docs/05 §2 已有"游戏"世界维条目、§3 已有"第四天灾"手法条目，本文档合并四条赛道的共性知识：游戏规则体系（这是唯一"规则必须完全自洽且前置公开"的流派）、比赛/战斗描写的战术层、双视角结构（操作者视角 vs 系统/观众视角）、赛季与版本变量。边界：系统面板的手法细节归 H15（游戏文常叠加系统卡但游戏规则卡独立）；直播弹幕写法与 H19 共享直播间卡。

## 2. 核心知识框架

1. **赛道演化史**：萌芽期（2000-2003，伴随《传奇》类网游普及，早期代表作《猛龙过江》）→ 黄金期（2004-2010，《从零开始》等"全息头盔+第二世界"长篇）→ 转型期（2011-2016，电竞文《全职高手》与游戏异界兴起，纯虚拟网游降温）→ 当下（"全民游戏化/领主/第四天灾"复合设定为主流，传统升级打怪式虚拟网游边缘化）。起点游戏分类下设虚拟网游/游戏异界/电竞/游戏系统等子分类；2025 年度盘点显示"游戏系统、传统网游、电竞"仍是三大主题群。
2. **游戏规则卡是流派宪法**：与玄幻"境界体系"不同，游戏文的力量体系必须像产品文档一样自洽（职业/技能循环/装备数值/地图机制/PVP 规则），且读者会像玩家一样找 bug。《全职高手》的人物塑造范式——主角"荣耀教科书、全职业精通、四大战术大师"的设定即建立在游戏体系完备之上；散人、技能点、银武等机制前后一致是口碑来源。读者对"游戏规则随意更改"零容忍（docs/05 雷点同源）。
3. **电竞文写作要点**（创作指南类资料共识）：①平衡游戏与现实——详细描写操作、战术、赛事规则增强代入感，但须穿插现实互动（对话/心理/日常）避免枯燥；②战术描写要提前埋伏笔（训练赛试新体系、复盘会讨论 BP），比赛时读者才有"原来如此"的爽感；③行业常识先行——知乎《电竞十问》澄清大众误解（电竞≠打游戏好、不止 LOl/CSGO），行业生态（青训/转会/直播合约/版本更迭）是职业文的骨架；④群像是灵魂：战队成员与对手各有故事线，对手不能是经验包。
4. **第四天灾双视角结构**：幕后经营者（主神/GM/策划）视角负责经营与大局，玩家视角负责喜剧、脑补与"游戏感"错位（把 NPC 悲剧当任务、把史诗当日常）；信息差是核心爽点——玩家以为是游戏，世界却真实存在。演化路径：早期"穿越成 NPC"视角 → 幕后经营+玩家工具人模式 → 沙盘创世流（KKnews 盘点）。写崩高发区：玩家智商、NPC 悲剧处理尺度、"游戏系统"逻辑自洽性（NGA 流派讨论帖也指出 GM 视角与玩家视角的写法分化）。
5. **比赛描写与节奏管理**：比赛是高潮单元，连载骨架靠训练/日常/团队矛盾支撑；联赛赛制易致中后期重复感，需要用新对手类型、转会、版本更新等变量破局。GitHub 网文写作手册（webnovel-handbook）总结起点经验：重复打脸、机制重复、对手反复送人头导致读者疲劳，应"连续三章压力递进"——对"比赛→下一场更强对手"的电竞循环尤其适用。
6. **游戏+直播的复合**：近年电竞文常见"游戏直播+职业电竞+轻喜爱情"三线融合，游戏主播已是独立标签；直播维度（弹幕反应/人气数值）与 H19 直播间卡共享 schema。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 游戏规则档案：世界观类型（VR 全息/异界/职业联赛）/职业与技能体系/数值框架/PVP 规则 → 世界向导必备，先于人物。
2. 版本与赛季时间线：版本更新表/赛季日程/转会窗口 → 长篇连载的节奏坐标系与变量来源。
3. 生态圈档案：公会/俱乐部/直播平台/厂商官方的势力关系图 → 冲突与商业务情节的来源库。

**设定卡 schema 扩展（游戏规则卡）**
4. 游戏规则卡（职业树/技能表/数值公式/地图机制/禁则清单）→ 流派宪法的结构化，向读者公开的部分即"明规则"。
5. 战术卡（战术名/适用地图/前置条件/执行分工/被克制关系）→ 比赛伏笔的登记单元，训练赛埋设、决赛兑现。
6. 战队卡（成员/位置/替补/战绩/赞助与矛盾线）→ 电竞群像的组织单元。
7. 玩家卡（第四天灾：ID/职业/性格标签/经典行为语录）→ 玩家行为库的条目，供喜剧桥段复用。

**校验规则**
8. 规则一致性：战斗结果违反已登记技能/数值/禁则 → error"规则穿帮"（游戏文的最高优先级 lint）。
9. 版本一致性：引用已"版本移除"的技能或装备 → warn"版本过期"。
10. 战术闭环校验：决赛用战术无前置铺垫（无训练赛/复盘登记）→ warn"战术无源"。
11. 玩家行为一致性：玩家角色做出违背其性格标签与已知信息的行为 → warn"玩家 OOC"。

**写法指南与节拍**
12. 电竞比赛节拍：赛前铺垫（对手情报/战术埋设）→ BP/开局劣势 → 中局翻盘点（对应战术卡兑现）→ 赛点定格（镜头感短句）→ 赛后余波（舆论/积分榜）。
13. 第四天灾节拍：玩家入场（新手引导喜剧）→ 玩家视角任务（信息差笑点）→ NPC/主神视角对照 → 世界真相钩子（每 2-3 章一次双视角对照）。
14. 长线破局节拍：每卷引入一个新变量（新对手/新版本/新队员/新赛事），防联赛重复感。

**读者期待与雷点**
15. 期待=操作与战术的智斗爽感/规则内以弱胜强/群像热血/经营养成/信息差喜剧；雷点=规则随意更改、数据前后矛盾、比赛流水账报操作、对手降智送人头、玩家智商失控或 NPC 悲剧被儿戏化 → taboos 清单。
16. 电竞行业真实性分级：职业文需要青训/转会/合约常识兜底 → 派系包内置行业术语表与赛制模板。

**AI 提示词倾向**
17. 续写状态块注入：当前版本号/可用技能清单/双方战术卡/比分与经济差——AI 不得引用未登记技能，新技能必须先回写游戏规则卡。
18. 双视角生成指令：同一场战斗输出"操作者视角正文+玩家/观众视角弹幕对照"两栏文本；战术描写要求"伏笔-兑现"成对出现。

## 5. 对御书设计的启示

**数据结构建议：游戏电竞派系包核心卡 schema**

```yaml
# schemas/游戏规则卡.yaml —— 流派宪法：规则一致性的唯一依据
extends: core/setting-card
fields:
  world_type: {type: enum, values: [vr-mmo, isekai-game, esports, fourth-disaster]}
  classes: {type: array}         # 职业树（含技能与冷却/消耗）
  numeric_rules: {type: object}  # 数值公式（伤害/经济/成长曲线）
  map_mechanics: {type: array}   # 地图机制与地形利用点
  banlist: {type: array}         # 明规则禁则（向读者公开）
  version: {type: string}        # 当前版本号（联动版本时间线）
```

配套：战术卡（name/map/prereq/roles/counters）、战队卡（roster/record/conflicts）、玩家卡（id/traits/quotes）。

**功能建议**
- 规则沙盒：战斗/比赛事件可走规则卡推演器验证结果合理性，异常结果标记"规则穿帮"。
- 赛程看板：赛季日程+版本时间线+战队战绩三联视图，自动提醒"下一卷变量"选项（新对手/版本/转会）。
- 玩家行为库：玩家卡语录标签化，生成第四天灾喜剧桥段时按性格标签抽取。

**校验规则建议**
- `game-rule-consistency`：战斗结果违反规则卡 → error。
- `version-stale`：引用已移除技能/装备 → warn。
- `tactic-unplanted`：战术无前置伏笔 → warn。
- `player-ooc`：玩家行为违背性格标签 → warn。

**AI 提示词建议**
- 状态块："版本{v}，可用技能{skills}，战术伏笔{planted}，比分{score}"；新技能/装备必须走登记回写流程。
- 电竞赛制模板提示词（联赛/淘汰赛/邀请赛）内置行业术语表（青训/BP/转会窗），按世界类型切换视角指令。
