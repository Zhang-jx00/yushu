# H06-超凡都市（异能 / 灵气复苏 / 神豪 / 赘婿 / 战神）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"超凡都市"世界维的写法：现代都市地表叠加超凡要素的整个家族——都市异能、灵气复苏（新旧秩序碰撞）与身份反转类金手指（神豪/赘婿/战神/神医）。对应 docs/05 世界维"超凡都市"条目、手法维"赘婿/战神/神豪/神医流""灵气复苏"两行。与 H07 现实都市的边界：本流派必须处理"超凡与世俗规则冲突"，H07 则完全无魔。该流派是免费平台（番茄"战神赘婿"即分类名）与短剧改编的核心赛道，节奏与付费文差异显著。

## 2. 核心知识框架

1. **双层世界结构**：表层（日常社会秩序）+里层（超凡体系）双轨运行；异能者分属秘密组织、政府机构、地下势力的三向归口（网文打斗套路分析），等级设定必须与组织结构配套——脱离势力的裸等级没有叙事意义。
2. **灵气复苏秩序重建学**：现代世界灵气回归后规则剧变——动植物变异、秘境/地窟出现、武考与武者协会等新体制诞生（全民参与感）、《全球高武》（老鹰吃小鸡，2018-2019 起点 835 万字，流派新一代标杆）以"经济收入换修行资源"把主角金手指与主线深度绑定；优秀作品还以设定隐喻现实（如"魂石分级"影射教育资源垄断）。核心难题是"复苏时间表"：D0 觉醒、百日、一年、十年各时点的秩序状态必须显式建模。
3. **异能设定方法**：三重渐进揭示法——拒绝信息轰炸，能力依托具体器物/场景首次亮相（器物锚定法），让读者通过画面而非说明理解（QQ 阅读《我爸爸是副职业大师》案例）；等级体系（F~S 级/一至九阶）要有成长空间与动态功能形态。
4. **身份反转公式**：压抑期（入赘受辱/退婚被嘲）→ 隐藏底牌（战神身份/百亿现金/系统）→ 打脸爆发（挑衅者登场→身份层层揭露→跪地求饶）→ 新循环（《上门龙婿》开篇"受尽屈辱→我有现金一百亿"即标准句式）；反套路变种：反派视角、自嘲吐槽式（小说阅读网《反派：开局妹妹带我去退婚》融合十余种套路）。
5. **平台节奏学**：免费平台按爽点需求切分（番茄"战神赘婿/神豪/无脑爽"直接成为标签），黄金三章有压缩为"黄金一章"的短剧化趋势；马甲文的"身份逐层揭开"节奏（docs/05 手法维）在本流派中与打脸循环深度耦合。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 灵气复苏项目强制生成"复苏时间表"（D0/百日/一年/十年四时点的秩序快照）→ 世界预设专用模板（docs/05"复苏时间表"要素）。
2. 超凡-世俗法律接口显式建模（武者协会/保密法/异能犯罪审判）→ 世界预设必填字段。
3. 都市地图真实感：小区/写字楼/城中村/夜市等日常地标优先于奇观 → 地点库（B04）的都市预设。

**设定卡 schema 扩展（超凡都市特有卡）**
4. 异能卡（名称/等级/代价/觉醒条件/保密级别）→ docs/05"异能体系卡"落地。
5. 都市势力卡（官方机构/世家/地下组织三层，各带"对超凡的态度"字段）。
6. 身份底牌卡（马甲清单+每层的知情范围与预定揭露时点）→ 马甲/战神/赘婿共用。
7. 财富系统卡（资产明细/资金流水/消费事件日志）→ 神豪流专属账本。
8. 灵气复苏事件卡（事件名/时点/触发的新秩序条目）。

**校验规则**
9. 保密规则校验：超凡能力在无保密措施场景公开使用且无后果链 → error（docs/05"保密规则"要素）。
10. 马甲时序校验：身份在预定揭露时点前被知情 → error（马甲不可提前穿帮）。
11. 财富守恒：神豪金额流水对账，消费超资产且无入账事件 → error。
12. 现实常识 lint：城市地理/法律程序/消费水平与真实常识冲突 → warn（世界维未声明架空时）。

**写法指南与节拍**
13. 压抑-释放高频循环：免费节奏 3 章内完成首个打脸；每章 1 个情绪波动点 → 节拍表（联动 H01 爽感算法）。
14. 打脸升级螺旋：小人物→富二代→家族→隐世势力，对手规格递增 → 大纲模板。
15. 灵气复苏卷级结构：复苏事件→学院/军营→地窟/秘境→全球格局 → 卷级模板。
16. 渐进揭示卡：每个新能力/新身份的首次亮相必须绑定具体场景 → 场景设计模板。

**读者期待与雷点**
17. 期待=装逼于无形、身份揭示、护短、新旧秩序碰撞的时代感；雷点=超凡与世俗规则冲突不处理、反转理由牵强、战力/金额通胀、都市背景悬浮 → taboos 清单。

**AI 提示词倾向**
18. 提示词注入"马甲状态表（已揭露给谁/未揭露）+ 异能等级 + 资产余额"→ 防穿帮与通胀。
19. 打脸场面按"挑衅→压制→身份揭示→围观反转"四段生成，结尾接断章钩子。
20. 日常-超凡双线比例控制参数（免费文超凡戏占比更高）→ 基调/平台参数包。

## 5. 对御书设计的启示

**数据结构建议：身份底牌卡（本流派核心差异化结构）**

```yaml
# schemas/身份底牌卡.yaml —— 赘婿/战神/神豪/马甲共用
extends: core/setting-card
fields:
  masks:
    type: array
    items:
      required: [identity, revealed_to, reveal_at]
      properties:
        identity: {type: string}      # 马甲（战神/首富之子/…）
        revealed_to: {type: array}    # 已知情的人物/势力 ref
        reveal_at: {type: string}     # 预定揭露时点（章节/事件）
        face_slap_hooks: {type: array}  # 可触发的打脸场景
```

**校验规则建议**
- `mask-timeline`：任何"知情范围"外角色对马甲做出知情反应 → error。
- `secret-breach`：超凡/底牌公开事件必须挂"后果链"实体，缺失 → error。
- `wealth-ledger`：神豪流资金流水守恒（复用 H02 资源账本引擎，币种换算）。

**写法指南与节拍建议**
- 平台参数包：目标平台=免费（番茄/七猫）时，把首个打脸时点从"3 章内"进一步前置并提示短剧化改写。
- 打脸螺旋大纲模板：对手规格递增表（个人→家族→隐世势力→国际）防止对手失重。

**读者期待与雷点**
- taboos.yaml：规则冲突不处理/反转牵强/通胀/背景悬浮；灵气复苏包追加"秩序快照断层"（时点之间世界状态对不上）。

**AI 提示词建议**
- 续写状态块："马甲知情矩阵{revealed_to}｜异能等级{rank}｜资产{assets}｜本章压抑/释放阶段{phase}"；双线比例参数控制日常戏与超凡戏配比，免费节奏下生成器自动提高打脸密度上限。
