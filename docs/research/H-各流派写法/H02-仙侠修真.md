# H02-仙侠修真（凡人流 / 洪荒流）

> 类别：H-各流派写法 ｜ 世界构建金字塔层级：叙事层 · 流派写法
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

研究"仙侠"世界维的写法：以修真求道为体系、东方神话为底色的类型，重点覆盖两大流派支系——凡人流（《凡人修仙传》开山，无背景凡人步步求道）与洪荒流（《佛本是道》开山，中国神话再创作）。与 H01 玄幻的区分：玄幻的引擎是战力与打脸，仙侠的引擎是资源稀缺、寿命焦虑与心境考验；修真境界谱系源自道家内丹学而非纯架空。对应 docs/05 世界维"仙侠"条目与手法维"凡人流""苟道流""家族修仙流"等行的写法侧细化。

## 2. 核心知识框架

1. **修真境界谱系**：主流九境"炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫/真仙"，源自道家内丹"炼精化气、炼气化神、炼神还虚、炼虚合道"的层级化改写；《凡人修仙传》体系（练气/筑基/结丹/元婴/化神/炼虚/合体/大乘/真仙）是该谱系最常被仿写的实例，且给出了明确的战力区间锚点（炼气 1~13、筑基 10~250、结丹 500~5000）。
2. **凡人流方法论**：主角资质平庸（四灵根级）、无逆天光环，靠谨慎、隐忍、谋略升级；核心是"物质修仙"——资源（灵石/丹药/法宝/功法）充足即可推进，因此世界必须资源匮乏、法则残酷；机缘存在但需主角自己发掘、算计、冒险（小寰岛、虚天殿式情节）。
3. **洪荒流设定学**：以《封神演义》《西游记》《蜀山剑侠传》《山海经》与传统神话为素材库再虚构；标志性原创设定包括十二祖巫（盘古血肉借尸还魂、巫族无元神）与巫妖大战（置于封神之前）；洪荒设定是小说家再创作而非正统神话（蚩尤刑天夸父原型属炎帝一脉，与"无情巫族"无关）——写作时需明确"再创作"边界。
4. **宗门生态与经济**：外门/内门/真传弟子结构、坊市交易、秘境开启周期、丹器符阵四艺分工，构成资源争夺的物质舞台。
5. **演化链**：凡人流 → 苟道流（风险规避喜剧）→ 家族修仙流（代际传承种田）→ 模拟器流（多周目收益叠加），叠加关系见 docs/05 §3 与 §8.3。

## 3. 可转化为产品规则的关键实践

**世界预设要点**
1. 世界按灵气密度分层（凡界/灵界/仙界）且资源稀缺度显式建模 → 世界预设必填"资源-地理-境界"三元约束表。
2. 时间跨度为世纪级 → 世界预设必须启用长寿时间轴与纪元字段（联动 C02）。
3. 洪荒流项目强制挂"神话素材来源表"（封神/西游/山海经……逐条标注沿用或改写）→ 世界向导的洪荒流专用 checklist。

**设定卡 schema 扩展（仙侠特有卡）**
4. 功法灵根卡（灵根资质/功法品阶/修炼速度修正）→ 凡人流金手指的载体。
5. 机缘卡（收益/风险/发现条件/是否可复现）→ 机缘风险表的数据底座。
6. 境界-寿元联动表（每境界 lifespan 字段，突破即更新）→ docs/05 派系包要素"境界-寿命联动"的落地。
7. 资源账本卡（灵石/丹药收支流水）→ 凡人流"资源精算"的可追踪化。

**校验规则**
8. 境界-寿元一致性：突破后寿元上限未更新 → error。
9. 越阶战斗校验：低阶胜高阶必须存在已登记的代价/底牌说明 → warn。
10. 资源守恒：消费大于持有且无获取事件 → error（灵石经济学 lint）。
11. 洪荒神话边界：把"再创作设定"标注为正统神话引用 → warn（防读者考据翻车）。

**写法指南与节拍**
12. 凡人流基础循环"资源短缺→风险决策→机缘获取→闭关消化"→ 节拍表模板。
13. 大境界突破=卷级高潮、闭关用时间压缩叙事（数年一笔带过+出关展现差距）→ 场景模板（联动 F03/F05）。
14. 秘境副本结构（开启-竞争-夺宝-追杀-脱身）→ 大纲模板。

**读者期待与雷点**
15. 期待=求道感、机缘、精算爽、寿命焦虑驱动的紧迫感；雷点=主角道德失准（滥杀无辜）、修炼逻辑断裂、机缘白给、寿命设定遗忘 → taboos 清单。

**AI 提示词倾向**
16. 续写提示词强制携带"当前资源账本+剩余寿元+当前境界瓶颈"三状态 → 防 AI 写成玄幻式无成本升级。
17. 机缘生成模板要求同时输出"收益/风险/代价"三元组 → 保持凡人流的风险对称性。

## 5. 对御书设计的启示

**数据结构建议：境界-寿元-资源三联动（仙侠派系包核心）**

```yaml
# schemas/功法灵根卡.yaml
extends: core/setting-card
fields:
  spirit_root: {type: string}      # 灵根资质（天/地/玄/黄 或 五行杂灵根）
  technique: {type: string}        # 功法名
  grade: {type: string}            # 品阶
  speed_modifier: {type: number}   # 修炼速度修正（校验升级节奏用）
  bottleneck: {type: string}       # 当前瓶颈描述（注入续写提示词）
```

**校验规则建议**
- `lifespan-sync`：境界 tier 变更事件必须触发寿元上限更新（cross_chapter 规则）。
- `resource-ledger`：灵石/丹药余额随消费事件递减，透支且无获取事件 → error。
- `cross-realm-fight`：以弱胜强场景检查是否存在 `trump_card`（底牌）引用，无则 warn。

**写法指南与节拍建议**
- 节拍表：凡人流默认循环 `资源短缺→风险决策→机缘获取→闭关消化`，每卷含 1 次大境界突破。
- 大纲模板内置"秘境五段式"（开启-竞争-夺宝-追杀-脱身）。

**读者期待与雷点**
- taboos.yaml：滥杀失德/修炼逻辑断裂/机缘白给/寿元遗忘；洪荒流追加"正史混淆"条目。

**AI 提示词建议**
- 生成前自动拼装状态块："寿元剩余{years}｜灵石{amount}｜瓶颈{bottleneck}｜本次机缘风险{risk}"；要求 AI 在情节中显式消耗或提及资源，维持"物质修仙"质感。
