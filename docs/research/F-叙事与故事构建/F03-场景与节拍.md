# F03-场景与节拍

> 类别：F-叙事与故事构建 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

场景与节拍研究故事的中观结构：场景（scene）如何由目标、冲突、灾难构成，场景之间的反应单元（sequel）如何由感受、两难、决定构成，以及句子级"动机-反应单元"（MRU）如何决定文字的呼吸感。它是 F01 宏观节拍与正文文字之间的中间层——一卷有几十场戏，一场戏由几百个 MRU 组成。边界区分：本领域不处理全书节拍排布（F01）与冲突的宏观升级（F06），只负责"单场戏为什么成立、单段文字为什么顺"。

## 2. 核心知识框架

1. **Scene-Sequel 双单元循环（Dwight Swain）**：Scene=Goal（POV 此刻想要什么）→Conflict（障碍）→Disaster（未达目标/更糟的转折）；Sequel=Reaction（情绪反应）→Dilemma（无好选项的处境）→Decision（做出选择，成为下一场戏的 Goal）。Ingermanson 名句："Disaster 就是没让角色达成目标——赢是无聊的。"
2. **结局类型学（try/fail 补充）**：并非每场都以灾难结束，四类结局=Yes / Yes-but（成功但有代价）/ No / No-and（失败且更糟）；Yes-but/No-and 保证每场都改变现状（Sanderson、Writing Excuses；Weiland 场景结局五型同源）。
3. **McKee 价值翻转**：每场戏必须让至少一条价值轴（生死/爱恨/自由-囚禁/希望-绝望）由正转负或由负转正，否则是"非事件"，应删或改；两难=两恶择一或两善取一的真选择。
4. **Gap（期望与结果的裂缝）**：角色基于期望行动，世界的回应撕开 gap，逼出下一层行动——场景推进的引擎（McKee；Emily Short 将其引入互动叙事）。
5. **MRU（动机-反应单元）**：外在客观的刺激（motivation）在前，角色反应（reaction）按生理顺序排列：情绪/本能→反射动作→理性动作与言语；段级配对决定因果流畅度。
6. **粒度对应**：The Novel Smithy 明确 MRU 是句级、Scene-Sequel 是章级、三幕是书级——御书据此按"书-章-场-句"四层组织结构数据。

## 3. 可转化为产品规则的关键实践

1. 场景卡双类型 → `kind: scene|sequel` 两组字段互斥必填（schema 见 §5）。
2. 价值翻转必填 → scene 卡必选"价值轴+翻转方向"，未翻转场景打"零翻转"警告并提示改为 sequel 或合并。
3. 决定→目标链条 → sequel.decision 自动生成下一 scene.goal 候选，形成可视化因果链。
4. 结局枚举 → disaster.outcome 限四选一（yes/yes_but/no/no_and），禁止"两不沾"。
5. MRU 顺序 lint → 检测"反应先于动机"（先写角色言行后补外部刺激）的段落并提示。
6. Scene:Sequel 配比仪表 → 连续 3+ 个 scene 无 sequel 提示"喘息缺失"，连续 2+ sequel 提示"节奏拖沓"。
7. 场景卡绑定 → 每张卡挂 story_time 与 POV（联动 F05/F04）。
8. 断章点推荐 → 在 disaster/reaction 边界自动推荐断章位置（服务网文钩子，联动 F02）。

## 5. 对御书设计的启示

**数据结构建议：场景卡 schema（目标/冲突/灾难/反应/两难/决定/价值翻转）**

```json
{
  "scene_id": "s-001",
  "kind": "scene",                     // scene=动作单元 | sequel=反应单元
  "pov": "char-id", "location_ref": "loc-id", "chapter_ref": "c-012",
  "story_time": {"start": "T+113d", "end": "T+113d"},
  "scene_fields": {                    // kind=scene 时必填
    "goal":   {"statement": "POV 此刻想要什么", "kind": "获取|摆脱|阻止|求证|报复", "stake": "失败失去什么"},
    "conflict": {"opposition": ["char-id 或 环境/规则/自我"], "escalation_note": "障碍如何加码"},
    "disaster": {
      "outcome": "yes_but",            // yes | yes_but | no | no_and
      "value_flip": {"axis": "安全↔毁灭", "from": "正", "to": "负"},
      "complication": "引出的新麻烦"
    }
  },
  "sequel_fields": {                   // kind=sequel 时必填
    "reaction": {"emotion": "第一情绪", "instinct": "本能反应"},
    "dilemma":  {"options": ["两恶A|两善A", "两恶B|两善B"], "axis": "冲突的价值观"},
    "decision": {"choice": "决定", "next_goal_ref": "s-002.scene_fields.goal"}
  },
  "word_budget": 1500,
  "checks": ["value_flip_or_sequel", "no_neutral_ending", "mru_order"]
}
```

**校验规则建议**
- 零翻转检测：kind=scene 且 value_flip 为空或同向 → 警告"非事件场景"。
- 因果断链：sequel.decision 未链接到下一场景 goal → 提示补链。
- 节奏配比：滚动统计最近 10 张场景卡的 scene/sequel 比与结局类型分布，全 yes 或全 no 均提示。
- MRU lint：启发式检测"角色言语/动作段落先于外部刺激描写"的句序（宽松级，可关闭）。

**功能建议**
- 场景卡看板：按章节排列 scene/sequel 卡，颜色标注 outcome 类型，一眼看出"连败连赢"。
- 断章推荐：把 disaster/reaction 边界标为候选断章点，输出钩子强度建议。

**AI 提示词建议**
- 生成正文前注入场景卡全文作控制上下文："本章场景目标 X、障碍 Y、结局为 no_and——正文结尾必须落在该转折上"。
- MRU 约束提示："反应段落按 情绪→本能动作→言语 顺序展开，不得先写反应后写刺激"。
