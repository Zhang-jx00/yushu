# F10-描写技巧

> 类别：F-叙事与故事构建 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

描写技巧研究叙述文本的"质感层"：展示与讲述（show don't tell）的判据与各自适用时机、五感与具象细节的使用、描写的人物滤镜（同一景物经不同 POV 角色的眼睛呈现不同色彩）、以及信息密度控制（场景/概要/停顿的时距选择决定每段文字承载的信息量）。与 F03（场景与节拍）的分工：F03 管场景的戏剧功能，本领域管句子层面的呈现质量。与 A08（世界观的叙事呈现）的分工：A08 管"写什么设定"，本领域管"怎么写才不变成设定说明书"。与 F09 的分工：F09 管对白行，本领域管叙述行——两者合成一章的血肉。

## 2. 核心知识框架

1. **Show, don't tell 的操作定义**（Reedsy）：把结论性陈述（"她很紧张"）替换为感官细节+动作+可见证据（"指尖敲着桌面；咖啡凉了没动"），让读者的想象力完成工作；讲述并非禁区，而是用于压缩时间、过渡场景与交代低张力信息（CRAFT Literary 的时机论：高情绪场景 show，过场 tell）。
2. **五感配置**（Clay Stafford / Enchanting Marketing）：多数初学者只用视觉，强者至少动用三感（气味与触感是最欠开发的沉浸源）；Enchanting 的练习法——为每个"讲述句"手写 2~3 个"展示细节"，是可产品化的改写流程。
3. **描写的人物滤镜**：描写永远通过 POV 角色的意识折射——猎户与画家看到同一片林子的细节不同；这与 Genette 聚焦理论（focalization）同构：谁感知，决定什么被写、如何被评价。失滤镜的"百科式描写"是视角崩坏的前兆（联动 F04）。
4. **MRU 的描写秩序**（Swain/Novel Smithy）：刺激（外部可观察的描写）在前、反应（内部感受）在后；句级秩序"感受→本能动作→理性动作与言语"天然决定了动作场景的描写节奏。
5. **信息密度与时距**（Genette 四时距）：场景（scene，等时长，高密度慢镜头）、概要（summary，压缩，"三年后"）、停顿（pause，纯描写，叙事时间冻结）、省略（ellipsis，跳过）；张弛节奏=四者配比。战斗用短句高密度、抒情用长句低密度是中文网文的常识性配比。
6. **网文语境的描写经济学**：免费阅读环境下读者滑屏快，描写必须"短、准、带钩"——环境描写不超过三行且必须服务于情绪或伏笔；"信息密度建议"在网文中的形态是：每段至少一个新信息或新变化，静态描写超过一段即有流失风险。

## 3. 可转化为产品规则的关键实践

1. 描写清单 → 场景卡附"感官覆盖检查"：视/听/嗅/触/味至少覆盖 3 感，纯视觉场景提示。
2. 讲述句检测 → 抽取情绪形容词+判断句（"他很愤怒/美丽/恐怖"），给出一键改写为"动作+细节"的建议。
3. 滤镜一致性 → 描写生成的形容词与意象须来自当前 POV 角色的职业/经历/情绪字段（联动 E02 档案），失滤镜警告。
4. 信息密度配额 → 按 Genette 四时距给段落标注 scene/summary/pause，统计连续 pause 篇幅（超过 1 段警告）、连续 summary 篇幅（超过 2 段提示"流水账"）。
5. 句长节奏提示 → 动作场景平均句长显著高于全书基线时提示"战斗段太文"，反之抒情段句长过短提示。
6. 描写-伏笔联动 → 描写片段可一键登记为伏笔（联动 F08 台账），环境意象默认进入伏笔候选池。
7. 设定说明书熔断 → 单场景内连续设定性叙述超过阈值，建议拆分为"对话传递/冲突传递/分章铺垫"。
8. 五感词库 → 按世界观（A09）维护可用的气味/声音/材质词表，防止 AI 生成跨世界违和意象（蒸汽朋克世界出现手机铃声）。

## 5. 对御书设计的启示

**数据结构建议：描写清单（挂接场景卡）**

```json
{
  "scene_ref": "sc-310",
  "sensory_check": {"visual": true, "auditory": true, "olfactory": true, "tactile": false, "gustatory": false},
  "filter": {"pov": "mei", "mood": "戒备", "profession_lexicon": ["玄铁", "兵符", "更漏"]},  // ← E02 档案
  "density_map": [                                        // 逐段时距标注
    {"para": 1, "mode": "pause",  "words": 90,  "new_info": 2},
    {"para": 2, "mode": "scene",  "words": 210, "new_info": 5},
    {"para": 3, "mode": "summary","words": 120, "new_info": 4}
  ],
  "tell_flags": ["他很紧张(P12)"],                          // 讲述句候选
  "setting_dump_risk": false,
  "linked_foreshadow": ["fs-001"]
}
```

**信息密度建议**
- 基线配比：正文场景 scene ≈60~75%、summary ≈15~25%、pause ≤10%；连续 pause >1 段或单段 pause >150 字告警。
- 每段信息配额：叙述段 new_info ≥1；连续两段 new_info=0 提示"原地打转"。
- 节奏分区：高潮段建议平均句长 < 全书基线 20%（短句加速），抒情/回忆段允许 +30%。
- 网文特例：环境描写单块 ≤3 行且须携带情绪或伏笔；设定叙述单场景 ≤300 字，超出强制拆分。

**校验规则建议**
- 讲述句检测：情绪形容词+人名/判断句模式匹配 → 给出改写建议而非自动替换（show/tell 时机由作者定）。
- 滤镜一致性：描写词汇命中 POV 角色禁用词域（如农家女视角出现化学术语）→ 标记。
- 跨世界违和：五感词库来自 A09 词表，越库词提示。

**AI 提示词建议**
- "以 mei 的视角改写本段：删掉情绪结论，用动作与感官细节呈现她的戒备；至少一种非视觉感官；不超过三行。"
- 生成注入："本场景滤镜=猎户视角的林子（可闻到腐叶与铁器），禁止画家视角的色彩词汇。"——把 E02 字段编译进提示词。
