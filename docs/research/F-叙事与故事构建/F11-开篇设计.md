# F11-开篇设计（黄金三章）

> 类别：F-叙事与故事构建 ｜ 世界构建金字塔层级：叙事层
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

开篇设计研究小说最初几千字的决策：在哪里开始（通常"紧贴第一动作之前"）、第一行/第一场景的钩子（clarity+intrigue+specificity）、信息供给顺序（世界观按需供给而非说明书轰炸）、主角登场与代入感建立、以及长篇结构的起点要素（激励事件如何前置或预告）。中文网文语境下特化为"黄金三章"：前三章决定编辑签约、推荐位与读者追读的平台筛选机制——创世编辑视角称之为首因效应，是免费阅读时代更严苛的"前三十秒"竞争。与 F02（网文连载结构）的分工：F02 管全卷节奏，本领域只管开局窗口。与 F07（悬念）的接口：开篇钩子本质是最高优先级的悬念发放。

## 2. 核心知识框架

1. **开篇位置论**（Writing.ie / Novlr）：从第一动作之前一刻开场（in medias res 的实用版），砍掉"清嗓子"段落（起床、照镜子、天气、回忆垫场）；很多作者写到第三章才发现真正的第一章——工具应支持"开篇重排"。
2. **钩子三属性**（Barker Books）：清晰（读者秒懂发生了什么）、好奇（提出全书要回答的问题）、具体（细节可感而非抽象口号）；Weiland 补充：钩子必须有机（organic）——内生于主线情节而非开场惊吓式的廉价噱头，且应出现在第一场景内。
3. **黄金三章的平台机制**（创世作家专区/知乎避坑指南）：前三章=编辑判断签约与读者判断追读的双重筛选面；典型雷区——梦境开局、大段世界观说明书、多视角漂移、主角憋屈过三章不反弹、开篇无冲突；正确结构——第一章立人设+发钩子，第二章给第一次正反馈，第三章兑现一次小爽点并亮出长线目标。
4. **信息供给的按需原则**：设定只在该用到时才给（iceberg 理论的工程化）；开篇允许读者"暂时不知道"，但必须"知道自己想知道什么"——即用问题清单替代信息清单。
5. **长篇结构的起点要素**（三幕结构）：开篇窗口内须完成 ords 激励事件（inciting incident）或其预告，使第一幕的转折有锚点；Weiland 的 hook→inciting event 序列给出两节拍的间隔设计（网文通常压缩为前三章内）。
6. **数据实证**（S1）：延后第一个爽点会显著伤害追读（35%→67% 的对照），但完全无蓄力又使爽点失效——开篇设计的本质是"第一次满足的时机定价"。

## 3. 可转化为产品规则的关键实践

1. 黄金三章检查清单 → 开局模板内置逐章必填项（schema 见 §5），缺项黄牌。
2. 雷区检测 → 开篇 5000 字内扫描梦境/回忆开局、设定说明书段、多视角漂移、纯对话开场等模式。
3. 钩子登记 → 第一章第一场景强制登记钩子（类型+解决的问题），要求与全书主线问题一致。
4. 激励事件锚点 → 标记激励事件所在章节，超过第三章警告"主菜未上"（可豁免并填理由）。
5. 信息供给账本 → 开篇每章登记"给了读者哪些设定/留了哪些问题"，检查问题数>设定数。
6. 正反馈节拍 → 前三章至少各一个情绪波动点，第三章必须含一次兑现型爽点（联动 F06 爽点节拍器）。
7. 开篇重排工具 → 支持把"现第 N 章"标记为真开篇并重算所有章节锚点（伏笔/悬念/时间线引用自动平移）。
8. 平台风格适配 → 按目标平台（起点/番茄/晋江）加载不同的开篇模板与雷区权重（联动 G/H 流派映射）。

## 5. 对御书设计的启示

**数据结构建议：黄金三章检查清单（开局模板）**

```json
{
  "checklist_id": "golden3",
  "applies_to_chapters": [1, 2, 3],
  "ch1": {
    "must": [
      {"item": "开篇钩子", "where": "第一场景", "rule": "清晰+好奇+具体，且来自主线问题"},
      {"item": "主角登场", "rule": "第一章内，带欲望与困境，禁止纯旁观视角"},
      {"item": "金手指/核心卖点亮相或预告", "rule": "至少预告"},
      {"item": "文风定调", "rule": "人称/视角/腔调在此定型（联动 F04）"}
    ],
    "banned": ["梦境开局", "大段回忆", "天气+镜子式起床", "多视角漂移", "纯设定独白"]
  },
  "ch2": {
    "must": [
      {"item": "世界观按需供给", "rule": "只给本场景用到的设定，问题数>设定数"},
      {"item": "第一次正反馈", "rule": "小胜/奇遇/金手指首次生效"},
      {"item": "短期目标成立"}
    ]
  },
  "ch3": {
    "must": [
      {"item": "兑现型爽点一次", "rule": "打脸/反转/能力兑现（联动 F06）"},
      {"item": "长线目标+短期目标双线可陈述"},
      {"item": "激励事件或其预告锚点"},
      {"item": "章末断章钩"}
    ]
  },
  "metrics": {"info_q_over_s_min": 1.0, "emotion_wave_per_chapter": 1, "hook_streak_max_gap": 0}
}
```

**校验规则建议**
- 逐项黄牌：清单 must 项缺失 → 开局页黄牌列表；banned 模式命中 → 红牌+定位到段落。
- 激励事件锚点：未在 ch1-3 标记激励事件 → 提示"第一幕无锚点"，允许豁免（慢热型文风须填理由）。
- 信息供给账本：ch2/ch3 的"设定条目数/问题条目数"比值 <1 → "说明书化"警告。

**功能建议**
- 开局仪表盘：三列（ch1/ch2/ch3）打勾卡片+雷区命中列表+追读关键指标（钩子位置、首爽点章节）。
- 开篇重排：拖拽章节设为新第一章，自动平移并复检伏笔台账（F08）与悬念矩阵（F07）的开篇锚点。

**AI 提示词建议**
- "写第一章：第一场景内完成钩子（清晰、好奇、具体），主角带欲望登场；不得出现梦境、回忆垫场与设定独白；结尾留断章钩。"
- 平台适配注入："目标平台=番茄：快节奏短段落，第一章内金手指生效，第一章即出现冲突；目标平台=晋江：允许铺垫，但第三章前须确立CP引力或核心悬念。"
