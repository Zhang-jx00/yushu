# B02-气候与自然带

> 类别：[B-地理与生态] ｜ 世界构建金字塔层级：[L1 地理层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

气候与自然带研究在大陆骨架之上铺设"气候皮"的全过程：纬度与大气环流、盛行风与洋流、降水分布（雨影效应、赤道辐合带）、气候带划分、以及由温度×湿度×海拔决定的自然带（biomes：雨林/草原/荒漠/苔原等），再往下是季节与天气事件层。边界上：地形本身归 B01，自然带里"住什么物种"归 B06/B07，气候如何被文明改变归 B09。本领域是 L1 层的中游枢纽——上游吃地形，下游供物种、资源、聚落与文化差异（草原游牧与水乡农耕的差异本质上是气候差异）。

## 2. 核心知识框架

1. **气候生成链**：社区最系统的推演路径（Worldbuilding Pasta《An Apple Pie from Scratch》气候篇）为：确定行星与纬度→大气环流（哈德莱/费雷尔/极地三圈环流决定信风/西风带与多雨/少雨纬度）→洋流输热→降水（雨影、季风、ITCZ）→气候带→自然带。YouTube 系列《How To Design Realistic Climates》与 Roll for Fantasy 的地图向导把同一链条压缩为可操作步骤。
2. **Köppen 分类作为命名骨架**：用 Köppen 气候分类（A 热带/B 干旱/C 温带/D 大陆/E 极地）给气候区命名与编码，是教程圈通行做法——它让"气候区"成为可枚举、可检索的类型而非模糊描述。
3. **简化四象限法**：面向作者的轻量方案（Go Teen Writers）：把世界按"湿冷/湿暖/干冷/干暖"四象限+海拔修正分配 biomes，牺牲精度换可用性；Madeline James 的系列教程也走"先分区再细化"路线。
4. **地形对气候的局部修正**：Roll for Fantasy 强调山脉雨影、湖泊调湿、森林自持水分等局部效应——同纬度不同侧可以有完全不同的自然带，这正是"可信但不呆板"的关键。
5. **可信度光谱**：r/worldbuilding 讨论"气候要多真实才够"的共识是：读者感知的真实感优先于物理精确；Worldbuilding Stack Exchange 的问答则给出由洋流与降水反推 biomes 的中量级方案。产品应提供风格化/半写实/硬核三档严格度。
6. **工具化对照**：Azgaar 管线把气候作为 heightmap 的直接下游层，自动计算温度/降水并映射 biomes——证明"气候层可自动生成、可手动覆盖"在工程上成立。
7. **气候服务故事**：Campfire Writing 的地理-气候教程（以托尔金为例）强调气候要转译为叙事资源：季节、风暴、旱季都是情节引擎，而不只是背景涂色。

## 3. 可转化为产品规则的关键实践

1. 气候层作为地形下游依赖 → 生成层序中 `climate` 依赖 `heightmap`；地形改动后未重算的气候层显示"已过期"标记。
2. 温度×湿度双轴自然带矩阵 → 内置 biomes 查表（含海拔修正列），一键按矩阵给地图上色并生成图例。
3. 雨影校验 → 检测"山脉背风侧紧贴湿热雨林"等冲突组合时告警并解释雨影原理。
4. 洋流/风向可选图层 → 作为气候区的"解释文档"图层，支持手绘与编辑，供 AI 生成降水描述时引用。
5. 天气与季节事件实体 → `WeatherEvent`（风暴/旱季/季风）挂在气候区下，可被场景与剧情引用。
6. 可信度档位 → 世界级设置 `realism_level`（风格化/半写实/硬核），控制本领域所有校验器的触发阈值。
7. 自然带聚合视图 → biome 条目聚合"此带常见物种/资源/聚落形态"，作为 B03/B05/B06 的导航入口。
8. Köppen 式编码 → 每个气候区给 `koppen_code` 类枚举字段，便于跨世界复用模板。

## 5. 对御书设计的启示

**数据结构建议**
- `ClimateZone`：`latitude_band`、`prevailing_wind`、`current_refs[]`、`precipitation`、`temp_range`、`koppen_code`、`weather_events[]`。
- `Biome`：`climate_ref`、`altitude_range`、`flora_default[]`、`fauna_default[]`、`resource_hints[]`、`mana_modifier`（预留超凡污染字段，衔接 B08）。

**功能建议**
- 气候向导四步流：纬度带→风带/洋流→降水→biomes，每步产出结构化字段而非整段文本。
- 季节日历联动：与 A04 时间法则的历法实体打通，季节由气候区驱动（北半球夏≠全球夏）。
- 写作侧"气候速查卡"：场景选中地点后悬浮显示其气候区、当前季节、典型天气。

**校验规则建议**
- 同纬度同海拔但气候带突跳（无山体/洋流解释）→ 提示补充成因或修正。
- 雨影检查：山系背风侧降水应显著低于迎风侧；赤道纬度出现冰原需显式理由（高海拔/魔法）。
- 与 B06 交叉：物种栖息 biome 不在该物种 `biomes[]` 列表内 → 引用错误提示。

**AI 提示词建议**
- 生成地区描写时注入：气候区类型、季节、近期天气事件，要求描写与之自洽（雨林不写尘土飞扬）。
- 生成动植物与物产清单时强制携带 biome 键（温度/湿度/海拔），从模板库按键取材再变异。
