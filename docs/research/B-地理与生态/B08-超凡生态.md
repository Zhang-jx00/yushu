# B08-超凡生态

> 类别：[B-地理与生态] ｜ 世界构建金字塔层级：[L2 生态层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

超凡生态研究超凡力量（魔法/灵气/异能/神力）作为生态要素参与世界运转的后果：超凡资源的自然分布（灵脉/魔晶矿/秘境）、魔化生物与魔化地貌如何嵌入食物网与自然带、以及超凡力量对资源、经济、战争的二阶影响。边界上：A02（超凡法则设计）回答"力量如何运行、有什么代价"——法则本身；D 系回答力量与文明水平的关系；本领域回答"法则落地之后，生态与地缘长什么样"。它同时是 B 系（地理生态）与 A02 的接口层：法则条目变更必须能传播到这里。

## 2. 核心知识框架

1. **Sanderson 三定律的生态推论**：限制>能力、理解度∝可解冲突（faq.brandonsanderson.com）——落到生态上即：任何超凡能力都必须以"成本/稀缺/副作用"的形式进入生态账本。能凭空造粮的法术若无成本，农业与饥饿立刻从世界里消失，随之消失的是一整个故事空间。
2. **二阶效应清单**：immortalcultivationhub 提出"魔法存在却不改变经济/政治/日常=世界构建失败"；The Sector M 按战争/教育/医疗逐项追问魔法的社会连锁。生态版本的同款追问是：谁靠它吃饭、谁被它取代、谁因它灭绝。
3. **魔法与经济相容性**：Worldbuilding Stack Exchange 经典问题"魔法与经济如何共存"的答案是给魔法设稀缺与成本（施法材料/损耗/风险）；r/worldbuilding 讨论"魔法滥用瓦解社会"则从反面警示：廉价万能的魔法会击穿食物网与阶层结构。
4. **系统化建模**：Project Multiplexer《How to Model Magical Reality》主张把魔法当作可推演的变量系统而非装饰性奇迹——这与 Azgaar 的分层思想同构：魔法法则应作为上游层，向下级联出魔化物种、超凡资源与地缘变化。
5. **超凡生态位与超凡资源**：魔植魔兽作为特殊生产者/捕食者进入食物网（"吞噬魔力"是一种代谢方式）；灵脉/魔晶作为资源进入 B03 的分布-贸易-冲突链；魔力污染与魔力枯竭是环境变迁的超凡形态（与 B09 交叉）。
6. **渗透进文化与日常**：Campfire《Magic in Daily Life》提示魔法应渗入艺术、习俗、语言——对应生态层即"凡人如何与魔化环境共处"（避瘴习俗、驱魔农业仪式），生态设定应能被文化条目引用。
7. **硬/软光谱决定可推演程度**：Dabble 的 hard/soft magic 光谱映射到生态：硬魔法下生态影响可量化推演（灵气密度→物种上限），软魔法下只能定性描述——产品应按世界的法则硬度切换校验强度。
8. **影响传播是行业空白**（种子库工具对比结论）：所有主流工具都没有"上游设定变更→下游受影响清单"机制，而这正是超凡生态最需要的能力——改一条法则，多少物种、资源、城市跟着失效。

## 3. 可转化为产品规则的关键实践

1. 超凡资源实体 → 灵气/魔晶/灵脉作为 `Resource` 子类型挂地图，自动参与 B03 的贸易、垄断与冲突推演。
2. 魔化 biome 变体 → biome 可标记 `mana_tainted`，自动生成"该带的魔化变体"提示（物种、色调、危险度），并要求引用来源法则。
3. 法则→生态 lint：能力必须有代价 → 超凡能力条目必填 `cost/limits`；"凭空创造物质"类无成本能力标记为"叙事危险"，并给出被其击穿的下游清单（农业/矿业/医药）。
4. 二阶效应三问问卷 → 新增/修改超凡法则时强制弹出：谁靠它吃饭？谁被它取代？谁因它灭绝/泛滥？答案写入影响记录。
5. 超凡食物网边 → 食物网支持 `mana_consumption` 边类型（魔物吞灵气、灵植吸魔脉），与普通捕食边并存且共享级联推演。
6. 法则变更影响报告 → 法则条目修改时自动列出受影响的物种/资源/城市/事件清单——把"影响传播"做成一等公民功能。
7. 灵脉图层 → 地图上叠加 `ManaNode`（灵脉节点/密度），与 B02 气候层并列成为可选图层。
8. 法则硬度档位 → 世界的 `magic_hardness`（软/半硬/硬）决定超凡生态校验强度：软魔法只要求"来源可引用"，硬魔法追加数量级校验。

## 5. 对御书设计的启示

**数据结构建议**
- `ManaNode`：灵脉节点（`map_pin`、`density`、`renewable`、`taint_effect`）；`Species.mana_affinity`（无/亲和/依赖/畏惧）；`SpellRule.cost/limits/side_effects`；`InfluenceRecord`（法则变更→受影响实体清单+时间戳）。
- `Biome.mana_modifier` 与 `Resource.type=arcane` 打通 B02/B03 的字段。

**功能建议**
- "如果魔法能 X"推演向导：输入一条能力，向导按 农业/矿业/医药/战争/transportation 五域逐项询问影响，产出结构化的二阶效应清单。
- 灵脉图层与超凡资源热力图：与普通资源层同交互，支持"灵脉改道/枯竭"事件（进入 B09 事件链）。
- 法则变更影响报告：修改 A02 法则条目时生成 diff 式受影响清单，逐项让作者确认"失效/重算/保留"。

**校验规则建议**
- 无成本凭空创造类能力 → 强提示并展示被击穿的下游条目。
- 魔化物种无对应法则来源（`source_rule` 为空）→ 告警；超凡资源被大量使用但查无产地 → 悬空引用。
- 硬魔法世界中"数量级失真"（灵气密度与魔兽数量不匹配）→ 按能量流给出参考区间。

**AI 提示词建议**
- 生成超凡生物/魔化地貌时注入其魔力来源与代价，要求描写"正常生态被如何扭曲"而非单纯堆砌异象。
- 生成超凡区域场景时注入灵脉密度与污染效应，使环境描写与法则事实一致。
