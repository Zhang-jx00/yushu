# B06-物种设计

> 类别：[B-地理与生态] ｜ 世界构建金字塔层级：[L2 生态层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

物种设计研究世界中生物种类的构建方法：智慧种族、普通动植物、真菌与怪物。它关心从环境与生存压力出发推导形态与习性（而非反过来给动物贴魔法标签）、物种卡的字段结构（生理/生态位/社会/用途）、物种与栖息地的绑定，以及物种条目的叙事功能（吉祥物/威胁/资源/象征）。边界上：物种之间的捕食关系与能量流动归 B07，超凡力量对物种的改造归 B08，文明驯化与物种灭绝的时间线归 B09。本领域是 L2 生态层的入口实体层。

## 2. 核心知识框架

1. **环境先行**：主流方法（SFWA 上 Orson Scott Card 的《Creating Aliens》与 Myers Fiction 的物种设计流程）一致：先定环境与生存问题，再选基础原型生物，逐项解决"吃什么、躲谁、怎么繁殖"，最后叠加独特识别特征——演化逻辑先于视觉奇观。
2. **Spec-evo 方法论词汇表**：Speculative Evolution Wiki 提供生态位、适应辐射、趋同演化、并行演化等术语体系；Serina: World of Birds 展示"种子世界"推演——从单一祖先物种按地质纪元向外辐射，是长期推演的范本。
3. **深度光谱**：Worldbuilding Stack Exchange 讨论"不做深度演化推演如何设计异星生物"——完全硬核 spec-evo 与"直觉式设计"之间存在中间态。产品应支持硬核档（记录祖先与选择压力）与轻量档（只填生态位与食性）。
4. **反人类中心主义**：r/worldbuilding 与 Conceptual Evolution 论坛的共识是警惕"额头加饰品的地球人"；后者给出"定义→机制→向前演化"的迭代设计法——先声明设计目标，再补机制，再沿演化前推到合理。
5. **物种卡的结构化先例**：Campfire 的 Species 模块与 World Anvil 的 statblocks（跑团双用）提供字段划分参照：生理特征/感官/寿命/繁殖/社会结构/特殊能力/与人类关系。
6. **东方博物志参照**：《山海经》异兽条目按"名称/形态/声音/出现地/药用或预兆"组织——物种条目天然可以携带"用途与象征"字段（可驯化、可入药、见则大旱），这是西方 statblock 缺失的叙事维度。
7. **物种与叙事**：物种设计最终要回答"它在故事里干什么"——威胁、伙伴、资源、谜团或主题装置；物种卡应有出场状态与钩子字段（同 B04 的冰山原则）。

## 3. 可转化为产品规则的关键实践

1. 物种卡最小必填集 → 必填：名称/类别（flora/fauna/fungus/other）/栖息 biome/食性/生态位；其余（生理/繁殖/社会）渐进展开。
2. 生态位必填校验 → 每个物种声明 `niche`（生产者/草食者/捕食者/分解者/寄生/共栖），为 B07 食物网供数据——没有生态位的物种进不了食物网。
3. 栖息地绑定 → `species.biomes[]` 只能引用已存在的 biome 条目，防止"悬空物种"（存在于文字里却无家可归）。
4. 山海经博物志模板 → 提供东方志怪字段组（形态/声音/药用/预兆/可驯化），一键把西方 statblock 转成博物志条目或双轨并存。
5. 演化链（可选硬核档） → 物种可挂 `ancestor_ref`+`selection_pressure` 文本，多条链接形成演化树；轻量档隐藏该字段。
6. 智慧种族额外检查 → `sapience=true` 的物种强制补"对文明的影响"字段（工具/战争/贸易/宗教角色），防止种族沦为贴纸。
7. 命名文化绑定 → 物种名可关联命名体系（语言种子/拉丁双名法），同一世界内命名风格一致。
8. 图鉴视图 → 按 biome 分组浏览全部物种，空 biome（无任何物种）与孤儿物种（无 biome）双向暴露。

## 5. 对御书设计的启示

**数据结构建议**
- `Species`：`category`（flora/fauna/fungus/other）、`sapience`、`diet`（植食/肉食/杂食/分解/其他）、`niche`、`biomes[]`、`traits[]`、`uses[]`（药用/役用/食材/材料）、`omen`（预兆，可选）、`ancestor_ref`、`selection_pressure`、`mana_affinity`（衔接 B08）、`reveal_state`、`hooks[]`。
- `SpeciesRelation`：`predator`/`prey`/`symbiont`/`parasite` 边（供 B07 食物网复用同一套边）。

**功能建议**
- 物种向导三步：选 biome→选生态位与食性→生成形态/特征/用途，输出结构化卡片而非整段设定文。
- 物种图鉴：按 biome 分组的图鉴视图+山海经式博物志视图双模式。
- statblock 导出：一键生成跑团兼容数据块（D&D/自定义），扩大用户面。

**校验规则建议**
- 场景中出现物种 X，但 X 的 `biomes[]` 不含场景所在 biome → 引用冲突提示。
- 智慧种族缺"对文明的影响"字段 → 建档不完整告警。
- 捕食/驯化关系引用不存在的物种 → 悬空引用错误。

**AI 提示词建议**
- 生成物种时强制注入 biome 键（温度/湿度/海拔）与生态位，要求形态由生存策略推导，禁止"随机拼贴翅膀+火焰"。
- 提供"基于 X 环境的三种生存策略生成三个变体"提示模板，批量填充图鉴。
