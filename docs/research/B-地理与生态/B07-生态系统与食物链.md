# B07-生态系统与食物链

> 类别：[B-地理与生态] ｜ 世界构建金字塔层级：[L2 生态层]
> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

生态系统与食物链研究物种之间"谁吃谁、能量如何流动、扰动如何传播"：食物网（food web）的构建、营养级（trophic level）与能量递减律、关键种（keystone species）与营养级联（trophic cascade）、生态平衡与崩溃的条件。边界上：单个物种的内部设计归 B06，文明对生态的改造（伐林/灭物种/引入外来种）归 B09；本领域聚焦"生态作为一张会传播扰动的网"。它的产品价值在于：生态网既是可信度基础设施（大怪兽为什么稀少），又是剧情机器（移除一个节点，全城挨饿）。

## 2. 核心知识框架

1. **营养级与能量流**：Wikipedia《Trophic level》与《Energy flow (ecology)》给出硬约束：食物网自生产者（营养级 1）起步，能量每上一级损失约 90%（十分之一定律）——这意味着顶级捕食者种群必然稀少、领地必然巨大，"密度过高的巨龙山脉"在生态上不可信。
2. **食物网优于食物链**：Wikipedia《Food web》与 Khan Academy 教程强调真实群落是网状而非线性——网状冗余决定稳定性；链条越单一，一个物种灭绝的破坏力越大。设计"脆弱生态"或" robust 生态"时，网密度本身就是设定参数。
3. **关键种与营养级联**：Wikipedia《Trophic cascade》的经典案例——海獭-海胆-海带的海洋级联、黄石狼-鹿-植被的陆地级联——证明移除或放回一个关键节点可以重构整个系统。关键种（keystone species）是生态叙事的杠杆点：它数量少但影响不成比例地大。
4. **Spec-evo 的长期视角**：Speculative Evolution Wiki 提供生态位填满/空缺、适应辐射的方法论；Serina 展示千万年尺度上生态位的易主与再平衡——生态不是静物，而是有历史的过程。
5. **与气候带的耦合**：Azgaar 管线把气候层输出为 biomes（自然带），r/worldbuilding 的社区流程同样是"先地形→气候梯度→生物群落"——食物网必须按 biome 分区构建，跨带迁徙物种作为例外显式标注。
6. **生产者与分解者是底线**：Khan Academy/LibreTexts 教程强调分解者与养分循环常被新手遗漏——一个没有"清道夫"设定的世界会积累无法解释的尸体与废物。
7. **生态驱动情节**：猎物灭绝→捕食者进村、瘟疫清空传粉者→歉收——营养级联路线就是现成的灾变剧情大纲，生态数据可以直接喂给情节生成。

## 3. 可转化为产品规则的关键实践

1. 捕食关系边表 → 食物网以 Species 之间的有向边（捕食/寄生/共栖/吞噬魔力）存储，提供图可视化画布。
2. 营养级自动推导 → 从生产者出发 BFS 计算每个物种的营养级，营养级 >5 时提示能量流不合理。
3. 种群规模提示 → 对顶级捕食者按能量递减律输出"合理数量级"参考（如该 biome 只能支撑 N 头），写"千头魔龙"前先亮黄灯。
4. 关键种标记 → `keystone=true` 的物种在删除/灭绝操作时自动触发"级联影响清单"（哪些物种挨饿、哪些泛滥）。
5. biome 生态完整性校验 → 每个 biome 至少 1 个生产者与 1 个分解者，缺失即告警；孤点物种（无任何捕食关系）提示补关系或标注"生态外成员"（如神兽）。
6. 灭绝推演沙盘 → 移除物种 X → 模拟直接相邻节点的一阶与二阶影响 → 输出剧情钩子列表。
7. 循环捕食检查 → A吃B、B吃A 的环状关系默认告警（寄生-宿主等例外需显式豁免）。
8. 跨带迁徙标注 → 跨 biome 活动的物种（候鸟/洄游鱼）要求声明迁徙路线，接入地图层。

## 5. 对御书设计的启示

**数据结构建议**
- `FoodWebEdge`：`predator`、`prey`、`relation_type`（predation/parasitism/symbiosis/mana_consumption——最后一类衔接 B08）、`biome_scope`（该关系在哪些带成立）。
- `Species` 补充字段：`trophic_level`（自动推导，人工可覆盖）、`keystone`、`population_scale_hint`（按能量流计算的数量级参考）、`migration_routes[]`。

**功能建议**
- 食物网画布：按 biome 过滤的力导向图视图，节点即物种条目，边可点击编辑。
- 灭绝推演沙盘：一键模拟"移除 X 后的第一/第二阶影响"，输出结构化剧情钩子（谁挨饿、谁泛滥、谁进城）。
- 图鉴联动：物种条目页直接显示"它吃什么/谁吃它"，写作时一眼查到生态位事实。

**校验规则建议**
- biome 缺生产者/分解者 → 完整性告警。
- 营养级 >5 或顶级捕食者数量级超标 → 能量流告警。
- 循环捕食环 → 告警（显式豁免除外）；捕食边引用不存在物种 → 悬空引用错误。

**AI 提示词建议**
- 生成野外/狩猎/灾变场景时注入该 biome 的食物网摘要，禁止出现网中不存在的猎物与捕食者。
- 生成"瘟疫/灾变"情节时按营养级联路线提示连锁后果，把生态数据转成情节大纲。
