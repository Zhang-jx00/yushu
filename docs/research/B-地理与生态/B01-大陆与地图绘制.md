# B01-大陆与地图绘制

> 质量要求：信息来源 ≥6 条、覆盖 ≥3 种来源类型；URL 必须来自真实检索结果。

## 1. 领域定义

大陆与地图绘制研究世界陆地的宏观骨架——大陆轮廓、山系走向、海岸线形态、水系（河、湖、内海）——以及把这些骨架表达为地图的工艺。它回答两个问题：一是"地理长什么样才可信"（地理内在逻辑），二是"地图怎么画、怎么标、怎么与设定库联动"（可视化与数据）。边界上：气候与自然带如何铺在地形之上归 B02，资源与地缘归 B03，聚落选址归 B05——本领域只负责"地"本身的生成、编辑与呈现。它处于 L1 地理层的最上游：地形是几乎所有下游设定（气候、资源、聚落、历史）的依赖根。

## 2. 核心知识框架

1. **分层生成管线**：Azgaar's Fantasy Map Generator 的生成顺序是 heightmap→biomes→rivers→burgs→states→…→trade routes，每层依赖上游、可独立重生成（官方 Wiki Quick Start）。这是"世界引擎"式产品的活教材：上游改动应级联下游，且每层可锁定后单独重掷。其 heightmap 变换/裁剪扩展讨论（Issue #997）也表明用户强烈需要"生成后手工微调"能力。
2. **地理可信性方法**：Mythcreants《Crafting Plausible Maps》给出的主流共识是"先山后水"——先定山系（板块构造式的走向），再由分水岭推导河流，河流自高地向低处汇流、支流只合不分，海岸线由侵蚀与沉降过程塑造。Worldbuilding Stack Exchange 上"河湖放在哪"类问答进一步总结出：城市常位于河口、渡口、河流交汇处，内陆盆地允许内流河但需要标注。
3. **手工绘图工艺**：面向作者的流程（Quill & Steel：草稿→海岸→山地→河流→植被→标注）与专业细节（Map Effects 的河流放置教程：等高线决定河道走向）互补；r/mapmaking Wiki 汇总了含气候带/洋流系列在内的系统性教程。标注规范（Designing Maps）：河流名斜排沿河走、山脉名沿走向排列、字号映射聚落重要度。
4. **工具谱系**：程序化生成（Azgaar，JS/D3、开源 GPL）、画笔式绘制（Wonderdraft/Inkarnate，Sprixen 有对比评测）、矢量精绘（Inkscape 等）。工具选择对应工作流差异：生成派从随机+编辑出发，绘制派从叙事意图出发。
5. **东方原生图式——《山海经》**：刘宗迪等研究指出《山海经》以"山—海—荒"三圈构成空间秩序，按山/泽条目记录物产、异兽、神祇、方国，是"地理-神话知识体系"。它提供了与西方"大陆-海洋"图式并列的另一种大陆组织方式：以圈层和条目而非投影与疆界来认识大地。
6. **地图作为设定索引**：社区实践中地图不单是插图——pin（图钉）承载地点实体、图层承载不同设定切片（政治/地形/贸易），地图即空间数据库的视图。

## 3. 可转化为产品规则的关键实践

1. 分层生成管线 → 世界引擎按"地形→水文→（下游：气候/聚落）"层序生成，每层可锁定，上游变更自动提示重算下游未锁定层。
2. 先山后水引导 → 新建大陆时先让用户画/生成山脊线，再派生海岸与水系，而非直接甩出完整地图。
3. 河流合法性校验 → 校验器检查：河流须起于高地终于海/湖、支流只合不分；异常项标记"待决"而非静默修正。
4. 内流区显式标注 → 内陆盆地内流河合法但要求打上"内流区"标签，防止被误判为错误。
5. 聚落候选点标记 → 在河口、河流交汇、山口、优良港湾自动输出"聚落候选点"，供 B05 消费。
6. 标注规范模板 → 内置标注层级规则（字号=重要度、河流斜排、山脉沿走向），地图图例自动生成。
7. 地形笔刷微调 → 生成后支持 heightmap 局部笔刷编辑，编辑结果只级联到未锁定层。
8. 三圈层东方模板 → 提供"山海经式"大陆模板（内圈山/中圈海/外圈荒）与西方大陆模板并列。
9. 地图 pin 与设定库双向绑定 → pin 即地点条目入口，图上可按图层切片（地形/政治/贸易）切换视图。

## 5. 对御书设计的启示

**数据结构建议**
- 新增 `MapLayer` 实体：字段 `layer_type`（heightmap/hydrology/climate/settlement/route…）、`seed`、`locked`、`upstream_deps[]`、`regen_policy`（自动级联/提示后级联/冻结）。
- 地理要素实体化：`GeoFeature`（coastline/mountain_range/river/lake/basin），河流带 `source_feature`、`mouth_feature`、`flow_direction`、`is_endorheic`（内流）属性；地图 pin 以 `location_ref` 指向 Location 条目。

**功能建议**
- 分层"生成历史"侧栏：像图层时间线一样记录每层每次生成的种子与参数，支持回滚某层而不动其他层。
- 地图即索引：点击任意 pin 直达地点条目；地点条目页内嵌小地图定位；导出同时产出静态图（含图例）与交互图层。

**校验规则建议**
- 水文 lint：无源之河、中途凭空消失的河、支流分叉、河流爬坡四类硬校验；海岸线闭合检查（多边形不自交）。
- 下游失效提示：修改山系后，依赖该分水岭的河流与下游聚落列表自动高亮"可能失效"。

**AI 提示词建议**
- 生成地理描写时注入地形事实（"此地位于 X 山脉背风坡、Y 河下游"），禁止 AI 自造与地图冲突的水文/地貌。
- 生成大陆骨架时按"先山后水"分两步提示，先产出山系方案供确认，再派生水系与海岸。
