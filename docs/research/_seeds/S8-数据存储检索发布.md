## 关键发现备忘
- "Markdown 真源 + SQLite 可重建索引"有官方级背书（FTS5 external content + appfileformat 论文）。
- WAL 是自动保存前提；索引库禁放网盘同步目录。
- 设定卡格式：YAML frontmatter（Obsidian 兼容）+ JSON Schema 校验 + TOML 配置。
- 知识管理四家收敛于"类型化实体+属性+视图"；视图只存查询定义。
- 关系建模选属性图（nodes/edges 两表+CTE），暂不引入图库。
- 时间线内部统一数字刻度，纪元/历法在渲染层转换（跨纪元换算=纯函数）。
- 防丢稿四层防线：dirty flag+debounce（500ms–1s）+本地兜底+启动恢复。
- 中文底座：jieba 自定义词典灌角色名、OpenCC 词级转换、clreq+GB/T 15834 排版规则。
