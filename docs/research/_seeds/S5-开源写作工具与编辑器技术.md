## 关键发现备忘
- 开源小说工具共性：项目树+结构化档案+单机桌面；均无世界观一致性校验与 AI 记忆能力 → 御书差异化。
- novelWriter 的"轻量标记+@tag 实体引用+纯文本"对 Git 最友好。
- Markdown 双向编辑解法：结构化文档为唯一真源，Markdown 仅序列化产物。
- Electron 官方 anti-patterns + utilityProcess/Worker；VSCode 证明上限高但需工程投入。
- 图谱选型：关系图编辑 React Flow/G6（万级），全量知识图谱只读 Sigma.js（十万级 WebGL）。
- 存储三件套统一到 SQLite：better-sqlite3 + simple 中文分词 + sqlite-vec。
- local-first 七理想可作数据层验收清单；"文件互操作 vs 数据库能力"取舍须 v1 定调。
