- ~~266 个 `.ts/.tsx` 文件里 SPDX 头 0 个~~ **R82 已收口**：扫描范围 297 个文件全部带头，`spdx-headers.test.ts` 4 例守住（漏加即红，本轮已实测红过一次）。
- 缺 `CODE_OF_CONDUCT.md`、`GOVERNANCE.md`、`CODEOWNERS`、`.nvmrc` ⇒ **前三份 R81 已补**；
  **`.gitattributes` 仍缺，且 R82 撞上了它的后果**：本机 `core.autocrlf` 来自 **system 级配置**
  （`git config --system --get core.autocrlf` = `true`，local/global 均未设），仓库又没有 `.gitattributes` 定策略 ⇒
  `git diff` 对每个源文件打印 "LF will be replaced by CRLF the next time Git touches it"。
  **处置边界**：不能改 system/global 配置（本机还有别的项目在推送，改了会影响它们）；
  正确做法是**只给本仓库加 `.gitattributes`** 并配一次 `git add --renormalize .` 的独立提交——
  那会产生一次全仓 diff，**必须单开一轮做，别混进功能轮**（同 SPDX 的口径）。
  本轮已按此事实校准：变异脚本与 SPDX 锁都按"文件可能是 CRLF"写（锁用 `split(/\r?\n/)` 取首行，行尾无关）。
- `docs/adr/` 只有 2 篇（规则 DSL、中文检索），`docs/04` §11.4 要求的误报阈值与插件 API 冻结面两篇还没写。
- **renderer 打包 1.5 MB / gzip 498 kB**：本地 `file://` 加载下分包未必更快，要先测冷启动与常驻再决定。
